# 自然口语化

> 对话贴近真实口语（默认），有停顿、重复、语气词，像真人说话。自然流畅，不做作。
> 所属节点：对话风格

## 教学指令

自然口语化对话是默认对话风格，核心在于'像真人说话'。真人说话不会把意思说满，会有停顿、犹豫、打断、话里有话、答非所问。具体技法：

1. 潜台词原则：人物说的话和真实想法之间永远有缝隙。表面聊天气，实际在试探；表面说没事，实际在生气；表面答应，实际在敷衍。用动作暗示真实态度（手指敲桌面=不耐烦，避开眼神=心虚，停顿太久=在撒谎）。

2. 动作标签(beat)设计：不要每句话都用'XX说/道'，用动作替代标签——递烟、倒茶、看窗外、挠头、沉默两秒。每3-4句对话之间必须插入一个动作或微表情，这个动作本身就在说话。

3. 口语节奏：允许语气词（啊/呢/吧/嘛/嗯/哦）、省略主语、半截话、打断。熟人之间说话不完整，不需要把每个信息点都说清楚。

4. 信息控制：对话是人物博弈，不是信息传递。角色不会主动把知道的全说出来，要通过追问、误解、回避、说漏嘴来推进。

5. 角色差异化：教育程度高的人句子完整、逻辑清晰；底层劳动者句子短、粗话多、喜欢用比喻；老人爱啰嗦、爱说教；年轻人说话快、网络词多。

### 约束规则

- 连续对话不超过4句必须穿插动作/神态/环境描写
- 对话标签'XX道/说'每千字不超过8次，优先用动作替代标签
- 禁止出现文绉绉的书面化台词（如'吾辈岂是贪生怕死之辈'），除非角色设定明确要求
- 每段对话场景中至少有1处潜台词（人物说的话和动作暗示的真实态度不一致）
- 禁止对话中直接说出角色情绪（如'我很生气''你别害怕'），情绪用语气和动作表现
- 对话标签禁止连续重复同一个动词超过2次

### 范例

**标注**：自然口语示范：用动作（按烟头/倒茶/盯着看/塞抽屉）替代对话标签，每句对话都短，潜台词丰富——陈默说'没事'但脸色不好明显有事，老周不拆信封直接塞抽屉表示信任，茶水溢了不擦说明心里有事。

```
老周把烟头按灭在烟灰缸里，烟蒂已经堆了半缸。「来了？」

「嗯。」陈默拉开椅子坐下，没看他。

「喝什么？茶还是凉白开？」

「随便。」

老周倒了杯茶推过来，茶水太满，溢了一点在桌面上。他没擦。「东西拿到了？」

陈默从外套内袋里掏出一个牛皮纸信封，放在桌上，没推过去。「你先看看。」

老周没去碰信封。他盯着陈默的脸看了几秒，端起自己的茶杯喝了一口。「你脸色不好。」

「昨晚没睡好。」

「出什么事了？」

「没事。」陈默终于抬眼看他，「你到底要不要？」

老周沉默了两秒，把信封拿过去，没打开，直接塞进了抽屉。
```
