# 记忆模式

> 9种记忆提取规则 + 伏笔生命周期 + 遗忘规则

## 记忆类型

| 记忆类型 | 存储内容 | 提取触发 | 有效期 |
|---------|---------|---------|--------|
| 伏笔-埋 | 初次暗示：异常现象/角色无心之言/环境细节 | 大纲中标记埋设章 | 至回收章 |
| 伏笔-触 | 再次提及：不经意间提到，加强读者记忆 | 距埋设3-5章后 | 至回收章 |
| 伏笔-提 | 接近回收：给出明显线索，读者开始猜测 | 距回收1-2章前 | 至回收章 |
| 伏笔-收 | 揭示真相：伏笔回收，读者产生"原来如此" | 回收章 | 回收后转为"已回收" |
| 角色记忆 | 角色知道的信息：角色经历/获取的信息/对其他人物的了解 | 角色出场时加载 | 持续，除非角色失忆 |
| 读者记忆 | 读者应该记住的信息：关键设定/重要事件/人物关系 | 涉及相关设定时加载 | 持续，定期触碰 |
| 世界观记忆 | 设定类信息：力量体系/地理/历史/社会规则 | 涉及相关设定时加载 | 持续，除非设定被推翻 |
| 事件记忆 | 已发生事件：前文章节摘要/关键事件时间线 | 写前分析时加载 | 持续 |
| 遗忘标记 | 标记不再需要记住的信息：已失效的伏笔/已被推翻的设定 | 无 | 永久 |

## 伏笔生命周期

```
埋设 → 间隔3-5章 → 触碰 → 间隔1-2章 → 提示 → 回收
  ↓                    ↓                    ↓
  │                    │                    │
  标记为"活跃"        标记为"活跃"        标记为"即将回收"
```

### 伏笔状态管理

| 状态 | 含义 | 操作 |
|------|------|------|
| 活跃 | 已埋设，待回收 | 每5章检查是否过了触碰窗口 |
| 触碰中 | 本章需要触碰 | 写前分析中列出 |
| 即将回收 | 1-2章内回收 | 写前分析中标注 |
| 已回收 | 已完成回收 | 移入"已回收伏笔"列表 |
| 遗忘 | 已放弃/不再需要 | 标记为遗忘，不再追踪 |

### 活跃伏笔上限

- 同时活跃伏笔不超过10个
- 大伏笔（卷级）不超过3个
- 中伏笔（跨章节）不超过5个
- 小伏笔（章内/跨章）不超过5个
- 超过上限时，优先回收旧伏笔，再埋新伏笔

## 遗忘规则

### 自动遗忘条件

| 条件 | 遗忘对象 | 说明 |
|------|---------|------|
| 伏笔埋设超过20章未回收 | 该伏笔 | 读者已遗忘，回收无意义，标记为遗忘 |
| 角色超过5章未出场 | 该角色的"角色记忆" | 再次出场时需重新建立角色状态 |
| 设定超过10章未被使用 | 该设定的"世界观记忆" | 再次使用时需重新触碰 |
| 事件超过8章未被引用 | 该事件的"事件记忆" | 不再作为写前分析的默认加载项 |

### 手动遗忘标记

- 被推翻的设定：标记为"已推翻，不再使用"
- 已放弃的伏笔：标记为"已放弃，不再回收"
- 已死亡角色的记忆：标记为"角色已死，记忆归档"

## 写前分析加载规则

每次写前分析时，按以下优先级加载记忆：

1. **事件记忆**：上3章摘要 + 本卷关键事件
2. **角色记忆**：本章出场角色的当前状态
3. **伏笔状态**：活跃伏笔列表 + 到期伏笔
4. **世界观记忆**：本章涉及的世界观设定
5. **读者记忆**：读者应该记住但可能遗忘的信息（触碰窗口检查）
