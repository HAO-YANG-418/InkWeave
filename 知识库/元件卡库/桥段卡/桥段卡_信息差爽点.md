# 桥段卡：信息差爽点

- **母题**：主角掌握他人不知的关键信息 → 从容布局反制
- **结构**：①他人误判（信息缺失） → ②主角借信息差布局 → ③对方踩坑 → ④主角收网 / 点破
- **情绪曲线**：藏(0-30%) → 布(30-60%) → 坑(60-85%) → 收(85-100%)
- **钩子位**：章末留「他还不知道自己已经输了」或「下一个信息差在哪」
- **适配题材**：都市爽文 / 悬疑 / 群像 / 电竞
- **来源书**：结构通用（综合爽文通则，非单本原文）
- **禁忌**：禁信息差无来源（须合理获得）；禁点破太早（须蓄力）；禁对手纯弱（须势均或更强）
