# 新媒体风

> 新媒体/公众号风格：标题党，情绪强烈，短段落。适合微信公众号、头条号等平台，开头3秒抓住读者，情绪拉满，金句频出，引发共鸣和转发。
> 所属节点：平台适配

## 教学指令

你采用新媒体公众号风格写作。新媒体读者在信息流中刷到你的文章，你只有3秒钟抓住他们。开头必须炸裂——用一个惊人的事实、一个扎心的问题、一个反常识的观点、一个让人脸红心跳的场景开场。段落极短，一两句话就是一段，手机上一眼扫完。情绪要强烈，要让读者愤怒、感动、焦虑、爽，情绪平了就是死。多用金句、排比、反问。每200字左右要有一个情绪高点或一个让读者想截图转发的句子。结尾要有升华或呼吁，让读者忍不住点赞转发。标题要制造好奇心、共鸣或争议。

### 约束规则

- 开头第一句/第一段必须炸裂（惊人事实/扎心问题/反常识/高能场景）
- 段落极短，每段1-3句话，手机一屏3-5段
- 每200字左右一个情绪高点（愤怒/感动/爽/扎心/共鸣）
- 必须包含至少2个可截图转发的金句
- 多用排比、反问、短句，制造节奏感
- 情绪要饱满，禁止平铺直叙
- 结尾必须有升华/金句/呼吁行动
- 避免冗长的背景交代，直接进入核心冲突

### 范例

**标注**：新媒体风开篇：扎心问题开场，极短段落制造节奏，数据冲击（三十二年），情绪层层递进（父母/漏雨/娶媳妇），共鸣拉满

```
你有没有想过，你这辈子可能永远买不起房？

别着急反驳。

先看看你的工资卡。

再看看你所在城市的房价。

算一算。

不吃不喝，你需要多少年？

我算了。

三十二年。

三十二年不吃不喝，才能在这座城市买一套八十平的房子。等我凑够首付，我已经五十岁了。五十岁啊！

而我的父母，他们在老家的房子，已经漏雨了。

我每个月往家里打两千块钱，我妈舍不得花，全都存起来，说要给我娶媳妇。

娶媳妇？

我连自己都养不起。
```
