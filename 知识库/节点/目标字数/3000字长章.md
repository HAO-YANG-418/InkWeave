# 3000字长章

> 单章目标字数3000字左右的长章节。适合起点等付费阅读平台，一章内容量充足，可以写完整场景和战斗，读者付费性价比高。
> 所属节点：目标字数

## 教学指令

你以3000字左右为单章目标字数写作。长章有充足的空间展开内容，可以写完整的大场景（一场战斗、一次对话博弈、一段探索）。开头可以有更充分的铺垫和场景营造（300字以内），中间有足够的篇幅发展多条线索，高潮部分可以写得更细致，结尾也有空间做情绪收束。3000字大约是12-18分钟阅读时间，读者对“一章”的期待感更高——必须有足够的实质内容，不能注水。付费读者对长章的质量要求高，每段都要有存在的价值。

### 约束规则

- 单章字数控制在 2800-3300 字之间（2800 为硬地板，低于即 error）
- 开头铺垫不超过300字
- 一章至少包含一个完整场景（有起因-经过-结果）
- 可以有更丰富的描写和心理刻画，但禁止注水
- 单段不超过200字
- 付费章节质量要求高，必须有实质剧情推进
- 结尾可以是钩子也可以是小高潮收束，给读者值回票价的感觉

### 范例

**标注**：长章结构：充分展开，细节丰富，高潮写透，值回票价

```
3000字长章结构示例：
- 开头（300字）：场景营造+情绪铺垫，承接上文
- 发展（1500字）：多线推进，对话+动作+描写+心理充分展开
- 高潮（800字）：核心冲突/战斗/反转，写足细节
- 收束（400字）：情绪沉淀+后续影响+钩子或小结
```
