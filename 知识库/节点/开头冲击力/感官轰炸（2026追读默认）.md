# 感官轰炸（2026追读默认）

> 2026最强开头模式：3秒停留率优化。第一句≤20字直接身体刺激/动作/冲突，0铺垫直接进现场。前300字完成冲突爆发→主角在场→异常出现。
> 所属节点：开头冲击力

## 教学指令

你使用2026年最强追读力开头模式——感官轰炸+3秒停留。严格遵守：

【第一句铁则】

- 第一句必须≤20字，直接写主角能感知的强刺激或正在发生的动作。

- 最优第一句是单字/两字感官鼓点：疼。/烫。/冷。/响。/血。/不对。

- 次优第一句是直接动作/冲突/结果：「刀尖抵住她喉结。」「外门弟子林凡，一刀斩了大师兄。」「离婚协议签完第三分钟，电话响了。」

- 绝对禁止：写景（天刚亮/寒风/大雪）、交代背景（在一个XX的地方/这是XX大陆）、介绍人物（我叫XX/XX今年XX岁）、回忆从前（很久以前/从前/话说）。

【前三句结构】

- 第一句：强感官刺激或直接动作冲突。

- 第二句：主角的本能身体反应（缩手/僵住/回头/屏住呼吸/手指扣紧/后颈汗毛竖起）。

- 第三句：读者看到一个具体的、正在发生的异常（不是背景介绍，是具体的东西在动/在发光/在流血/在逼近）。

【黄金300字】

- 前300字必须完成三件事：冲突已经在发生→主角身体已经在反应→一个异常信号已经出现。

- 前300字内不能有任何世界观说明、等级介绍、人物回忆、环境铺陈。

- 背景信息用一句话插在动作中间带过：「这是灵气枯竭第27年，他正在被人追砍。」

- 人物不超过2个（主角+直接施压者）。

- 场景聚焦一个动作现场：签字台/手术室门口/擂台中央/矿道深处。

### 约束规则

- 第一句≤20字，单字/两字感官鼓点最佳
- 第一句禁止写景/背景/介绍/回忆
- 第二句必须是主角本能身体反应
- 第三句出现具体异常信号
- 前300字：冲突在场→主角身体在场→异常在场
- 前300字禁止世界观说明/等级介绍/回忆/环境铺陈
- 前300字人物不超过2个，场景不超过1个

### 范例

**标注**：矿工式强开篇：第一句单字「疼。」；第二句身体反应（指关节砸到、渗血、火辣辣烧）；第三句异常出现（茧壁在震，而且不是他凿的那种震）。

```
疼。

凿尖砸在指关节上，林深闷哼一声，指缝里渗出血。他甩了甩手，骨节处火辣辣地烧，血珠滴在靴面上，很快被岩尘吸成深色。

茧壁在震。

不是他凿的那种震。
```

**标注**：系统文强开篇：第一句直接动作+金手指（刀尖抵喉结+系统亮了）；第二句身体反应（呼吸卡住、凉意钻骨）；第三句异常/金手指展开。

```
刀尖抵住她喉结时，系统弹窗亮了。

苏晚的呼吸卡在喉咙里，脖子不敢动，刀尖的凉意顺着皮肤往骨子里钻。

【检测到濒死状态，绑定「反向许愿」功能】
```

**标注**：玄幻穿越强开篇：第一句直接写结果（越级杀人）；第二句现场反应+主角身体反应（手抖）；第三句信息反咬（灵魂穿越，颠覆读者预期）。

```
外门弟子林凡，一刀斩了内门大师兄。

血溅在演武场的青石上，围观的弟子全傻了。林凡握刀的手在抖，不是因为害怕，是因为这具身体里的灵魂，三秒前还不是他。
```
