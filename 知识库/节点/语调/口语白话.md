# 口语白话

> 通俗流畅、有活人气味的口语化叙事（默认），像说书人讲故事，不端着，适合大多数网文。
> 所属节点：语调

## 教学指令

口语白话是默认叙事基调，核心是'像说书人给读者讲故事'。语言必须通俗直白、口语化、有活人气味——不端着、不故作高深、不半书面。具体规则：

1. 用词层面：必须多用口语词和语气词——日常动词（走/跑/跳/踹/瞪/攥/整/搞/弄）、口语代词（咋/啥/哪/谁）、语气词（了/吧/嘛/呗/呢/咱/甭/干脆）。这是'必须'不是'可以'。允许适度方言点缀，但不能满篇方言。

2. 句式层面：以中短句为主（15-25字），偶尔长句补充信息。句子结构简单直接，主谓宾清晰。短句要连成一气——靠'然后/其实/说白了/结果/可/但/说到底'这类口语词续气，绝不靠句号硬断成一逗一段。一句一段是断奏不是节奏。

3. 叙事距离：中等距离——叙事者知道主角在想什么，可把人物的碎碎念、吐槽、自嘲用自由间接引语揉进叙述（这就是'人味'的主来源：主角脑子里要一直在嘀咕）。不能用第二人称'你'跟读者说话（除非特殊设计）。

4. 节奏：叙事节奏明快，不拖泥带水。描写不拖泥带水，动作干脆利落（不拖泥带水≠不说清：事件因果、动作链、设定逻辑必须写完整，禁的是堆砌修饰和慢镜头，不是禁把话说完）。信息传递直接，不绕弯子。

5. 通俗≠粗糙：口语化不等于水字数。每句话都要有信息量，不能说废话。'他很厉害'是废话，'他一刀劈碎了试剑石'是有效的。'非常紧张'是废话，'手心全是汗'是有效的。

6. 禁止事项：禁止文艺腔（'彼时''忽而''颔首''蹙眉'）、禁止翻译腔（'是的，他想''我恐怕不能同意'）、禁止书面语堆砌、禁止过度解释（把读者当傻子什么都说明白）。

7. 禁书面联接词做过渡：因此/然而/继而/况且/换言之/总而言之/与此同时/由此可见/须知/固然/诚然/不可否认——一律不用，改用口语连接或干脆另起意思。

8. 范式与反例：

- 口语写法：'许照把刀折了塞回兜里，又蹲回国庆跟前，盯着他那片不渗血的暗红看了会儿。操，这玩意儿居然不往外冒血。'

- 半书面反例（禁止）：'许照把刀折回去，塞口袋。蹲回陈国庆面前，看那片不渗血的暗红。'——'口袋/面前/看那片…暗红'是中性书面形，缺语气、缺内心戏、用书面联接，是病句。

### 约束规则

- 以中短句为主（15-25字），单句不超过50字，禁止一逗到底
- 禁止使用生僻词、文言词（彼时/忽而/颔首/蹙眉/沉吟/思忖等），除非角色对话需要
- 禁止程度副词堆砌（非常/十分/极其/很+形容词连续出现），用具体细节替代
- 每段必须有实质内容（动作/对话/信息/感官），禁止空洞段落（'他心中百感交集''气氛十分凝重'这类空话）
- 禁止叙事者跳出来对读者说话（'各位看官''你猜怎么着''你要知道'）
- 形容词使用克制——能用动词和名词表达的不用形容词
- 段落目标长度80-120字，手机阅读友好
- 必须多用口语词和语气词（了/吧/嘛/呗/呢/咋/啥/咱/甭），禁止只用中性书面形叙事
- 短句必须连成句群或段落，靠口语连接词续气，禁止一句一段的断奏式排版
- 禁止书面联接词做过渡（因此/然而/继而/换言之/与此同时/由此可见/须知/固然/诚然/否认）

### 范例

**标注**：口语白话示范：用词通俗（干啥/没干啥/咋了/操），句子短，动词精准（甩/扔/凑/摸/嚼/摔），没有华丽修饰，但信息量大。'馒头是凉的，硬得像石头'一个细节就传递了环境艰苦和人物心情。结尾一个'操'字比任何描写都有力。叙事直接，不解释壁温36度意味着什么（读者通过老张的反应自己体会）。

```
陈默推开宿舍门的时候，屋里三个人正在打牌。

「回来了？」上铺的老张头也没抬，甩出一张牌，「今天工头找你干啥？」

「没干啥。」陈默把外套挂在门后，在自己床沿坐下，开始解鞋带。矿靴上全是泥，鞋带结成了硬块，解了半天才解开。

「没干啥能留你到这个点？」对面床的小李扔了牌，凑过来，脸上带着那种知道了秘密的笑，「听说深区那边又出事了？」

陈默没接话。他把矿靴脱下来，摆在床下摆齐，然后从枕头底下摸出半块干硬的馒头，咬了一口。

馒头是凉的，硬得像石头。

「到底咋了？」小李不依不饶。

陈默嚼着馒头，看了他一眼。小李的眼睛在矿灯光下发亮，像等着听故事的小孩。

「壁温升到36了。」陈默说。

屋里安静了两秒。老张手里的牌停在半空。

「操。」老张把牌往床上一摔。
```

**标注**：口语白话示范：动作连成一气（折了塞回兜里/又蹲回/盯着看了会儿），用'兜里/跟前/这玩意儿'等口语形；结尾一句心里吐槽'操，这玩意儿居然不往外冒血'把人味和情绪一下带出来，再补一句'现在抽等于告诉监控他来过'用口语逻辑推进。没有'塞口袋/面前/看那片暗红'这类中性书面形，也没有句号硬断成一逗一段。

```
许照把刀折了塞回兜里，又蹲回国庆跟前，盯着他那片不渗血的暗红看了会儿。

操，这玩意儿居然不往外冒血。

他摸了摸兜里那包烟，没抽。现在抽，等于告诉监控他来过。
```
