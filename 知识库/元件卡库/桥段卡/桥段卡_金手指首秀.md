# 桥段卡：金手指首秀

- **母题**：隐藏能力首次展露 + 旁观者震惊
- **结构**：①被逼入展示场景（比试/危机） → ②众人预期主角输 → ③金手指轻描淡写发动 → ④全场哗然 + 反派脸色变
- **情绪曲线**：压(0-30%) → 疑(30-55%) → 炫(55-85%) → 爽(85-100%)
- **钩子位**：章末留「这还只是开始」或「有人盯上了他」
- **适配题材**：全题材通用（爽文核心骨架）
- **来源书**：斗破苍穹 / 全职高手 / 斗罗大陆（结构提炼，非原文）
- **禁忌**：禁止首秀即无敌（须留成长空间）；禁止围观反应脸谱化（须有层次：从嘲到惊到惧）
