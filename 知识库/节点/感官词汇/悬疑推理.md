# 悬疑推理

> 悬疑推理世界观词库，包含尸体、血迹、指纹、线索、嫌疑、动机、不在场证明、凶器、密室、推理、侦探、警察、法医、监控、脚印等刑侦推理专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用悬疑推理世界观词库。写作时自然融入刑侦推理的专有名词和感官描写：血腥味的铁锈味、福尔马林的刺鼻、黑暗中地板的吱呀声、指纹粉末的灰白、尸体的僵硬冰冷、监控画面的噪点。身体描写注重紧张感——后颈发凉、心跳加速、手心出汗、瞳孔收缩、屏住呼吸。动作描写要有侦查味：蹲下身检查、戴手套取证、翻看物证、调监控、做笔录、还原现场、推理演绎。场景：凶案现场、审讯室、法医解剖室、监控室、密室、雨夜街道、废弃建筑。氛围营造至关重要：压抑、紧张、诡异、不安。

### 约束规则

- 必须使用刑侦推理专有词汇，法医和警察程序要合理
- 线索描写要精确，不能模糊（伤口形状/血迹形态/指纹位置等）
- 氛围营造是重点：压抑/紧张/诡异/不安
- 推理过程要有逻辑，线索必须公平（读者和侦探获得同样信息）
- 感官描写注重：血腥味/福尔马林/黑暗中的声音/冰冷触感
- 对话可以是警察之间的术语对话，也可以是审讯中的心理博弈

### 范例

**标注**：悬疑推理词库示例：尸体/血迹/尸斑/尸僵/致命伤/密室/指纹粉/取证/法医等刑侦词汇，氛围紧张压抑

```
血腥味还没散。

陈默蹲在尸体旁边，戴上乳胶手套。死者是一名中年男性，仰面躺在客厅的地毯上，胸口有一处刀伤，血迹以他为中心呈放射状喷溅，在白色墙壁上画出一幅刺目的图案。

“死亡时间大约在昨晚十点到凌晨两点之间。”法医蹲在另一边，指着尸体脖颈处的紫红色斑块，“尸斑已经固定，尸僵开始缓解。致命伤是一刀毙命，凶器是单刃锐器，宽度大约三厘米，从肋骨间隙刺入心脏。”

陈默的目光从尸体移开，扫过整个房间。门窗完好，没有撬动痕迹。茶几上有两个茶杯，一杯还剩半杯凉茶，另一杯几乎没动。

“密室？”助手小王低声问。

陈默没说话，他注意到一件奇怪的事——死者右手的食指和拇指上沾着一些灰白色的粉末，但他家里没有任何面粉或类似的东西。

那是指纹粉。

有人在警察来之前，已经擦拭过现场了。
```
