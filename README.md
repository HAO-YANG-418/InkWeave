# InkWeave · 墨织 — 让 AI 写出能 battle 热门网文的章节

> **一句话**：把「写前分析（镜头链规划）+ 双树质量门禁」焊进流程，AI 产出的每一章都**好懂、饱满、0 error 可出货**。
> 零 API Key，装好即用；说一句「写第 3 章」就自动走完流程。

---

## 为什么需要 InkWeave

普通 AI 写网文，十章九翻车：

| 通病 | 表现 | InkWeave 怎么治 |
|---|---|---|
| **水** | 凑字数、信息密度低 | 镜头链强制每场 ≥400–600 字、合计 ≥目标，字数从规划来，不是写完再补 |
| **碎 / 冷** | 逼碎句、文学性凌驾可读性 | 「好懂」是唯一硬标准，文学性是可选子风格，绝不凌驾「一眼看懂」 |
| **AI 味** | 「笑了笑」「嘴角一勾」、书面联接词 | 门禁零容忍：AI 套路词 + 书面联接词直接打回 |
| **标点翻车** | 破折号乱飞、引号错位 | 破折号零容忍 + 全角弯引号成对 + 引号内疑问句用问号，生成主路径就焊死 |
| **不出货** | 写完不知道行不行 | 写完必过门禁，0 error 才放行，否则打回重写 |

## 30 秒安装

```bash
# 1. 克隆
git clone https://github.com/HAO-YANG-418/InkWeave.git
cd InkWeave

# 2. 安装依赖（运行时）
npm install

# 3. 把 skill 装进 WorkBuddy 可加载目录（项目级 + 用户级）
npm run install-skill

# 4. 重启 WorkBuddy
```

重启后，对话里说「写第 3 章 / 续写 / 盲写」，WorkBuddy 自动加载 `inkweave-writer`，跑：
**写前分析（镜头链规划）→ 生成 → 门禁循环（0 error 才出货）**。
你不用记任何命令，不合格的章会被打回重写。

> 不想装 skill、只想手动跑？在仓库根目录：
> `npx tsx 检测工具/inkweave-write.ts --chapter 3 --title "觉醒"`（生成规划）
> `npx tsx 检测工具/inkweave-write.ts --review "<章节文件>"`（门禁验收）

## 它凭什么「好懂不水」（门禁硬标准）

每章生成后自动跑 `检测工具/check-chapter.ts`（双树合并口径），**有 error 即打回**：

1. **破折号零容忍**：本章不出现任何「——」。
2. **省略号零容忍**：不出现「……」。
3. **引号铁则**：全角弯引号 `""` 成对；引号内疑问句用问号结尾。
4. **禁 AI 套路**：「笑了笑」「嘴角一勾」等套路词直接 error。
5. **禁书面联接词**：然而 / 因此 / 由此可见 / 总而言之 等 warning。
6. **字数地板**：低于下限即 error；目标字数（默认 3000）从写前规划来，内容写丰 → 字数自然够。

## 核心架构（四根支柱）

```
大纲 / 想法
   ↓
[inkweave-writer Skill]   ← 命令驱动入口：装好自动加载，不可跳过流程
   ↓
[写前分析]                ← 镜头链规划 + 元件卡库调用（偷框架不抄剧情）
   ↓
[生成引擎]                ← 源码/（生成时真身）· 节点系统 × 元件卡库（正交）
   ↓
[质量门禁]                ← 检测工具/（CLI 验收）· 双树合并去重，防口径分裂
   ↓
高质量章节（好懂优先 · 0 error 可出货）
```

1. **双树架构（防口径分裂）**：`源码/` 是生成时真身，`检测工具/` 是 CLI 验收（唯一检测逻辑源），合并去重并标注来源。
2. **节点系统 ⊥ 元件卡库（正交控制）**：节点控「怎么写」（风格），元件卡控「写什么结构」（骨架），互不替代。
3. **标点归生成主路径 + 零容忍门禁**：标点铁则写在 `源码/kb/base-prompt.ts`，破折号零容忍，检测器确定性规则兜底。
4. **Skill 自包含**：所有 craft 铁则 / 禁令 / 预设固化在 `知识库/` + `生成指令.md` + `base-prompt.ts`，不依赖对话记忆。

## 进阶：微调底座（可选，不装也能用）

要让底座真正贴合「好懂直白」的网文语感，可用热门网文微调。语料定稿 8 本（好懂口语化、非文风特殊）：斩神 / 斗罗大陆 / 完美世界（指定）+ 大奉打更人 / 斗破苍穹 / 全职高手 / 灵境行者 / 第一序列。

**你只需做一件事（不用写代码）**：把正版 `.txt` 放进 `corpus/`，告诉我「放好了」，我跑 `finetune_prep.py` 自动清洗→切段→蒸馏成 `finetune_data/train.jsonl`。`corpus/`、`finetune_data/` 已设为不入库，书**不会**上 GitHub。

> 没有语料也完全不影响现在用 InkWeave 出章——skill 阶段零成本、不需微调。

## FAQ

- **需要 API Key 吗？** 不需要。skill 阶段用默认底座盲写、自检、出货，零成本。
- **出的章能直接发吗？** 能。过 0 error 门禁即出货级，可直接用于宣传 / 引流素材。
- **装好后为什么没自动加载？** 装完要**重启 WorkBuddy**；确认 `npm run install-skill` 输出「已安装到 用户级 / 项目级」。
