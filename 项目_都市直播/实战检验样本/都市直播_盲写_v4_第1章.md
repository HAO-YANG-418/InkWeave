# 都市·直播带货 · 第1章 断掉的那条线（盲写 v4 · 跨载体验证）

> 盲写口径：与 v3 一致——写前不回看任何规则（好懂红线 / #6 / #7 已从 生成指令.md 剥离；铁则、技法亦不查阅），只靠已去冷峻的默认底座自然写。目的：验证 skill 通用性**不依赖单一题材**（前两轮均为玄幻同人，本轮换都市现实题材）。

陈默盯着后台那条线，看了三秒，就知道今天完了。

不是掉，是断。八点十分，在线人数从两万三直接砸到九百，像被人从中间砍了一刀。

"投流呢？"他问。

运营助理小邱手指在键盘上抖："投流没停，钱还在烧。但流量……不进人了。"

"查口碑分。"

"掉了。四点九掉到四点二。"

陈默后槽牙咬紧了。

口碑分掉到四点二，自然流量池直接锁死，投流再多的钱也灌不进来。这不是出 bug，这是有人从背后捅了一刀——直播间被批量投诉了。

他抬头看向主播。小姑娘还在镜头前笑，一句一句喊"三二一，上链接"，完全不知道自己脚下已经踩空了。

陈默走过去，把手机屏幕亮给她看了一眼，又收回来。

"播你的。"他说，"别停。"

他退回后台，手指飞快点开投诉记录。三百一十七条。时间集中在八点零五到八点零八，三分钟。投诉理由一模一样，连错别字都一样："收到货物与描述不符，主播辱骂消费者"。

小邱脸白了："默哥，这是刷的。"

"我知道。"

陈默把后台截图一张张存下来，存了三十七张。存到第三十八张的时候，办公室的门被推开了。

进来两个人。前面是老板赵建业，后面跟着周航。

周航是他带的。三年前这小子连千川后台都点不明白，是陈默一个键一个键教出来的。去年双十一，陈默把主账号交给他练手，自己去做新号。

现在周航站在赵建业身后，下巴抬着，不看他。

"老陈，停一下。"赵建业拉了把椅子坐下，语气很和气，和气得像在念讣告，"口碑分掉成这样，今晚这场先下播吧。账号，先交给周航。"

陈默没动。

"赵总，"他说，"三百一十七条投诉，三分钟进来的，理由一字不差。这不是口碑分的问题，这是有人花钱买人来搞我。你查都不查，就让我交号？"

赵建业笑了下："生意上的事，不用搞得这么难看。号是公司的，你也是公司的，对吧？"

"号是公司的。"陈默点头，"那我这三年呢？"

办公室里静了两秒。

周航终于开口了，声音不大："默哥，你别这样。GPM 上个月就掉了一百二，自然流量占比连着六周往下走，赵总不是针对你。"

陈默慢慢转过头看他。

"周航，"他说，"GPM 掉那一百二，是因为你把主推款从九十九换成了六十九。客单价掉三成，GPM 能不掉？你换款那天，我在群里发了三个问号。"

周航没接话。

赵建业站起来，拍了拍陈默的肩，手很重。

"老陈，你先回去歇两天。工资照发。"

陈默把手机扣在桌上。

他没有吵。办公室里吵架的人从来赢不了。他站起来，把椅子推回原位，拿起自己的保温杯。

走到门口的时候，他停了一下。

"赵总，"他回头，"账号交出去可以。但有一件事我提醒你——"

"什么？"

"今晚这场是年货节大场，平台给的流量券是绑在我个人实名上的。"陈默说得很慢，"号交出去，券带不走。今晚剩下这四个小时，你们只能靠自然流量撑。"

赵建业脸上的和气，僵了一下。

陈默没再看他们，推门出去了。

走廊很长，灯管坏了两盏，一明一暗。他走到电梯口，按下行键，然后低头打开手机。

后台还开着。那是他自己的小号——三年前注册的，实名是他，绑的是他母亲的银行卡。粉丝数：四百三十七。

他点开"开播"，把标题改了三个字。

然后给小邱发了条消息：

"把今晚的排品表发我一份。原版，别改。"

电梯门开了。陈默走进去，镜面门合上的时候，他看见自己笑了。

### 写后比对（写完才评估）

- **开头**：数据断崖（两万三→九百）硬开场，外部压力第一句就到场；非"陈默坐在工位上回想"式慢起。
- **有货（真行业细节）**：口碑分 4.9→4.2 锁死自然流量池、投流照烧但不进人、GPM 掉一百二、客单价从 99 换 69 导致 GPM 跌、千川后台、年货节大场流量券绑个人实名、排品表、主推款——全部是可核的具体业务细节，非"他很懂直播"这类概括句。
- **人物厚度**：三年师徒（一个键一个键教出来的周航）背叛；"号是公司的，那我这三年呢"；被踢时不吵（"办公室里吵架的人从来赢不了"）——有软肋、有城府、不工具人。
- **推进与反转**：投诉刷量→交号逼宫→陈默反手点出流量券绑个人实名（信息差反打）→小号开播 + 要排品表（后手）。
- **章尾硬钩**：小号开播 + 要原版排品表 + 镜子里他笑了——concrete 反击伏笔，非"明天还要继续"式任务续集。
- **对话人味**：赵建业"和气得像在念讣告"、周航"你别这样"、陈默"你换款那天我在群里发了三个问号"——各带目的与信息差，互相顶，非汇报式问答。
- **好懂**：全篇口语白话、零文艺腔、术语都随上下文自解（不掉书袋）；长短句自然交错，未剁碎句。
- **跨载体结论**：都市现实题材与玄幻同人题材下，默认底座产出同档质量 → **通用性不依赖单一书**。
