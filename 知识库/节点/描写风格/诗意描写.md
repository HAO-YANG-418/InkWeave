# 诗意描写

> 意象优美，节奏舒缓，语言有诗的质感。善用比喻、通感和意象叠加，营造独特的审美氛围。
> 所属节点：描写风格

## 教学指令

描写追求诗意美感。善用新鲜的比喻和意象，允许通感（声音有颜色、温度有形状），语言有节奏感和音乐性。意象要精准独特，避免陈词滥调。节奏舒缓，像散文诗一样铺展画面。情感不直说，通过意象传递。每一个意象都要承载情感重量。

### 约束规则

- 比喻和意象必须新鲜，禁止陈词滥调（心如刀割、泪如雨下等）
- 描写节奏舒缓，不急于推进动作
- 每个场景至少有一个核心意象贯穿
- 避免堆砌华丽辞藻，诗意来自精准而非华丽

### 范例

**标注**：月光如霜、如凉水，影子如颤抖的线——意象新鲜，节奏舒缓。

```
月光从天窗流下来，在石板地上铺成一片霜。

她坐在那片霜里，像一株被遗忘在冬夜的植物。铜碗搁在膝上，碗沿的凹角盛着一小片月光，像盛着一碗凉透了的水。

风从巷道尽头来，带着三千尺地底的呼吸。灯焰晃了晃，把她的影子投在墙上，拉成一道细长的、颤抖的线。
```
