# 通用基础（默认）

> 标准填充词检测模式，使用默认阈值。允许适度的填充词和过渡表达，在节奏和精炼之间取得平衡。maxFillerSentences=3, maxFillerWords=8。
> 所属节点：填充词

## 教学指令

你使用标准填充词检测模式。在这个模式下，明显的空洞填充（重复啰嗦、无意义凑字数）需要删减，但允许适度的过渡词、情绪渲染词和节奏调节词。写作不是电报，适当的铺垫、情绪渲染和过渡连接是必要的。关键标准是：这句话虽然不是核心信息，但它是否在调节节奏、渲染氛围、或者提供必要的缓冲？如果是，可以保留。如果只是单纯重复、凑字数、或者空洞无物，则应该删减。

### 约束规则

- 每千字填充词句不超过3句
- 每千字填充词不超过8个
- 允许适度的过渡词和连接词（然而/但是/就在这时等）
- 允许适度的情绪渲染词（但不要重复堆砌）
- 禁止连续多句无实质内容
- 禁止同一段落内重复表达同一个意思
- 套路句（倒吸冷气/震惊等）可以偶尔使用，但一章内不超过2次

### 数值参数

| 参数 | 值 |
|------|-----|
| maxFillerSentences | 3 |
| maxFillerWords | 8 |
| maxDashCount | 3 |
| maxEllipsisCount | 3 |

### 范例

**标注**：标准模式：允许适度的描写和情绪渲染，但不允许空洞重复

```
他推开那扇门，一股霉味扑面而来。屋子里落满了灰尘，看起来已经很久没有人住过了。

他环顾四周，目光最终落在了桌上的一封信上。信封已经泛黄，但上面的字迹还依稀可辨。

他走过去，拿起那封信，手指微微有些颤抖——这是父亲的笔迹。

（标准模式允许“微微有些颤抖”这类情绪渲染，也允许连接词和过渡，但“实在是太不可思议了他简直不敢相信自己的眼睛”这类重复空洞的表达会被标记为填充）
```
