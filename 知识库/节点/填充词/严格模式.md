# 严格模式

> 严格检测填充词/水字数模式，将更多词汇和句式判定为填充。maxFillerSentences=1（每千字最多1句填充），maxFillerWords=4（每千字最多4个填充词）。适合追求精炼文风的作者。
> 所属节点：填充词

## 教学指令

你使用严格填充词检测模式。在这个模式下，几乎所有空洞无信息量的表达都会被判定为填充并需要删减。严格限制以下类型的表达：无意义的感叹（“真是太……了”“不得不说”）、重复的强调（反复说同一个意思）、空洞的过渡（“话说回来”“值得一提的是”）、冗余的修饰（不必要的形容词和副词堆砌）、凑字数的心理描写（没有实质内容的“他想了想”“心中暗道”之后跟空洞感想）、万能填充句（“周围的人都惊呆了”“倒吸一口冷气”等过度使用的套路句）。每一句话都必须推进剧情、塑造人物或传递信息，否则就该删。

### 约束规则

- 每千字填充词句不超过1句
- 每千字填充词不超过4个
- 禁止使用空洞感叹：“真是太……了”“简直……”“不得不说”“不可否认”
- 禁止无信息量的心理描写和自言自语
- 禁止反复强调同一个信息（说一遍就够）
- 禁止套路化万能句滥用（“所有人都惊呆了”“倒吸冷气”等）
- 禁止不必要的副词和形容词堆砌
- 每个句子都必须有实质功能（推进/塑造/传递信息）

| maxFillerWords | 4 |

### 范例

**标注**：严格模式：大量修饰词和套路句都被视为填充，应删减到最精炼的表达

```
【填充句-需删除】
他实在是太厉害了，简直就是天才中的天才，周围的人都不由得倒吸一口冷气，所有人都震惊了。

【修改后-精炼】
他赢了。
```
