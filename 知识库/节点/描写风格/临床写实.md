# 临床写实

> 客观冷静精确的描写方式，像医生观察病例、像警察记录现场。不带感情色彩，细节精确到数字和量化描述。
> 所属节点：描写风格

## 教学指令

描写客观、冷静、精确，不带感情色彩。像写报告一样记录场景：精确的数字、准确的位置关系、可量化的物理属性。不写「恐怖」「美丽」「恶心」等主观评价词，只写可观察的事实。温度是多少度，距离是多少米，伤口多长多深，光线从几点钟方向来。冷感来自客观本身，而非形容词。

### 约束规则

- 禁止使用主观感情色彩词（恐怖、美丽、恶心等）
- 物理属性尽量精确量化（温度、距离、尺寸、时间）
- 描写顺序遵循空间逻辑（从整体到局部/从外到内）
- 不加入叙述者的情感评价

### 范例

**标注**：法医/刑侦式客观记录，不带感情，细节精确。

```
尸体位于七号矿道岔口，距主巷入口47米。

男性，年龄约45-50岁，身高172厘米，身着藏蓝色矿工服，头戴安全帽，头灯已碎裂。

死亡时间初步判断为6-8小时前。体表无明显外伤，但右手食指指甲断裂，指缝中有矿渣残留。岩壁温度计显示当前壁温35.8度，低于正常值1.4度。

死者面部朝向岔口深处，双目圆睁，右手向前伸出，呈抓取姿态。
```
