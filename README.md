# InkWeave — 墨织 · 网文写作智能引擎

> 「以墨为线，编织故事。」

**InkWeave**（墨织）是一个专为中文网文打造的**写作智能引擎**。它不只是帮你写——它把网文的节奏、爽点、读者心理沉淀成可复用的结构资产，在生成每一章的同时自动做质量门禁，让产出自带追读力、且**好懂优先**。

---

## 它现在是什么（阶段定位）

当前阶段 = **内部 skill 阶段**：以三套发布级 Skill 为直接载体，引擎底座（生成 + 质检）作为 Skill 的运行时支撑。

- **发布载体**：三套 WorkBuddy Skill（见下「三套 Skill」），用户无需任何 API Key 即可用默认底座盲写、自检、出货。
- **根因治理**：引擎曾把「文学极简 / 克制 / 留白 / 低逗句比」误当「写得好」，逼出晦涩碎句，与网文「好懂直白」诉求相悖。现已用**好懂优先元规则**从训练本质层面纠正——好懂是唯一硬标准，文学性只是可选子风格。
- **软件化阶段**（后续，非当前阻塞）：接入真 LLM API 跑量、用热门网文语料微调底座。当前验证一律零成本、不需要 key。

## 核心架构

```
大纲/想法
   ↓
[三套 Skill]   ← 发布级载体（写作工坊 / 大纲创作院 / 设定工坊）
   ↓
[写前分析]      ← 镜头链规划 + 元件卡库调用（偷框架不抄剧情）
   ↓
[生成引擎]      ← 源码/（生成时真身）· 22 配置节点 × 95 选项风格系统
   ↓
[质量门禁]      ← 检测工具/（CLI 验收）· 双树合并去重，防口径分裂
   ↓
高质量章节（好懂优先 · 0 error 可出货）
```

**四个工程支柱**

1. **双树架构（防口径分裂）**
   - `源码/`：生成时真身（引擎运行时直接读）。
   - `检测工具/`：CLI 验收（唯一检测逻辑源）。
   - 二者算法不共享、同指标可算不同值，`check-all.ts` 合并去重并标注来源，凡同指标自相矛盾先怀疑双树口径。

2. **节点系统 ⊥ 元件卡库（正交控制）**
   - **节点系统**（`源码/node-registry.ts`，22 节点 × 95 选项）控制「怎么写」（风格：口语人味 / 节奏 / 感官 / 修辞…）。
   - **元件卡库**（`知识库/元件卡库/`）控制「写什么结构」（骨架）：母题卡 / 桥段卡 / 章法卡 / 句法卡——来自对热门网文的**结构级拆书**，不抄原文、版权合规。

3. **蒸馏三档（规则 → few-shot → 微调）**
   - 规则化：`生成指令.md` 铁则体系（已到二十五，人审可审计）。
   - few-shot：元件卡库按「题材 × 位置」注入示例。
   - 微调：`scripts/finetune_prep.py` 把合规语料蒸馏成续写 pair（`finetune_data/train.jsonl`，system 指令已「好懂优先」）。

4. **标点归 LLM + 零容忍门禁**
   - 标点正确性铁则写在生成主路径（`源码/kb/base-prompt.ts`），破折号零容忍，检测器 4 条确定性规则兜底。
   - 迭代铁律：任何改动不得回潮已验证能力（口语人味 / 破折号硬禁 / 0 error 门禁 / dist 同步 / 8 本好懂语料）。

## 三套 Skill（发布目录）

| Skill | 职责 |
|---|---|
| `InkWeave写作工坊` | 正文生成：写前分析 → 生成指令 → 结构卡 → 自检门禁 |
| `InkWeave大纲创作院` | 大纲 / 节奏规划：黄金三章、爽点回报间隔、反转套娃 |
| `InkWeave设定工坊` | 世界观 / 人物 / 设定沉淀，供给生成与大纲 |

Skill 自包含、不依赖对话记忆；发布后用户无我们对话上下文也能稳定出货。

```
└── docs/方案与验收/        # 方案、验收报告、拆书方法论
```

## 快速开始

### 1. 用 Skill 出章（零成本，不需 key）
在 WorkBuddy 中启用 `InkWeave写作工坊`，给大纲即生成；生成后自动过质量门禁。

### 2. 验收一章（CLI）
```bash
node 检测工具/check-chapter.ts 实战出文/压力测试/都市爽文_第01章_神级选择.md
```

### 3. 批量验收
```bash
node 检测工具/check-all.ts
```

### 4. 蒸馏语料（合规样本 → 续写 pair）
```bash
python scripts/finetune_prep.py
# 产出 finetune_data/train.jsonl + val.jsonl
```

> 引擎接真 LLM API 与微调底座属「软件化阶段」，当前默认种子即可盲写验证。

## 设计原则（与行业标杆对齐）

- 先抽象题材共性，再补题材个性
- 知识库是资产，不是聊天结果
- 拆书蒸馏是显式工程步骤，不是玄学
- 写完必过门禁，门禁才放行
- 长篇必持久化记忆（规划中）
