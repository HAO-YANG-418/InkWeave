# 高密度快节奏

> 短段落为主，段落切换频繁，信息推进快。适合爽文、战斗、追逐等快节奏场景，阅读感畅快。
> 所属节点：段落密度

## 教学指令

采用高密度短段落写法。每段尽量不超过80字，段落之间频繁切换，一个动作或一句对话即可成段。信息推进要快，每段都要有新信息或新进展，不做冗长铺垫。对话和动作交替出现，制造翻页感。减少大段心理描写和环境铺陈。

### 约束规则

- 单段不超过80字
- 每千字不少于40个段落
- 每段必须包含新信息、新动作或新对话
- 禁止超过100字的连续环境/心理描写

### 数值参数

| 参数 | 值 |
|------|-----|
| maxParagraphLength | 80 |
| targetParagraphLength | 40 |
| minParagraphCount | 40 |
| infoPointsPerThousand | 5 |

### 维度权重

| 维度 | 权重 |
|------|------|
| action | 1.3 |
| infoAdvance | 1.3 |
| sensorySignal | 0.8 |
| emotion | 0.9 |

### 冲突选项

- opt_dense_low

### 范例

**标注**：每段极短，切换快，紧迫感强。

```
他踹开门。

屋里空无一人。

桌上的茶还冒着热气。

他摸向腰间的枪。

窗户开着。

窗帘在风里飘。

楼下传来引擎声。

他冲到窗口。

一辆黑色轿车正驶出巷子。
```
