# 中等密度

> 段落长度适中（默认），兼顾节奏和信息密度。对话、动作、描写交替出现，阅读舒适流畅。
> 所属节点：段落密度

## 教学指令

采用中等密度段落写法。段落长度控制在50-120字之间，对话和动作可以单独成段，描写和叙述适当合并。保持稳定的阅读节奏，不要频繁空行制造断奏感，也不要大段堆砌文字造成阅读压力。每段有明确的焦点。

### 约束规则

- 单段不超过200字
- 每千字不少于20个段落
- 对话和动作段落简短，描写段落适中
- 避免连续3段以上纯描写无动作/对话推进

### 数值参数

| 参数 | 值 |
|------|-----|
| maxParagraphLength | 200 |
| targetParagraphLength | 80 |
| minParagraphCount | 20 |
| infoPointsPerThousand | 3 |

### 范例

**标注**：段落长度适中，叙述/对话/描写交替。

```
早上七点半，林深准时出现在矿道口。他换好了下井的工装，头灯卡在帽檐上，电池包在腰侧坠出一个沉甸甸的弧度。

老范已经在等他了，叼着根没点的烟，眉头皱得像打了结的麻绳。

「今天下七层？」林深问。

老范把烟从嘴里拿下来，看了他一眼：「你小子昨天才上来，今天又下？」
```
