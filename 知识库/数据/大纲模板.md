## 四、逐章大纲

### 标注行格式

```
[第X章] [情绪类型:温暖/疼痛/过渡] [情绪强度:1-5] [钩子:悬念/情绪/信息/选择/温暖/对话/危机] [对话:角色名列表] [顶层势力:显性-名称/隐性-现象/无] [环境:名称] [感官变奏:听觉/嗅觉/视觉/触觉] [新信息:≤2个关键词] [世界观层级:自然法则/社会结构/历史脉络/日常细节] [伏笔:大/中/小-埋/触/提/收-伏笔名] [子线:角色-节拍类型] [角色弧线:角色-六步节点] [单元:编号-引入/推进/收束] [预估字数:数字] [时间节点:标记]
```

### 标注行字段说明

| 字段 | 可选值 | 说明 |
|------|--------|------|
| 情绪类型 | 温暖/疼痛/过渡 | 本章整体情绪基调 |
| 情绪强度 | 1-5 | 1=最低沉，5=最高昂 |
| 钩子 | 悬念/情绪/信息/选择/温暖/对话/危机 | 章末钩子类型 |
| 对话 | 角色名列表 | 本章有对话戏份的角色 |
| 顶层势力 | 显性-名称/隐性-现象/无 | 顶层势力是否在本章出现 |
| 环境 | 名称 | 本章核心场景 |
| 感官变奏 | 听觉/嗅觉/视觉/触觉 | 本章突出的感官类型 |
| 新信息 | ≤2个关键词 | 本章释放的新设定/信息 |
| 世界观层级 | 自然法则/社会结构/历史脉络/日常细节 | 新信息所属层级 |
| 伏笔 | 大/中/小-埋/触/提/收-伏笔名 | 本章伏笔操作 |
| 子线 | 角色-节拍类型 | 角色支线本章节拍 |
| 角色弧线 | 角色-六步节点 | 角色弧线当前节点 |
| 单元 | 编号-引入/推进/收束 | 所属叙事单元及阶段 |
| 预估字数 | 数字 | 本章预估字数 |
| 时间节点 | 标记 | 故事时间线定位 |

### 逐章详细大纲

每章300-500字展开内容，标注行下方紧跟详细描述。
