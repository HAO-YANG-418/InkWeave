## 一、BUG② 真身与修复（代码方领地，本次已修）

- **现象**：同一章检测报告自相矛盾——基础统计表「身体锚点 92」，但锚点警告「锚点数为 0 / 密度每千字 0.0 / 2278 字无锚点段落」。
- **根因（双树锚点口径不一致）**：
  - CLI 树 `检测工具/checkers.ts:132` `computeTextStats` 用硬编码 `bodyParts` 正则宽松数身体部位名词 → 正确值 92。
  - 生成时真身 `源码/anchor-detector.ts:111` `detectAnchors` 定义「身体部位词 + 附近±10字符感官/动作动词」组合，且完全依赖 `vocab.bodyParts` 词表（:127-133 `if (bodyParts.size === 0) return count:0`）。裂日 vocabulary 未配 bodyParts 词表 → 直接返回 0。
  - 两树锚点定义/口径打架，源码树吐的 5 条「锚点 0」警告全是误报，卡在 66 不过线（5 条 warning × 4 分 = 20 分）。
- **修复**：`源码/anchor-detector.ts` 加内置 `FALLBACK_BODY_PARTS` 词表（等价 CLI 树正则），词表缺失或组合匹配为空时 fallback 到「数身体部位名词」，与 CLI 树统一。`npm run build` 重新编译 dist。
- **验证**：锚点 0→150（正确），5 条误报全消，评分 66→78。
