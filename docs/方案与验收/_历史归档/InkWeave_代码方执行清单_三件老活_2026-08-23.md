## 老活一：检测双轨（正则层 + LLM 层 + 空洞度）

依据：检测侧新规则方案（全文 7 节）。设计原则：单靠正则打不尽 AI 味（实战十章可算维度均健康），必须**双轨**；阈值必须中文网文语料标定，不能照搬英文/火山数据。

### 1.1 正则层 `check-ai-flavored-regex.ts`（低风险，先上）
- **新增文件**：`检测工具/checks/check-ai-flavored-regex.ts`
- **5 维度 + 阈值**（方案第 1 节表）：transition_density 连接词>6 warning/>10 error；cliche_density 模板句>8/>14；repetition_3gram 3-gram重复>20%/>30%（**需排除专有名词**）；punctuation_cv 标点节奏CV<0.30/<0.20；dialogue_ratio 对白%<5或>65/<3或>75。
- 连接词表/模板句表见调研报告 2.2 节。复用现有 notX/排比/破折号/碎句/比喻（已在 `checkers.ts`）。

### 1.2 LLM 层 `check-ai-flavored-llm.ts`（**治本关键**）
- **新增文件**：`检测工具/checks/check-ai-flavored-llm.ts`
- 调 InkWeave 生成模型通道（同 `pre-analysis` 用的），对本章算：`perplexity`（越低越 AI，中文需标定）、`semantic_smoothness`（相邻句 embedding 余弦>0.92 高风险）、`burstiness`；输出 `ai_flavor_score` 0–100（>70 高风险对齐朱雀 / >50 warning / ≤50 正常）。
- 复用 `prompt-builder` / `pre-analysis` 现有 LLM 调用通道。

### 1.3 空洞度 `check-emptiness.ts`
- **新增文件**：`检测工具/checks/check-emptiness.ts`
- 本地近似：概括句占比（无具体名词/动作动词、纯形容词副词堆砌）、设定解释类占比。
- LLM 层：模型评估「每屏新信息量」，每段是否推进情节/人物/伏笔（三不沾=empty）。
- ⚠️ 实证发现 5 章字数<2700 但感官密度不低 →「写空」更可能是**情节信息密度不足**，非感官词缺失，故空洞度**必须含信息层评估**，不能只数感官词。

### 1.4 接入主流程 & 反向闭环
- 改 `检测工具/checkers.ts` 主流程尾端（fingerprint 产出后）调用上述 checker，汇总 warning/error。
- warning（非 error）Top3 → 经 `warning-feedback` 注入下章禁忌（接第 1115 行跨章通道）。

## 老活二：反向闭环

依据：P0 反向闭环设计方案（全文 6 节）。目标：每章 detector 的 warning 自动变下一章生成禁忌，让引擎从 C 级往 B 级爬，不再靠人工事后扩写。

### 2.1 新增 `warning-feedback.ts`
- **新增文件**：`源码/learning/warning-feedback.ts`（纯函数 + 轻量状态读写，不依赖 LLM）。
- **导出 API**（方案第 2.1 节签名）：`extractTopWarnings(violations, limit=3)`、`buildTabooPrompt(taboos)`、`upsertTaboos(mem, projectId, chapterNumber, warnings)`、`loadNextChapterTaboos(mem, projectId, nextChapterNumber)`。
- **参数**：TOP_N=3（每章最多注入 3 条禁忌）、DECAY_WINDOW=4（超 4 章未命中权重衰减 50%）、仅 `warning`（error 由门禁卡死不需注入）。

### 2.2 改动 `源码/prompt-builder.ts` 第[4]层
- 在 `buildSystemPrompt` 的 [4] 层 `userCustomPrompt` 拼装**之后**追加 [4.5] 反向闭环注入（方案第 3.1 节代码块）。
- `BuildPromptOptions` 增加可选字段 `nextChapterTaboos?: ChapterTaboo[]`。

### 2.3 改动 `检测工具/checkers.ts` 主流程尾端
- 接**第 1115 行已有跨章通道**（非另起 `LongTermMemory`），调用 `extractTopWarnings` + `upsertTaboos`（方案第 3.2 节）。
- 在「开始下一章生成」前调用 `loadNextChapterTaboos` 传入 `buildSystemPrompt` 的 options。
- **不动**各检测器逻辑（D1–D6 已修）、**不动** `FeedbackLoop`（它仍管用户手动编辑，本闭环是平行第二根机器 warning 学习线）。

### 2.4 防副作用（方案第 4 节，必须看）
只注入 warning / Top3 上限+衰减 / 自然语言「请规避」措辞（与铁则「禁止」分层）/ 项目级隔离（裂日不串矿工）/ UI 可关（`reverseLoopEnabled` 默认 true）。

## 老活三：KB 阈值标定（中文网文语料）

依据：知识库对齐说明第三节第 3 条。
- **文件**：`源码/kb/` 下 preset 的 `threshold_overrides`（如 `infoPointsPerThousand`、`targetSentenceLength`、`maxFillerSentences`）。
- **现状**：多沿用旧值（英文/火山口径），中文 slStd 天然 15+、3-gram 重复天然 30%+，直接套会误杀。
- **动作**：收集 30+ 中文头部网文章节 + 30+ AI 生成章节，跑双轨特征做 ROC 标定；以实证十章为「治理前基线」，生成铁则（十九/二十）落地后重跑对比。
- 与老活一 1.4 / 2.3 共用同一批语料，联动标定。
