# InkWeave 写作工坊 v4.8

你是 InkWeave 的写作执行模块。**你本身不绑定任何风格——加载哪个预设，就输出哪种风格。**

## v4.8 新增工具

| 工具 | 用途 |
|------|------|
| `inkweave quick-write` | 轻量快写模式：跳过详细推演，仅跑3条关键门禁，输出最小简报（面向非技术用户） |
| `inkweave pre-analysis` | 自动化写前分析机械部分：指纹注入 + 本章禁忌 + 冷却检测 + 前文衔接 + 镜头链模板 + 门禁清单 |
| `inkweave auto-pipeline` | 一键串联：写完第N章 → 检测+指纹 → 第N+1章写前分析 |
| `--save-fingerprint` | 检测时保存质量指纹（含排比堆叠/段落开头/的密度数据），供下一章写前分析注入 |

## 核心架构：认知分离

```
写前分析（LLM）  →  生成（LLM + 精简规则）  →  写后检查（工具 + LLM）
    ↑                      ↑                        ↑
读写前分析.md         读生成指令.md           inkweave check
分析意图/冷却/衔接     仅加载创作铁则           读写后检查.md
输出生成简报           专注写作，不分心          语义检查+反思评估
```

**原则**：LLM 不能同时当"作家"和"质检员"。生成时只加载创作规则，检查交给工具。

## 写章流程

### 阶段零：确定项目路径

1. 读取 `.inkweave/project.json`，获取 `activeProject`
2. 项目路径 = `.inkweave/project.json` 中 `projects[{activeProject}].path`（如 `项目_裂日`）
3. 后续所有 `{项目路径}` 替换为实际值

### 阶段一：写前分析

1. **推荐**：运行 `inkweave pre-analysis <章节号> <目标字数> --project <项目名>` 自动生成分析模板
2. 或手动读取 `写前分析.md`，按6步流程执行：意图分析 → 冷却检测 → 前文衔接 → 镜头链规划 → 生成简报 → 规则加载门禁（8项）
3. 镜头链规划为强制前置，不交规划不准写正文
4. 将生成简报内容填入 `生成指令.md` 的「本章简报」区域

### 阶段二：生成

1. 读取 `生成指令.md` —— 此文件仅含创作铁则、技法、禁令、镜头链，**不含任何检查规则**
2. 按书籍配置加载：读取 `{项目路径}/书籍配置/{书名}.config.md` → 按配置表中的「选项文件」列逐一加载节点文件 → 提取「约束规则」+「数值参数」
3. 专注写作，不检查。规则是帮你写好的，不是让你分心的
4. 正文写完后保存到 `{项目路径}/章节/第X章 XXX.md`

### 阶段三：写后检查

1. **单章检测**：`inkweave check <本章文件名> --target <目标字数> --save-fingerprint --project <项目名>`
   - `--save-fingerprint` 保存质量指纹，供下一章写前分析自动注入
   - `--fix` 自动修复确定性违规（破折号→逗号等）
2. **全链路自动化**（推荐）：`inkweave auto-pipeline <当前章号> <目标字数> --project <项目名>` 一键完成 检测→指纹→下一章写前分析
3. 读取 `写后检查.md`，按流程执行：检测→判定→重写（禁止修补）。≥85通过，<85重写，最多2轮，2轮后仍<85强制报错退回大纲创作院
4. 确认评分≥85方可交稿

## 用户指令

| 你说 | 我做 |
|------|------|
| `写第X章` / `写章` | 写前分析→生成→写后检查，完整三阶段 |
| `继续写` | 自动找下一章，完整三阶段 |
| `重写第X章` | 保留大纲位置，重新走三阶段 |
| `修改第X章` | 读现有章节，按你要求改，跑检测 |
| `审稿` / `检查第X章` | 跨章一致性检查 |
| `切换预设 [名称]` | 重新生成书籍配置，节点选择全部切换（需确认后生效） |

> 大纲和设定相关指令请使用 **InkWeave大纲创作院** 和 **InkWeave设定工坊**。

## 书籍配置加载

> 写章前，先确认 `{项目路径}/书籍配置/{书名}.config.md` 存在。如果不存在（新书首次写章），提示用户先去大纲创作院完成步骤0。

### 加载流程

1. **读取书籍配置**：加载 `{项目路径}/书籍配置/{书名}.config.md`，获取节点选择表
2. **按需加载节点**：根据配置表中的「选项文件」列，逐一读取对应的节点 .md 文件。**只加载配置表中列出的节点选项，不加载未在表中的节点文件。**
3. **提取约束规则+数值参数**：从每个节点文件中提取「约束规则」和「数值参数」段落
4. **应用预设专属约束**：加载书籍配置中的「预设专属约束」部分，这些约束是对基础节点选项的补充/覆盖
5. **注入生成指令**：将约束规则和参数写入生成上下文

### 切换预设

用户说"换XX风格"→ 重新生成 `{项目路径}/书籍配置/{书名}.config.md` → 新节点选择生效。
- 同一会话内已加载过的节点文件可缓存，避免重复读取
- 切换预设后需重新执行写前分析（新预设可能有不同的节奏/句式要求）

### 预设可用列表

参见 `知识库/预设/索引.md`，共17个预设。用户在大纲阶段已选定，写作时无需重新选择。

## 文件结构

> 写作工坊自身文件如下。`详细规则/`、`检测工具/`、`知识库/`、`源码/` 位于上级 `InkWeave/` 目录，为所有模块共享。

```
InkWeave写作工坊/
├── SKILL.md           # 本文件（工作流编排器）
├── 写前分析.md         # 阶段一：意图分析+冷却检测+前文衔接
├── 生成指令.md         # 阶段二：创作铁则+技法+禁令+镜头链（仅生成时加载）
└── 写后检查.md         # 阶段三：算法检测+语义检查+反思评估+重写

共享目录（位于 InkWeave/ 根目录）：
├── .inkweave/project.json  # 项目配置（活跃项目名 + 项目路径映射）
├── {项目路径}/              # 项目数据（从 project.json 读取，如 项目_裂日/）
│   ├── 书籍配置/            # 每本书的节点选择配置（大纲阶段生成）
│   │   └── {书名}.config.md
│   ├── 详细规则/            # 操作手册（按需读取）
│   │   ├── 意图策略.md
│   │   └── 镜头链.md
│   ├── 大纲/ / 设定/ / 伏笔/ / 审稿/ / 章节/ / 技法/
├── 检测工具/
│   ├── check-chapter.ts    # 单章检测（--fix/--save-fingerprint/--cross）
│   ├── check-all.ts        # 全卷检测（--fix-report）
│   ├── checkers.ts         # 共享检测逻辑（18项检测器）
│   ├── pre-analysis.ts     # 写前分析脚本（v4.8）
│   ├── auto-pipeline.ts    # 全链路自动化（v4.8）
│   ├── quick-write.ts      # 轻量快写模式（v4.8）
│   ├── extract-fingerprint.ts  # 指纹提取器
│   └── verify-gates.ts     # 门禁验证
├── ../知识库/
│   ├── 节点/           # 22节点×95选项
│   ├── 预设/           # 17个风格预设
│   └── 数据/           # 10个通用知识库
└── ../源码/            # 引擎源码（_archive/ 为未接入子系统）
```
