# 冷却模式库

> 定义哪些写法/情节/角色模式需要冷却，冷却多久，变体有哪些

共 54 个冷却模式。

## 开篇模式（冷却5章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 眼中精光一闪式开篇 | 眼中精光一闪、眼中闪过一丝精光、双目精光一闪... | 用一个具体行为开场：推门/握拳/起身/看向某处 |
| 深吸一口气式开篇 | 深吸一口气、长长地吐出一口浊气、缓缓吐出一口气 | 从环境/声音/动作开场，不用呼吸描写 |
| 此刻的XX式开篇 | 此刻的、此时的、眼下的 | 直接写角色在做什么，不用"此刻"标记 |
| 话音刚落式开篇 | 话音刚落、话音未落、话音落下 | 直接写下一个动作/反应，不用"话音刚落"过渡 |
| 清晨醒来式开篇 | 清晨、天刚亮、翌日清晨... | 跳过日常流程，从当天第一个事件/异常写起 |

## 战斗描写（冷却3章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 一拳轰出 | 一拳轰出、一拳砸出、一拳打出... | 写拳头的轨迹/力量/风声/击中效果，不用"一拳XX出" |
| 气势暴涨 | 气势暴涨、气势大盛、气势陡然攀升... | 写气势变化的具体表现：空气震动/地面龟裂/衣袍猎猎 |
| 脸色大变 | 脸色大变、脸色骤变、面色大变... | 写具体的面部反应：血色褪尽/青筋暴起/嘴唇发白 |
| 倒飞出去 | 倒飞出去、倒飞而出、暴退数步... | 写飞出去的具体过程：脚离地/撞碎什么/滚了几圈 |
| 轰的一声 | 轰的一声、轰然巨响、一声巨响... | 写声音的具象：地面震裂声/空气爆鸣声/骨骼碎裂声 |
| 化为残影 | 化为残影、化作残影、身形一闪... | 写速度的具象：只看到模糊的线条/风先到人后到 |

## 装逼打脸（冷却5章）

| 不知死活 | 不知死活、找死、自寻死路... | 写对手的具体反应：冷笑/出手/不屑一顾 |

## 转折信号（冷却2章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 然而 | 然而、但是、可是 | 用事件因果转折，不用转折词 |
| 就在这时 | 就在这时、就在此时、正在这时... | 直接写发生的事，让事件本身制造转折 |
| 他不知道的是 | 他不知道的是、殊不知、他尚未意识到... | 删掉，让读者和角色一起发现 |
| 意外的是 | 意外的是、出乎意料、出人意料 | 直接写意外发生的事，不用"意外的是"预告 |

## 对手原型（冷却8章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 嚣张富二代/少爷 | 少爷、公子、纨绔... | 设计不同类型的对手：阴险型/隐忍型/疯癫型/理想型 |
| 阴险长老/前辈 | 长老、前辈、老夫... | 设计不同年龄/身份的对手：同龄天才/神秘强者/体制对手 |
| 傲慢天才 | 天才、第一、百年难遇... | 设计有实力但不同性格的对手：沉默型/狂热型/理性型 |
| 伪善君子 | 道貌岸然、伪君子、表面仁义... | 设计动机更复杂的对手：被迫型/信念型/利益型 |
| 嫉妒同门 | 嫉妒、凭什么、不甘心... | 设计有不同动机的同辈对手：竞争型/误解型/立场对立型 |

## 对话套路（冷却4章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 你根本不懂式对话 | 你根本不懂、你不明白、你永远不会理解... | 用行为展示不理解：摇头/转身/沉默，替代台词喊出来 |
| 冷笑反问式对话 | 冷笑一声、冷笑道、嗤笑... | 用微表情/动作传达轻蔑：眼角微抬/手指敲桌面/视线偏移 |
| 发誓赌咒式对话 | 我发誓、我对天发誓、若违此誓... | 用行为/决策展现决心，不用口头发誓 |
| 嘲讽重复式对话 | 就凭你、就你、你也想... | 写对手的漫不经心：继续做自己的事/不看对方/随手一挥 |
| 设定灌输式对话 | 你知道吗、让我告诉你、其实事情是这样的... | 通过角色争论/质疑/误解来自然带出设定，不用一人说教 |

## 心理描写套路（冷却3章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 握拳暗誓式心理 | 暗暗发誓、握紧双拳、心中暗想... | 写决心后的第一个行动，用行动代替心理独白 |
| 脑中闪过式心理 | 脑海中闪过、脑中浮现、脑海中掠过... | 直接写角色做了什么决策/动作，不写思考过程 |
| 复杂情绪标签式心理 | 说不清的感觉、复杂的眼神、难以言喻... | 写一个具体的微表情或动作来暗示复杂情绪 |
| 恍然大悟式心理 | 恍然大悟、猛然醒悟、顿时明白... | 写领悟后的行为变化，不用"恍然大悟"标签 |
| 天人交战式心理 | 天人交战、心中挣扎、两个声音在脑海... | 写角色在犹豫中的无意识行为：来回踱步/反复拿放东西 |

## 环境描写套路（冷却4章）

| 名称 | 触发词 | 替代写法 |
|------|--------|----------|
| 死寂式环境 | 死一般的寂静、死一般的沉寂、空气仿佛凝固... | 写具体的安静：能听到自己的心跳/远处的虫鸣/风穿过缝隙的声音 |
| 压抑氛围式环境 | 压抑、令人窒息、喘不过气... | 写具体的环境细节传达压迫感：低矮的天花板/昏暗的灯光/狭窄的通道 |
| 寒风呼啸式环境 | 寒风呼啸、冷风刺骨、寒风凛冽... | 写风对具体事物的影响：衣角翻飞/沙石打脸/火把摇灭 |
| 月色如水式环境 | 月色如水、月光倾泻、银色的月光... | 写月光照在具体物体上的效果：地上投下的影子/水面反射的光斑 |
| 宏大叙事式环境 | 一眼望不到头、无边无际、广袤无垠... | 用具体参照物展现空间尺度：走到中间花了半天/抬头看不到顶 |

## 情节模板（冷却8-12章）

| 名称 | 冷却 | 典型步骤 | 变数建议 |
|------|------|---------|---------|
| 装逼打脸 | 10章 | 被看不起→隐忍→展示实力→全场震惊 | 打脸后引发更大麻烦/对方有后台/赢了但付出代价 |
| 拍卖会 | 12章 | 进入拍卖场→竞价→主角截胡→得罪竞拍者 | 拍到的东西有问题/拍卖行有阴谋/买不起想要的东西 |
| 比赛/比武 | 12章 | 抽签→遇强敌→苦战→突破→晋级 | 输了但有收获/比赛被打断/对手放水有目的 |
| 奇遇/宝物 | 10章 | 陷入绝境→意外发现入口→获得宝物→实力大增 | 宝物有代价/传承不完整/获得的是信息不是力量 |
| 英雄救美 | 8章 | 遇危难→出手相救→被救者感恩→建立关系 | 救的人是敌人卧底/救援失败但获线索/被救者更强 |
