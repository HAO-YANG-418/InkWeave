## 〇、先回应"他们是不是抄我的" —— 结论：不是，是殊途同归

### 0.1 事实证据（三条，条条硬）

1. **我们的项目是本地私有项目，从未发布。** InkWeave 一直在你本机 `C:/Users/admin/Desktop/写作引擎产品/InkWeave/`，没上 GitHub、没进任何市场。一个私有本地仓库，**物理上无法被他人抄袭**。
2. **那些公开 skill 是独立仓库、各有作者与历史。** Lorn.NovelWriteSkills（作者 lornshrimp，185★，最后更新 2026-08-09）、awesome-novel-skill（coolair01，517★）、xt-webnovel-writing（OpenClaw）、webnovel-writer（5315★）都是公开 repo，有自己的提交史、star、维护者。它们早于或平行于我们这轮工作，不可能引用一个私有项目。
3. **我是这一轮才用 WebSearch 发现它们的，它们没参与我们早期设计。** InkWeave 的核心架构（认知分离 / 22 节点 / 双树 / 破折号零容忍 / 铁则体系）是在 09-01～09-04 你的多次纠正里一步步长出来的，跟这些公开库无关。我搜它们只是为了**对标Benchmark**，不是抄来当方案。

### 0.2 那你为啥"感觉像抄的"——因为撞上了行业公约数

2025–2026 的 AI 写作 agent 领域，几个模式是**公认的工程常识**，谁做谁都会落到这：

| 公约数（大家都这么干） | 我们叫法 | 他们叫法 |
|------------------------|----------|----------|
| 生成与质检分离 | 认知分离（写前/生成/写后） | Lorn 门禁脚本 / awesome 审阅闭环 |
| 写完必过门禁 | 检测 18 项 + 破折号零容忍 | Lorn 字数/质量/相似度/反注水 |
| 把"学爆款"当工程步骤 | 蒸馏（finetune_prep） | Lorn 蒸馏三件套（文风DNA/蓝本DNA/写作研究） |
| 长篇不忘前文 | 指纹 + 伏笔台账（规划中） | awesome `.claude/knowledge/permanent-memory` |
| 通用能力 + 题材个性分开 | 节点/预设 | Lorn CommonSkills + 题材目录 |

**这不是抄，是同一个问题域里最优选法的收敛。** 你感觉"像我的"，恰恰说明我们独立走出的架构方向，和业界最强实践对上了——这是好事，证明路没走歪。

### 0.3 但 InkWeave 有他们没做到的硬差异化（这才是我们的壁垒）

| 我们独有 | 说明 | 公开 skill 缺什么 |
|----------|------|-------------------|
| **22 节点 × 95 选项可调风格系统** | 加载预设即换风格，不绑死模型 | 多数只有 Prompt 模板，无"风格维度拆解+组合" |
| **双树架构（检测工具/ + 源码/）** | 防两棵树检测口径分裂，merge 去重标注 | 单树，口径矛盾靠人肉发现 |
| **破折号零容忍 + 标点铁则归 LLM** | 14 条确定性规则 + 生成端铁则，不依赖 key | 普遍只"反AI味"粗糙过滤 |
| **铁则体系（到二十五）** | 口语人味 / 去冷峻 / 回看反转 / 开篇四拍 / 多题材母题，是人审可审计的 craft 沉淀 | 多为 Prompt 片段，无体系化铁则层级 |
| **好懂优先元规则（治根因）** | 直接打"文学极简误当写作好"这个根因 | 多数默认追"文学性"，反而踩我们踩过的坑 |
| **迭代铁律（别倒退能力）** | 每次改动复跑对照章，能力不许回潮 | 无此约束，易越改越差 |

> **结论**：方向重合 = 收敛验证；实现差异化 = 我们的壁垒。最终方案站在"公约数（已被验证正确）+ 我们的差异化（更狠更可审计）"之上，不抄谁、也不怕被抄。

## 一、根因与架构决策（已锁定，不可动摇）

- **根因**：引擎把"文学极简 / 克制 / 留白 / 低逗句比"误当"写作好"，逼出晦涩碎句，与网文"好懂直白"核心诉求相悖。
- **架构决策**：skill 烂 → 走微调；微调必须与 prompt / 检测器两侧**同步迭代**；语料只用热门网文（好懂直白），**禁用文学小说**。
- **验证口径**：好懂 = 唯一硬标准 > 文学性（已固化为 base-prompt 元规则）。

---

## 二、标点归 LLM（已锁定）

- 标点本就在生成端：`base-prompt.ts` 标点铁则 + `checkers.ts` 4 条确定性规则 + 破折号零容忍。
- **不依赖你给 key**；真 LLM 跑量也走 workbuddy 真加载底座，零成本。

---

## 三、书库零操作用户自建（已锁定）

- 路径一（零成本·合规）：agent 用公开试读 + 原创合成样本填充 `corpus/`，跑通 `finetune_prep.py` 出 jsonl。已落地 9 pair。
- 路径二（非阻塞）：你授权正版 txt 全量 → 接微调底座。不授权也能出货。

## 四、知识库搭建：拆书驱动元件卡库（核心方案）

### 4.1 拆书 = 偷框架，不抄剧情（四层）

| 层级 | 拆什么 | 产物 | 来源合法性 |
|------|--------|------|-----------|
| L0 母题 | 核心冲突 / 爽点类型 / 价值主张 | 母题卡 | 公开研究（合法） |
| L1 桥段 | 可复用模板（退婚打脸/系统觉醒/金手指首秀） | 桥段卡 | 公开研究（合法） |
| L2 章法 | 章首钩子公式 / 章末钩子轮换 / 回报间隔 / 节奏分布 | 章法卡（=作品蓝本DNA） | 目录+试读+公开研究（合法，**不需全文**） |
| L3 句法 | 金句 / 感官白描 / 对话 beat 范式 | 句法卡（=作者文风DNA） | **需原文→路径二授权** |

> **关键判断**：L0–L2 结构级拆书从目录 + 公开试读 + 公开研究即可合法零成本推断，**你"不买书不操作"也能做真拆**；只有 L3 句法级等授权。

### 4.2 KB 四层架构

```
知识库/
├── 通用层/      # 跨题材铁则、通用桥段、通用章法
├── 题材层/      # 都市/玄幻/悬疑/电竞/灵异…每题材一套包装（=Lorn 题材目录）
├── 元件卡库/    # ★拆书产物 L0–L3，按母题/桥段/章法/句法组织
└── 门禁层/      # 检测工具/ 18 项 + 反AI味 + 相似度（已有）
```
节点系统控"怎么写"（风格），元件卡控"写什么结构"（骨架）——**二者正交**。

## 五、蒸馏三档（落点）

| 档 | 做法 | 成本 | 状态 | 决策 |
|----|------|------|------|------|
| 规则化（铁则） | 拆书规律→铁则/节点 | 零·可审计 | ✅ 到二十五 | 继续，L0–L2 人审固化 |
| few-shot 示例库 | 真拆片段按题材×位置注入 | **零·未做** | ❌ 缺口 | **优先补** |
| 微调底座 | finetune_prep→换底座 | 算力/授权 | ⚠️ 9 pair | 软件化阶段 |

**落点权重**：铁则 + few-shot 先跑（稳·零成本·可审计），微调治本但需算力，不阻塞出货。

## 七、分阶段路线图 + 唯一阻塞

- **P1 结构级拆书（零成本·路径一）**：对 8 本跑 L0–L2，产 `元件卡库/` 母题+桥段+章法卡。
- **P2 few-shot 注入**：写前分析按题材×位置调卡，生成指令增结构卡；跑 3 章验证 B+ 不倒退。
- **P3 持久化记忆**：伏笔台账 + 前文衔接自动注入。
- **P4 题材层包装**：都市/玄幻/悬疑/电竞/灵异各一套包装层。
- **P5 微调底座（路径二·需授权）**：授权正版 txt → 补 L3 句法卡 → finetune_prep 放量 → 换底座。

**唯一真阻塞**：路径二授权（不授权也能走 P1–P4，仅 L3 句法级暂缓）。
**非阻塞待定**：要不要上 RAG 向量检索（先用确定性加载+few-shot，卡库>50 张再评）。

## 八、迭代铁律 / 验收口径（不可破）

1. **别倒退能力**：每阶段复跑对照章（玄幻/都市/历史）确认仍 0 error + 口语人味不丢，才推进。
2. **双树同步**：改 `源码/kb/**` 必 `npx tsc` + grep 补丁串验证 dist。
3. **好懂优先**：任何新增铁则/节点不得回灌"冷峻极简=高级"。
4. **版权红线**：L3 前不碰全文/盗版；路径二须你授权。

## 九、一句话总结

根因（文学极简误当写作好）已锁定 → 架构（skill+微调同步、语料只热门网文）已定 → 标点归 LLM 已固 → 书库零操作已闭环 → **KB 用拆书驱动元件卡库升级（L0–L2 合法零成本先跑）** → 蒸馏走铁则+few-shot+微调三档 → 不阻塞出货，路径二授权后补 L3 句法级。方向撞车业界最强实践＝收敛验证，实现差异化（双树/22节点/破折号零容忍/铁则体系/好懂元规则）＝我们的壁垒。
