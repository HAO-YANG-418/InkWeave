# InkWeave P0 去均匀腔 · 验收报告（v5.0 → v5.1）

> 验收时间：2026-08-21
> 目标：消除检测层与生成层的"均匀腔"——即每章都用同一批套路（破折号硬禁导致千篇一律、感官只走非视觉三选一、质感词循环）造成的新型 AI 味。
> 结论：**验收通过**。单测全绿（43/43），真实第16章《共振》零回归（93/A 零 error）。

---

## 一、问题回顾（为什么要做 P0）

P1/P1.5 把长程一致性补齐后，实战暴露出新的均匀腔风险：

1. **破折号硬禁（error 级）** → 生成端彻底不敢用破折号，每章节奏一模一样，"太干净反而没个性"，成为新套路。
2. **感官基调只限非视觉三选一**（触觉/听觉/嗅觉）→ 章节间感官分布雷同，制造不出卷间起伏。
3. **质感词无约束** → 身体感受词容易"凉/麻/颤"循环，每章都用同一批，形成均匀腔。

P0 不改变已验证有效的长程一致性（P1/P1.5）与表层去 AI 味能力，只在"去均匀腔"维度做收口。

## 二、改动清单

### 2.1 检测端（checkers.ts）

| 项 | 旧行为 | 新行为 |
|----|--------|--------|
| 破折号 | `——` 一律 `forbidden_char` error 硬禁 | 拆出 `forbidden_char_dash`：**≤2 处不报**；>2 处报 **warning**（破格额度），仍建议收敛 |
| 质感多样性 | 无 | 新增 `checkTextureVariety`：连续 2 句同质感词且全章≥3次，或某质感词全章≥6次且超过其余总和 → `texture_variety` warning |
| 聚合 | — | `checkChapter` 内接入 `...checkTextureVariety(text)` |
| 版本号 | 报告头 v5.0 | 统一 v5.1 |

### 2.2 写前分析端（pre-analysis.ts）

- `dominantSense` 从 `['触觉','听觉','嗅觉']` 非视觉三选一 → 改为五感 `['视觉','听觉','触觉','嗅觉','味觉']` 按章号 `%5` 轮换。
- 注入文案改为："本章感官基调 = 某感（可主导分布）；每场景至少 1 处非基调感官。视觉占比不强制 ≤45%。"
- 第 509 行 `injectFingerprint` 内重算 `dominantSense`，避免作用域漂移。

### 2.3 生成指令端（InkWeave写作工坊/生成指令.md）

- **铁则八 · 感官基调起伏**：改为"五感皆可主导，可>45%，但每 200-300 字至少一次非基调感官触发，禁止单一感官全程霸权"。
- **铁则十二 · 破折号破格额度**：零容忍 → ≤2 处额度（第 3 处起用逗号替代，>2 报 warning）；明确"完全零破折号反而显太干净没个性"。
- 顶部禁用清单：破折号从 error 级硬禁改为额度说明；新增"质感多样性禁用（凉/麻/颤循环 warning）"。

## 三、测试修复与工程收口

1. **旧破折号单测**（原断言 `forbidden_char` error）→ 改为验证破格额度：≤2 不报、>2 报 warning。
2. **P1.5 mock 测试清理失败**：`fs.unlinkSync` 经 WorkBuddy safe-delete shim 拦截抛错阻断 `finally` → 改为 `fs.rmSync(cfgPath, { force: true })` 包 try/catch 静默清理。
3. **新增 vitest.config.ts**：`include` 限定 `检测工具/**/*.test.ts`、`exclude: ['dist/**']`，避免 vitest 同时跑 src 与 tsc 编译产物造成重复失败。
4. **新增 P0 单测 4 项**：破折号额度边界、质感密集抓取、质感分散不误杀、五感轮换逻辑。

最终：`npx tsc` 通过；`npx vitest run` → **43 passed / 0 failed**。
