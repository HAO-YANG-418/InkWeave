# 网文专属补充

> 网文专属填充词模式，在标准阈值基础上，将网文特有套路句纳入填充词检测范围（如“天地异象”“威压笼罩”“道音隆隆”等过度使用的网文固定句式），但保留网文中必要的节奏词。
> 所属节点：填充词

## 教学指令

你使用网文专属填充词检测模式。网文有自己独特的套路和句式，其中一些已经被过度使用到变成了纯粹的填充——比如“天地异象”“威压笼罩”“道音隆隆”“气势暴涨”“一股恐怖的气息”等等。这些词第一次用很有气势，但一章出现三次就变成了水字数。这个模式专门针对网文套路词进行检测，在保留网文风格的同时避免过度套路化。常见的网文填充套路包括：反复描写气势/威压（每打一架就“恐怖气息肆虐”）、万能围观反应（“所有人都惊呆了”“倒吸冷气”）、过度感叹（“太强了！”“这怎么可能！”）、重复强调（“他的实力远超想象”“比想象中还要强”反复说）。

### 约束规则

- 在标准阈值基础上，额外检测网文特有套路填充
- 气势/威压描写每场战斗不超过2次
- “天地异象”“道音隆隆”等大场面词每10章最多出现1次
- “所有人都惊呆了”“倒吸冷气”等围观反应每章不超过1次
- 禁止连续使用感叹句表达震惊（“太强了！”“这不可能！”“天哪！”连用）
- “气势暴涨”“气息爆发”等升级描写每次突破只写1次
- 允许使用网文节奏词和必要套路，但要节制

### 范例

**标注**：网文专属模式：将过度使用的网文套路词（天地异象/道音隆隆/恐怖如斯等）标记为填充，但保留必要的节奏词，避免套路堆砌

```
【网文填充-过度套路】
他身上爆发出一股恐怖的气息，威压笼罩全场，天地异象频发，道音隆隆，霞光万道，瑞气千条。所有人都惊呆了，纷纷倒吸一口冷气。太强了！这怎么可能！他的实力竟然恐怖如斯！

【修改后-适度使用】
他突破了。
气息从他身上扩散开来，周围的人不自觉地后退了几步。
```
