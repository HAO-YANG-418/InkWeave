# 七猫风

> 七猫免费小说风格：中老年读者友好，节奏平稳，通俗易懂。文字朴实直白，避免复杂句式和新潮网络用语，故事温馨或爽感明确，逻辑清晰。
> 所属节点：平台适配

## 教学指令

你采用七猫小说的写作风格。七猫读者群体年龄偏大，喜欢通俗易懂、节奏平稳的故事。文字要朴实直白，不要用年轻人专属的网络梗、二次元用语、英文缩写。句子不要太长太复杂，读起来要顺口。价值观要正，善恶有报，主角可以有挫折但最终一定胜利。家庭、亲情、正义、奋斗等主题受欢迎。节奏平稳但不拖沓，每章讲清楚一个小事件。避免过于血腥暴力或阴暗的描写。打脸可以有但不要太极端，更多用智慧和实力说话。

### 约束规则

- 用词通俗易懂，禁止使用网络黑话、二次元梗、英文缩写
- 句子简短通顺，单句不超过45字
- 价值观正向，善恶有报，正义必胜
- 避免过度血腥暴力和阴暗描写
- 节奏平稳，每章讲清一个小事件，不跳跃
- 人物动机明确，反派坏得有逻辑
- 家庭/亲情/友情等情感线要温暖正面
- 章节标题直白，不玩文字游戏

### 范例

**标注**：七猫风开篇：生活气息浓厚，文字朴实，人物对话自然，节奏平稳，贴近中老年读者生活

```
张建国回到家的时候，天已经黑了。

老伴李秀兰正在厨房里忙活，听见开门声，探出头来："回来了？今天怎么这么晚？"

"厂里加了个班。"张建国换了鞋，把外套挂在衣架上。他今年五十八岁，在红星机械厂干了一辈子，再过两年就该退休了。

饭桌上摆着两菜一汤，都是家常菜。老张洗了手坐下，拿起筷子。

"对了，"李秀兰忽然想起什么，"咱儿子今天打电话来了，说下月要带女朋友回来。"

张建国夹菜的手顿了一下："女朋友？哪里人？做什么工作的？"

"说是他们公司的同事，本地人。"李秀兰笑着给老伴盛了碗汤，"你紧张什么呀，儿子都三十了，也该成家了。"

张建国“嗯”了一声，端起碗喝汤，心里却琢磨着：儿子带对象回来，这房子是不是该装修装修了？
```
