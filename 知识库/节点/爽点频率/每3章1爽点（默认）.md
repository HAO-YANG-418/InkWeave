# 每3章1爽点（默认）

> 每3章一个大爽点，这是爆款网文的平均节奏。张弛有度，铺垫充分，爽点爆发时更有冲击力。
> 所属节点：爽点频率

## 教学指令

你采用每3章一个大爽点的节奏模式，这是经过市场验证的爆款平均节奏。基本节奏为：第1章铺垫（设局/埋线索/制造压力），第2章发展（矛盾升级/危机加深/主角蓄力），第3章爆发（爽点释放/打脸反转/实力展现）。大爽点之间可以穿插小爽点或小钩子保持读者兴趣，但核心爽点必须在3章内兑现。铺垫章节要有足够的信息量和张力，不能变成水字数。发展章节要让压力递增，让读者期待爆发。爆发章节要写足，爽点要写透，不能一笔带过浪费前面的铺垫。

### 约束规则

- 每3章必须有一个大爽点（打脸/逆袭/升级/揭秘/反转等）
- 铺垫章（第1章）：设局、埋线索、制造压力，必须有信息量
- 发展章（第2章）：矛盾升级、危机加深、主角蓄力，节奏渐紧
- 爆发章（第3章）：爽点释放，写足写透，给读者强烈满足感
- 大爽点之间可以穿插小爽点/小钩子，但不能替代大爽点
- 铺垫禁止水字数，每段都要为后续爽点服务
- 爆发章的爽点必须呼应前面2章的铺垫，形成完整闭环

### 范例

**标注**：每3章1爽点：第1章铺垫（抽到强敌/获得传承），第2章发展（节节败退/蓄力等待），第3章爆发（一招制敌/全场震惊）

```
【第1章-铺垫】
赵无极在宗门大比的抽签仪式上抽到了一号签，对手是内门排名第三的李天豪。所有人都觉得他必输无疑——李天豪已经是凝气九重，而赵无极只是凝气五重。

"赵无极，你自己认输吧，免得受伤。"李天豪居高临下地说。

赵无极没有说话，只是握紧了拳头。没人知道，他昨晚在禁地意外获得了上古传承，修为一夜之间突破到了凝气七重，而且还学会了一招绝学。

【第2章-发展】
比赛开始，李天豪一上来就下狠手，招招致命。赵无极节节败退，看起来岌岌可危。

"就这点本事也敢参加大比？"李天豪冷笑，一掌拍向赵无极胸口。

台下议论纷纷，都觉得赵无极撑不过十招。连裁判都准备随时终止比赛。

然而没人注意到，赵无极的嘴角微微上扬——他在等，等李天豪使出那招他早已看穿的破绽。

【第3章-爆发】
李天豪大喝一声，使出了绝招“裂山掌”，掌风呼啸，空气都被压缩得发出爆鸣。

就是现在！

赵无极脚步一错，以一个不可思议的角度避开掌风，同时右手并指如剑，一指戳在李天豪肋下三寸——那是他刚才观察到的真气运行破绽。

"噗！"

李天豪如遭雷击，整个人倒飞出去，重重摔在擂台边缘，一口鲜血喷出。

全场死寂。

"怎么可能？！"

"他一招就击败了李天豪？！"
```
