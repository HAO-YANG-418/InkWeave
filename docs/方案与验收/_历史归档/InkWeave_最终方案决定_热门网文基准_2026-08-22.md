# InkWeave 最终方案决定 · 去 AI 味与内容充实化（热门网文基准版）

> 版本：v1 最终决定（2026-08-22，基于「优秀网文范式 + 朱雀类检测逻辑 + 十章实证基线 + 热门优质网文基准」四源合参）
> 定位：本文件是**锁定的最终方案**，不是又一版探索草稿。后续只做「按本方案落地 + 实测调参」，不再重开方向辩论。
> 核心前提（用户拍板）：**《裂日》只是测验载体，目标是把 InkWeave 写作引擎 skill 本身练强；小说写得好不好是探针，不是目的。**

---

## 0. 用户真实需求（经多轮追问确认，置信度 ≥95%）

1. **AI 写的文有明显特征（AI 味），要去掉**——不是改 D1–D6 那种表面痕迹，而是从生成源头就让文字像人写。
2. **字数不够是"内容问题"不是"判定问题"**——用户原话："内容写丰富了怎么会字数不够"。所以 D4 门禁**不放开**，靠生成侧把内容写充实，字数自然达标。
3. **想源头治理，但觉得很难**——承认比"写完挑错"难一个量级，但路径明确：调研→写铁则→实测→看 AI 味/字数→调铁则，迭代推进。
4. **调研以热门优质网文为标杆，别把 AI 灌水网文当正面样本**——AI 文只作"反面教材"看一眼，用于对标本质。

---

## 1. 调研结论（四源合参）

### 1.1 取样标杆（合规：人类作者 + 真实读者 + 平台爆款）
- **平台机制**：起点/番茄榜单规律——黄金三章（300 字内抛冲突、第二章解锁金手指、第三章小逆袭）、3-5-10 节奏（每 3-5 章小爽点、10 章中反转、20-30 章大高潮）、章末钩子（"门开了，门外站着本该已死的人"）。
- **大神方法论**（均人类作者，非 AI）：
  - 猫腻：**人设 > 文笔**，正面人设带瑕疵、反派有软肋。
  - 烽火戏诸侯：**画面感 + 留白**，写情绪用生理反应/细微动作，不堆形容词。
  - 会说话的肘子：**情绪价值是第一生产力**，压抑+翻盘=极致爽感、铺垫+拉扯=持续勾欲。
  - 爱潜水的乌贼：**开篇三章定生死**（入戏/立人/抛悬念）。
  - 愤怒的香蕉：**套路是骨架、细节是灵魂**，融入自我认知避免千人一面。

### 1.2 直接用于引擎的基准（B 类，正面）
| 编号 | 基准 | 对引擎的意义 |
|------|------|------|
| B1 | 信息密度优先：每段都得有货（冲突/人物/钩子/情绪），水段落读者直接快进 | 治"写空"——不是加字数，是每段有信息 |
| B2 | 章末钩子（强制） | 每章结尾留未解悬念，不得平淡收尾 |
| B3 | 情绪线（强制）：每章情绪起伏，复合情绪优于单一 | 治"AI 顺滑无灵魂" |
| B4 | 画面感/Show-don't-tell：用生理反应/动作/双感官写情绪，不堆形容词 | 治"正确废话" |
| B5 | 留白：不把情绪/真相/心理全说透 | 治"解释腔" |
| B6 | 人设自洽带瑕疵：主角有缺点，配角不工具人 | 治"纸片人/龙傲天" |
| B7 | 长短错落 + 短句冲击：铺垫长句拉弓、转折短句放箭 | 治"均匀流水" |

### 1.3 反面教材（C 类，仅对标，不作正面基准）
> 数据来源：AI 网文读者 survey（超 62% 拒看）、华东师大《天命使徒》案例、番茄 AI 签约文分析。这些**明确是 AI 灌水产物，只用于反推"不要长什么样"**。

| 编号 | AI 泔水特征 | 典型样本 |
|------|------|------|
| C1 | 正确的废话：抽象名词+情绪动词堆砌，无具体触感 | "他感到一股无名的怒火从心中升起""脸上洋溢出喜悦的笑容" |
| C2 | 均匀填充/注水：AI 不懂省略，均匀摊字数凑数 | 三句话能讲完的事水三章；从客厅走到厨房写八百字心理活动 |
| C3 | 上下文失忆：人名/设定前后矛盾 | 第三章"赤焰剑"、第五章变"寒霜刃"；凭空冒出"暗月神教" |
| C4 | 同质化套模板 | "双目赤红捏碎翡翠茶杯""暴雨中撕碎婚书"；退婚/重生/系统三重必选 |
| C5 | 情感密度不足：模仿情绪但不理解 | 写得出"难过"，写不出"那种难过"；语义过顺、低 perplexity |

### 1.4 实证校正（上一轮已跑，本次沿用）
- 我方十章在可算维度（连接词/模板句/句长方差/词汇多样性）**健康** → AI 味在**模型层（C5 语义过顺）**，本地正则算不出。
- **结论：检测侧必须双轨（正则层抓 C1-C4 + LLM 层抓 C5），不能只做正则。**

## 2. 范式升级：从"挑错"到"像人写"

| 维度 | 旧范式（D1–D6） | 新范式（本方案） |
|------|------|------|
| 时机 | 写完挑错 | 生成源头教 AI 像人写、写充实 |

| 检测 | 表面痕迹正则 | 双轨：正则(C1-C4) + LLM(C5) |
| 闭环 | 无 | warning 自动注入下章禁忌 |

## 3. 最终生成侧铁则（已落 `InkWeave写作工坊/生成指令.md` 十九/二十，本次按基准升级）

**铁则十九 · 内容密度（治"写空"·热门网文基准）**
- 字数不够=内容没铺够，不是判定问题。
- 动笔前列 3–5 个「必须落地的具体信息点」，写时逐一铺陈，禁止概括式叙述空转。
- 每段承担至少一项：推进冲突 / 展示人物 / 给钩子 / 给情绪。
- **章末钩子（强制）**：每章最后 80–120 字留未解悬念/危机/反转。
- **情绪线（强制）**：每章情绪起伏，用「压抑→翻盘」或「铺垫→拉扯」弧线。
- 双感官铺陈（触觉/嗅觉最易漏）；镜头远景→中景→特写；写情绪用生理反应不堆形容词。
- 留白：不把情绪/真相说透。

**铁则二十 · 去 AI 味写作（打破顺滑·热门网文基准）**
- **禁"正确的废话"**：写情绪不写形容词，禁止"感到无名的怒火"类万能模板，写动作/生理反应。
- 制造语义跳跃（人类写作有断层，不必每段丝滑）。
- 注入主观性与具体经验；逻辑转折口语化（但/可/说到底）。
- 句式长短错落；人设自洽带瑕疵（主角可怂/犯错，反派有苦衷）；禁正确但空洞的总结句。

## 4. 最终检测侧规则（双轨，给代码方落地）

### 4.1 正则层（可本地算）
| 检测器 | 抓什么 | 对应基准 |
|------|------|------|
| `D-EMPTY` 正确废话 | "感到/涌起/洋溢 + 情绪名词"模板 + 抽象名词密度超阈 | C1 / B4 |
| `D-FLAT` 均匀填充 | 段落信息密度低且均匀（无冲突/钩子/情绪起伏的大段叙述） | C2 / B1 |
| `D-CLICHE` 同质化套模板 | 固化搭配（"双目赤红捏碎X"等）高频出现 | C4 |
| `D-CONT` 上下文失忆 | 人名/设定前后矛盾（需跨章状态） | C3 |

### 4.2 LLM 层（必做，治本）
| 检测器 | 抓什么 |
|------|------|
| `D-SMOOTH` 语义平滑/低 perplexity | 接 LLM 算困惑度与语义顺滑度，抓 C5 模型层 AI 味 |

### 4.3 口径（锁定，不与本方案冲突）
- **D2 = 方案 B**（已落：≥3 处 error，1–2 处 warning）——用户拍板。
- **D4 <2700 = error**（不放开）——字数达标靠密度自然消除，不是调门禁。

---

## 5. D4 定调（明确，避免反复）
**不放开 D4 阈值。** 用户已确认"字数不够是内容问题"。新铁则十九（信息密度/每段有货/双感官/章末钩子）落地的直接效果就是字数自然达标——因为把每段写充实后，2700 字是水到渠成，而非凑数。若某章仍 <2700，说明内容密度没达标，应回炉补信息点，不是降门禁。

## 6. 反向闭环（接 `检测工具/checkers.ts` 第 1115 行跨章通道）
- 每章跑完提取 warning Top3（ruleId）→ 转自然语言禁忌 → 持久化 → 下一章生成注入第[4]层 `userCustomPrompt`。
- 只注入 warning、不注入 error；项目级隔离；UI 可一键关。
- 不耦合现有 `FeedbackLoop`（它只吃手动编辑）。

## 9. 一句话总结
**让 AI 像热门人类网文作者那样写：每段有货（信息密度）、用生理反应写情绪（画面感）、章末留钩子、每章有情绪弧线、人设带瑕疵——字数达标是这些的自然结果，不是门禁放水的奖励。检测侧用"正则抓表面泔水 + LLM 抓语义顺滑"双轨兜底。**
