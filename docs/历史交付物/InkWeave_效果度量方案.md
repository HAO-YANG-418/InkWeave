# InkWeave v4.8 效果度量方案

## 背景

v4.8 修复了三个致命盲点（error 不拦生成、软循环、未播种），新增排比堆叠/感官均衡/的密度检测。但**卖课时讲不出"提升 X%"**——这是唯一阻碍变现的硬伤。

## 度量目标

证明 v4.8 修复后产出的章节，在以下维度**显著优于**修复前：

| 维度 | 对应修复 | 可量化指标 |
|------|----------|-----------|
| 句式多样性 | 排比堆叠检测 + 反向闭环 | 排比组数、段落开头重复率 |
| 感官丰富度 | 视觉≤45% 硬约束 | 视觉占比、非视觉感官词数 |
| 语言简洁度 | 的密度检测 | 每千字"的"字密度 |
| 阅读流畅度 | 逗号链检测 + 句式控制 | 平均句长、逗号/句号比 |

## 度量分两阶段

### 阶段一：检测器指标对比（零成本，立即可做）

**做法**：选 3 章代表性章节（开头/中段/高潮），用 v4.8 规则重写 → 跑检测 → 对比新旧指纹。

| 指标 | 获取方式 | 对比 |
|------|----------|------|
| 排比组数 | fingerprint.stylePatterns.verbStacking | 旧章 vs 新章 |
| 视觉占比 | fingerprint.sensoryMentions | 旧章 vs 新章 |
| 的密度 | fingerprint.stylePatterns.deDensity | 旧章 vs 新章 |
| 段落开头重复 | fingerprint.stylePatterns.nameStacking | 旧章 vs 新章 |
| 评分 | 检测报告总分 | 旧章 vs 新章 |

**输出**：一份对比表，可直接用于宣传物料（"排比堆叠从 16 组降至 2 组，视觉占比从 83% 降至 42%"）。

**成本**：0 元，只需重写 3 章（约 9000 字）。

---

### 阶段二：读者盲评（小样本，有说服力）

**样本设计**：
- 选 3 组章节对（每组 = 旧版 + 新版，同一大纲位置）
- 6 篇文本随机编号（A1-A6），读者不知道哪篇是旧是新
- 3-5 名读者，每人读完全部 6 篇

**评分维度**（1-5 分）：

| 维度 | 问题 |
|------|------|
| 句式多样性 | "读起来是否有重复、机械的句式？"（1=很机械，5=很丰富） |
| 感官沉浸 | "场景描写是否让你感受到多种感官？"（1=只有视觉，5=五感丰富） |
| 阅读流畅 | "读起来是否顺畅？"（1=磕磕绊绊，5=行云流水） |
| 整体质量 | "如果这是网文，你愿意追读吗？"（1=不想，5=很想） |

**分析**：
- 每组旧 vs 新对比，计算各维度平均分差异
- 如果 3 组中 ≥2 组新版显著优于旧版（平均分差 ≥0.5），可声称"提升显著"
- 最终输出：**"句式多样性提升 X%，感官丰富度提升 Y%，整体质量提升 Z%"**

**成本**：找 3-5 名读者（可从写作群/论坛招募，或付费找评测），每人约 30 分钟。

---

## 执行路径

```
第1步：选 3 章（建议：第1章 开头 / 第8章 中段 / 第14章 高潮）
第2步：用 v4.8 规则重写这 3 章（走完整闭环：pre-analysis → 生成 → 检测 → 门禁）
第3步：阶段一——跑检测器对比，产出指标对比表
第4步：阶段二——随机编号 6 篇文本，找 3-5 名读者盲评
第5步：汇总数据，产出"提升 X%"结论
```

---

## 预期产出物

| 产出 | 用途 |
|------|------|
| 指标对比表（3章×5指标） | 产品页、宣传图 |
| 盲评数据表（3-5人×6篇×4维） | 卖课/推广时的"硬数据" |
| "提升 X%"一句话结论 | 抖音口播、PPT 标题 |

---

## 风险与注意事项

1. **重写章本身必须是高质量**——如果重写章质量差，对比数据反而打脸。建议走完整 v4.8 闭环，门禁 exit 0 才算合格。
2. **盲评读者不能是熟人**——熟人会倾向给好评，数据不可信。建议从网文读者群/论坛招募，或使用付费评测服务。
3. **样本量小是硬伤**——3-5 人×6 篇在统计学上不算严谨，但对"卖课"场景足够了（多数竞品没有任何数据）。
4. **不要声称"统计显著"**——样本量不够，用"读者反馈"措辞比"统计显著"更诚实，也避免被较真的人打脸。
