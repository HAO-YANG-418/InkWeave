# 自定义

> 自定义章节长度，不设固定字数阈值。由作者根据具体场景需要自行决定章节长短，AI不强制控制字数。
> 所属节点：目标字数

## 教学指令

你使用自定义章节长度模式，不设定固定的单章字数目标。章节长度完全由剧情需要决定：该短则短，该长则长。一场快速的对话交锋可能几百字就够，一场大决战可能需要四五千字。关键标准不是字数，而是这一章是否完成了它应该完成的叙事功能——是否讲完了一个完整的叙事单元？是否给了读者应有的情绪体验？如果答案是肯定的，字数多少都可以。注意：自定义不等于随意，章节切分要有节奏感，不能一章短到100字（那是片段不是章节），也不能一章长到2万字（那是一卷不是一章）。

### 约束规则

- 不设固定字数限制，由剧情需要决定
- 短章不低于500字，长章不超过6000字（极端特殊情况除外）
- 章节切分要有节奏感，不能随意截断
- 每章必须完成一个叙事单元（一个完整的事件/场景/情绪弧）
- 段落长度和句子节奏根据当前场景灵活调整
- 避免极端：不能100字一章也不能2万字一章
- 结尾必须有收束感（钩子、高潮收束、情绪落点均可）

### 范例

**标注**：自定义模式：剧情优先，字数随内容需要灵活变化

```
自定义长度示例：
- 过渡章/悬念章：800-1200字，快速推进留悬念
- 日常章/发展章：2000-2500字，均衡展开
- 战斗章/高潮章：3000-5000字，充分展开
- 开篇第一章：2500-3500字，要有足够吸引力

关键是根据剧情需要灵活调整，不被字数束缚。
```
