## 一、诊断（人味到底缺什么）

对真实第16章《共振》(93/A) 做五维人味审计，结论：
- **生活质感细节 / 身体锚点**：本章做得好（糖纸窸窣、指甲掐月牙、铁锈硌红印），不缺、不强制检测。
- **系统性缺位**：① 情感只有平铺数值锚点（骨温三十七度一），无克制→溃堤→余波层次；② 留白/未说出口几乎为零（关键对话全说破）；③ 角色声音指纹不可检测/未引导；④ 自嘲/反讽/幽默彻底缺席。

确认这是 AI 文与真人写的最后鸿沟。

## 二、改动清单

### 2.1 检测端（checkers.ts）— 全 warning 级，绝不阻塞门禁

| 检测器 | ruleId | 逻辑 | 边界（防误杀） |
|--------|--------|------|----------------|
| D1 情感弧线 | `emotion_arc` | 平铺情绪锚点≥4 且层次标记(克制/释放/余波)为 0 → warning | 仅"数值密集但无层次"才报，冷硬叙事不误杀 |
| D2 留白缺失 | `unsaid_gap` | 对话占比≥8% 且全章留白标记(截断/动作替语言/环境承接)为 0 → warning | 对话极少(<8%)不报 |
| D3 声音漂移 | `fact_voice_drift` | 上章角色口头禅≥2，本章该角色 present 但口头禅池为空 → warning | 仅上章口头禅清晰才比对，每章最多报一次 |

### 2.2 抽取层（extract-entities.ts）

- `ChapterFact` 新增可选 `voicePrints: {name, tics}[]`。
- `extractChapterFacts` 为每个 present 角色抓"附近口头禅指纹"（语气词/惯用语字典：啦/呗/嘛/哈/嗯/呢/吧/呃/切/啧/哟/哎/喂/靠/操/才怪/也就是说/说白了/反正），供 D3 跨章比对。

### 2.3 调度层（check-chapter.ts）

- 先抽本章 `chapterFacts`（含 voicePrints），再传入 `checkCrossChapterFacts(text, prev.facts, curVoices)` 启用 D3。
- fingerprint 保存自动含 `voicePrints`（facts 字段透传），上章读取亦透传。

### 2.4 生成指令端（InkWeave写作工坊/生成指令.md）

- 新增 **铁则十八 · 人味（P2）**：四条正向引导，每条 ✔✘——情感分层 / 留白 / 角色声音独一 / 自嘲反讽。
- 顶部禁令清单新增三项：情感平铺禁用 / 留白缺失禁用 / 角色声音漂移禁用（均 warning）。

### 2.5 版本号

- 报告头统一 `v5.2`（4 处）。

## 四、边界与诚实声明

- **未做（超出规则检测能力）**：幽默/反讽是否"好笑"不可规则判定 → 仅生成指令正向引导，不强制检测。
- **生活质感不强制检测**：好文本本就有（第16章证明），强制检测会误杀 → 仅正向引导。
- **D3 保守性**：仅上章口头禅清晰(≥2)才比对，避免噪声；属 warning 级提醒。
- **人味是主观维度**：规则检测只能抓"结构性缺失信号"，不能替代真人审美。P2 把"人味"可量化部分补上，残余的主观质感需作者/LLM 在生成端把控。
