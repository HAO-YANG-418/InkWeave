## 一、优秀网文写法范式（提炼自调研，可注入铁则）

### 1.1 反注水 / 内容密度
- **场景为剧情/人物服务**：无目的的描写再美也删。写一个场景只挑 2–3 个最有代表性的细节（锈铁门、掉漆牌子、搪瓷缸），不面面俱到。
- **跟着人物视角走**：人物注意到什么写什么，急查案不会欣赏风景，只扫关键信息。
- **融入情绪**：描写带人物感受，非客观介绍。心情差看什么都灰蒙蒙。
- **注水判定**：删掉这段，主线/人物有无影响？没影响就是水。文字贵精不贵多。
- **蒙太奇**：省掉穿衣吃饭走路等琐碎，与高潮相关则浓墨重彩，无关则一笔带过；略写但**不让人物情绪断掉**。

### 1.2 信息密度 / 情绪密度平衡
- 信息密度太高+情绪密度太低 → 读者累；应「低密度写、缓缓揭」，一次只揭 1–2 点，重要设定藏起来制造解谜感。
- 「水文」的真谛：让信息密度变低**但非零**——汤太浓加点水，不是光加水（硬凑=没信息）。

### 1.3 Show, Don't Tell（展示而非陈述）
- ❌ 告诉：「主角很勇敢、很悲伤」→ ✅ 展示：拳头攥得指节发白、呼吸发抖、双腿在抖却仍向前。
- 能用台词/动作表达的情绪，绝不用形容词直说（「你给我滚出去！」他猛拍桌子，震得茶杯叮当响）。

### 1.4 节奏与结构
- 每章结构参考：**300 字入戏（抛冲突/悬念）+ 1500 字推进（小冲突→小反转→小解决）+ 200 字钩子（卡点）**。
- 快慢配比 3:2（紧张:舒缓）；快=短句短段，慢=补心理/环境/情绪。
- 每章结尾留微型钩子（危机/疑问/反转），不每章大爆炸；旧坑刚填新坑立马挖。
- 段落小冲突穿插：日常桥段也塞小型对立，全程无空白无聊段。
- 信息不要一次说完，拆开释放；长线伏笔分散铺垫、中后期回收。

### 1.5 对白
- 说人话：身份决定措辞（村民不说书面语、领导不说大白话）。
- 对话带潜台词、信息不完美、符合身份；避免「套娃式复读」（同一情绪反复说）。

## 二、AI 味特征全集（补全 D1–D6 之外的缺口）

> D1–D6 已覆盖：notXisY、排比堆叠、破折号滥用、碎句、感官比例失调、比喻堆叠。
> 以下是**新发现、需补入**的特征，分两层：

### 2.1 模型层（必须接 LLM 才能检测，正则算不出）
| 特征 | 说明 | 人类 vs AI |
|------|------|-----------|
| **Perplexity 低** | 文本过于可预测，AI 选最高概率词 | 人类有「惊奇词」、不完美表达 |
| **Semantic Smoothness 高** | 相邻句 embedding 相似度 >0.92，逻辑过顺、缺乏人类跳跃 | 人类常有思维断层、突然换角度 |
| **Burstiness 低** | 句长/结构均匀（AI 15–25 字均匀） | 人类长短交错（本十章 slStd=15.6 健康） |
| **词汇惊喜度低** | 高频词密集、同义替换有限 | 人类用词跳跃 |

### 2.2 正则层（本地可算，但实测本十章已较干净）
| 特征 | 典型标记 | 实测十章 |
|------|---------|---------|
| 连接词套路 | 此外/然而/值得注意的是/不难看出/某种意义上/综上所述/一方面…另一方面 | **0.9/千字，极轻** |
| 模板情绪句 | 眉头紧锁/深吸一口气/嘴角微微上扬/眼神一凛/不由得/微微/缓缓 | **1.1/千字，极轻** |
| 3-gram 重复 | 短语复读（需排除专有名词） | 34.9% 但中文固有偏高 |
| 标点节奏过匀 | 标点间隔 CV 低（人类 ~0.45） | 本十章 0.36–0.43，略低 |
| 对白比例极端 | <5% 或 >65% | 本十章 11–26%，正常 |
| AI 偏好词 | 英文 delve/robust/pivotal；中文 值得一提的是/不难看出/某种程度上 | 极少 |

## 三、实证结论对方案的校正（关键）

基于 `InkWeave_实证体检_十章AI味基线_2026-08-22.md`：
1. **可计算维度（连接词/模板句/句长方差/词汇多样性）在实战十章均健康** → 单靠正则检测器打不尽 AI 味。
2. **用户主观「AI 味明显」指向模型层**（perplexity 低、语义过顺）→ 检测侧新检测器（2.2）**必须含 LLM 层**，不能只做正则。
3. **阈值不能照搬英文/火山数据**：中文 slStd 天然 15+、3-gram 重复天然 30%+，需中文网文语料标定。
4. 「写空」不能靠感官密度代理（5 章字数不足但感官密度不低），更可能是**情节信息密度/场景铺陈不足**。

## 四、落到 InkWeave 的具体动作（预览）
- **生成侧（2.1，方案方活）**：新增铁则「内容密度」「去 AI 味写作」，核心指令 = 打破顺滑（加具体细节/个人经验/主观性/逻辑转折/口语化）+ 每章规划信息点密度。详见生成指令改写。
- **检测侧（2.2，给代码方）**：双轨检测器 = 正则层（连接词/模板句/3-gram/标点节奏，阈值中文标定）+ **LLM 层**（调生成模型算 perplexity + embedding 相似度）。详见检测侧方案文档。
- **反向闭环**：AI 味/空洞 warning 自动注入下章禁忌（上轮方案）。
