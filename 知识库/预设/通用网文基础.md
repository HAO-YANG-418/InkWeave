## 节点约束规则汇总（22节点，仅供参考，完整规则请读节点文件）

### 句式节奏 · 长短交错
- 段落内部必须有长短句变化，禁止连续5句以上相同长度区间
- 动作场景短句比例≥60%，抒情/回忆场景长句比例≥50%
- 每1000字≥3处极短句（1-5字）作为节奏重音，且在长句铺垫之后
- 长句（40字以上）内部≥2个逗号停顿，禁止一逗到底
- 单句不超过60字，超过必须拆成两句
- 节奏转换自然：紧张段到舒缓段之间≥2句中句过渡
- 段落长度按节奏调整：紧张段3-5句，舒缓段5-8句，关键瞬间1句一段
- 对话前后必须有动作/神态描写，形成"描写-对话-描写"节奏单元

### 对话风格 · 自然口语化
- 连续对话不超过4句必须穿插动作/神态/环境描写
- 对话标签"XX道/说"每千字不超过8次，优先用动作替代标签
- 禁止文绉绉的书面化台词（除非角色设定明确要求）
- 每段对话场景中≥1处潜台词（人物说的话和动作暗示的真实态度不一致）
- 禁止对话中直接说出角色情绪（如"我很生气""你别害怕"），情绪用语气和动作表现
- 对话标签禁止连续重复同一个动词超过2次

### 情感表达 · 内外结合（推荐默认）
- 情绪可用身体反应（Show）也可直接内心独白（Tell），两者互补；禁止陈词滥调反应（心如鹿撞/瞳孔地震/倒吸一口凉气等），但不禁止直接写情绪
- 每个情绪场景≥2处具体的身体反应/微动作，必须具体到身体部位和动作细节
- 禁止陈词滥调的身体反应（心如鹿撞、浑身发抖、倒吸一口凉气、瞳孔地震等）
- 每300字≥1处"无用动作"（无意义的习惯性动作）来表现情绪
- 情绪表现层次：外在身体反应与内心独白结合，强烈情绪可外放也可内收，**以读者好懂为准，不靠"不说透"制造质感（藏逻辑=晦涩）**
- 对话必须有潜台词，人物说的话和真实想法之间要有缝隙
- 每250字≥1处身体锚点（生理反应/微动作/感官细节）
- 禁止叙事者跳出来解释人物情绪
- 情绪转折点必须有具体的动作标记（手停了/烟掉了/打火机打不着/杯子洒了）

### 描写风格 · 感官沉浸
- 每个场景至少激活3种感官类型，视觉占比不超过45%，必须有非视觉感官
- 触觉（温度/质感/身体感觉）是核心锚点，每个场景≥1处触觉描写
- 感官描写必须融入动作或叙事，禁止像清单一样单独罗列
- 描写要具体到质感——不写"红色"写具体是什么红，不写"声音响"写是什么样的声音从哪来
- 禁止感官陈词滥调（寒气冲天灵盖/倒吸一口凉气/弥漫着恐怖气息等）
- 每个新场景/地点出现时，必须有≥1个专属的气味或声音标记
- 感官要被角色情绪过滤——紧张时听觉放大，恐惧时闻到异味
- 声音的变化比声音本身更重要——声音停了/变近了/变调了，都要写出来

### 战斗风格 · 重细节拆招
- 每个攻防动作必须写清方向、部位、方式
- 动作链条有因果关系，不能跳跃
- 使用精准动作动词，不用模糊描述
- 每3-4个动作穿插一次身体感受（疼痛、麻木、重心失衡等）
- 战斗句长：最长35字，目标18字，短句比例50%

### 锚点密度 · 标准
- 每500字≥1个身体/感官锚点
- 单章锚点间隔不超过800字
- 锚点自然融入叙事，不生硬插入
- 锚点类型多样：手部/面部/身体姿态/感官体验/呼吸心跳等
- 锚点要与情绪/场景匹配
- 对话段落也要有适当的锚点穿插（动作标签）

### 开头冲击力 · 感官轰炸
- 第一句≤20字，单字/两字感官鼓点最佳（疼。/烫。/冷。/响。/血。）
- 第一句禁止写景/背景/介绍/回忆
- 第二句必须是主角本能身体反应（缩手/僵住/回头/屏住呼吸）
- 第三句出现具体异常信号（不是背景介绍，是具体的东西在动/在发光/在流血）
- 前300字：冲突在场→主角身体在场→异常在场
- 前300字禁止世界观说明/等级介绍/回忆/环境铺陈
- 前300字人物不超过2个，场景不超过1个
- 背景信息一句话插在动作中间带过

### 转折频率 · 标准反咬
- 每250-350字必须有一次信息反咬/反转
- 反咬类型多样化：安全→危险 / 以为是A→是B / 以为错了→对了 / 以为结束→刚开始 / 以为是友→有疑点
- 新信息出来后必须接人物身体反应或物理痕迹
- 禁止线性匀速推进，禁止连续400字无转折
- 每段只承载一个新信息

### 章末钩子 · 悬念钩子
- 章末必须有明确的未解问题或未完成动作
- 最后一句不能是总结句/判断句
- 悬念必须具体，不能是"未来会怎样"这种空泛悬念
- 必须让读者想知道答案

## 写作范例

**通用强开篇：感官轰炸→身体反应→异常出现**

```
烫。他猛地缩手，指腹已经红了一片。这才看清，那截金色纤维的尖端在发光。
```

**对话示范：自然口语+动作标签+潜台词**

```
老周把烟头按灭。"来了？"

"嗯。"陈默拉开椅子坐下，没看他。

"喝什么？茶还是凉白开？"

"随便。"

老周倒了杯茶推过来，茶水太满，溢了一点在桌面上。他没擦。"东西拿到了？"

陈默从外套内袋里掏出一个牛皮纸信封，放在桌上，没推过去。"你先看看。"
```
