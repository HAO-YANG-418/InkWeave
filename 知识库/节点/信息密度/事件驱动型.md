# 事件驱动型

> 高密度信息推进，每千字4-5个新信息点。事件接连发生，几乎不给读者喘息空间，适合快节奏爽文和悬疑类作品。
> 所属节点：信息密度

## 教学指令

你采用事件驱动型的信息密度模式。写作时以事件推进为核心，每1000字必须包含4-5个新信息点——新角色登场、新线索出现、新冲突爆发、新设定揭示、局势反转等都算信息点。减少大段环境描写和心理独白，用事件本身来传递信息。场景切换要快，一个场景内不要停留过久。对话承担大量信息传递功能，但避免纯说明性对话（说人话，不要角色嘴里念设定）。每个场景结束时，局势必须有变化——不能回到原点。

### 约束规则

- 每1000字至少4个新信息点（新角色/新线索/新冲突/新设定/反转）
- 连续纯描写/心理/说明不超过150字
- 每个场景结束时局势必须有变化
- 禁止出现“什么都没发生”的过渡段落
- 信息点要自然融入剧情，禁止角色大段讲解设定
- 对话承担信息传递功能，但必须符合角色身份

### 范例

**标注**：事件驱动型：短段落，每段都有新信息，信息密度极高，几乎无冗余描写

```
李明推开门，发现办公室里一片狼藉。（信息点1：异常状况）

保险柜被撬开了，里面的机密文件不翼而飞。（信息点2：核心失窃）

他刚要报警，手机响了——是一个陌生号码。（信息点3：神秘来电）

"李警官，别报警。"电话那头的声音经过变声处理，"你女儿在我们手上。"（信息点4：绑架威胁）

李明浑身一震，转头看向桌上的相框——照片里女儿笑得灿烂。相框旁边多了一个红色的信封。（信息点5：新线索出现）

他颤抖着打开信封，里面只有一张照片：女儿被绑在椅子上，身后站着一个穿着黑色风衣的男人，男人的手腕上有一个蛇形纹身。（信息点6：线索细节）
```
