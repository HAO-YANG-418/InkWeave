# 题材层包装：悬疑（探案朝堂 / 推理）

> 写前分析第3.5步第一步加载。锁定题材基调 + 推荐结构卡，与节点系统（怎么写）正交。

## 一、题材定位与读者爽点

- **定位**：离奇案件 / 阴谋，靠线索与逻辑推进。
- **读者核心爽点**：线索反咬、真相钩子、公平推理、反转、每章留新疑点。

## 二、好懂基调（好懂优先铁律 · 不可破）

- 直给异常现场，信息密度高但一眼看懂。
- **禁慢热无钩子**（每章必留新疑点 / 新反转）。
- **禁止回灌"冷峻极简 = 高级"**；氛围靠具体异常细节，不靠晦涩碎句。

## 三、题材禁忌 / 雷区

- 禁推理跳跃（须给读者公平线索）。
- 禁案件烂尾不收（须阶段性回收）。
- 禁主角降智配合反派。
- **禁用**退婚打脸类慢热逆袭桥段（不适配悬疑，见桥段卡「适配题材」）。

## 四、推荐元件卡（指向 知识库/元件卡库/）

- **母题卡**：大奉打更人
- **桥段卡**：
  - 案发现场反推（探案朝堂 / 悬疑 / 历史）
  - 公开羞辱反转（探案朝堂 / 玄幻 / 历史；禁用纯感情向）
  - 危机反杀（全题材通用 · 高潮骨架）
  - 底牌揭晓（玄幻 / 都市爽文 / 群像）
- **章法卡**：大奉打更人
