# 均衡型（默认）

> 波浪式节奏，信息密度适中（每千字2-3个新信息点）。张弛有度，有紧张的推进也有舒缓的铺陈，是最通用的节奏模式。
> 所属节点：信息密度

## 教学指令

你采用均衡型的信息密度模式。写作节奏呈波浪式：紧张的事件推进之后，要有适当的缓冲——人物的反应、情感的沉淀、环境的描写、日常的互动。每1000字大约2-3个新信息点，不紧不慢。高潮段落可以加快节奏，日常段落可以适当舒缓。重要的信息点要给足笔墨，让读者消化；次要信息可以一笔带过。避免连续高强度输出导致读者疲劳，也避免长时间无信息量的水文字。整体节奏如呼吸：吸（推进/信息）-呼（沉淀/反应）-吸-呼。

### 约束规则

- 每1000字约2-3个新信息点，允许上下浮动
- 高潮段落可加密信息点，日常段落可放缓
- 连续紧张推进后必须有缓冲段落（反应/情感/日常）
- 信息点之间要有消化空间，禁止信息轰炸
- 重要信息点需给予足够的描写和反应篇幅
- 禁止连续500字以上无任何新信息

### 范例

**标注**：均衡型：有日常缓冲（面试后回想/心理活动），有信息推进（未接来电/父亲摔伤），张弛交替

```
面试结束后，林小雨走出写字楼，阳光有些刺眼。

她深吸一口气，回想着刚才的面试过程。HR的问题一个比一个刁钻，但她自认应对得还算得体。不过那个技术总监最后说的“回去等通知”，让她心里有些没底——通常说“等通知”就是没戏的意思吧？

走到公交站，她掏出手机想刷一下消息，却看到了三个未接来电，都是妈妈打的。

林小雨心里一紧，连忙拨回去。

"小雨啊，你爸刚才在工地摔了，现在在医院！"妈妈的声音带着哭腔。

林小雨脑子“嗡”的一声，手里的包差点掉在地上。

"哪家医院？我马上过去！"
```
