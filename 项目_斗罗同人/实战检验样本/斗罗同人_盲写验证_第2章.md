# 斗罗同人 · 第2章 古庙里的尺（盲写验证版）

> 验证说明：本章在「不回看任何显式规则（好懂红线 / #6吃肉 / #7节奏骨架 / 铁则）」的前提下，仅依靠已改过的 config 默认种子（语调=口语白话·通俗直白、情感=内外结合）自然写出。用来回答"改根本后，忘掉记忆写，还行不行"。

陆鸣把铁牌翻来覆去看了三遍。

牌上的纹路，和他铁尺柄上那道刻痕，一模一样。

老周蹲在门槛上，烟袋锅子敲着鞋底，半天才憋出一句："这是量尺门的记号。你爹当年，就是揣着把铁尺出去的。"

陆鸣手一紧。

他从小以为爹是进山采药摔死的。娘临死前只撂下一句"别问你爹的事"，就没了下文。

"量尺门是什么？"他问。

"三百年前的事了。"老周把烟点上，"那时候圣魂村不叫圣魂村，叫尺村。村里人人一把铁尺，量的不是布也不是米，是魂兽骨头上的纹。哪根骨头值钱，哪根藏着魂力暗道，铁尺一搭就知道。"

"后来呢？"

"后来一夜之间，全村没了。"老周吐出一口烟，"房子还在，人不见了。官府来查，说染了瘟。可俺爷爷说过，那晚他听见尺村方向传来尺响，一下一下，像有人挨家挨户敲门。敲完，人就都没了。"

陆鸣后背一凉。

昨夜古庙那声尺响，就是这么来的。

他握紧铁尺。玉鳞蛇魂环里那个空脸灰袍人，还有那些反常结群的蛇——如果蛇是被人放出来探路的，那放蛇的人，和量尺门，和昨晚的古庙，是不是一伙的？

"我去古庙看看。"他说。

老周猛地站起来："你疯了？那地方邪性！"

"我爹可能就在里头。"陆鸣把铁牌塞进怀里，"铁牌从泥里浮出来，纹跟我尺一样。他要真还在，我得去。"

老周盯着他看了好久，忽然从墙角拽出一把生锈的柴刀。

"俺陪你去。"老人把刀往腰上一别，"你爹当年帮过俺。这恩，该还。"

两人摸黑出了村。

古庙在村后山的背阴面，荒了不知多少年。门板斜挂着，风吹过来吱呀一声。陆鸣踏进去的瞬间，铁尺自己颤了一下——不是手抖，是尺身发烫。

庙里没神像，供台上摆着一排空铁尺，整整齐齐，像等人来拿。

地下有新鲜的脚印。很小，很密，是蛇肚皮蹭出来的。

陆鸣蹲下，顺着脚印往供台后看。供台后面有个洞，洞口歪歪扭扭，像是被人从里头刨开的。洞里黑，但飘出一股味——

腥，里头像裹着甜。

跟玉鳞蛇魂环里那股味，一样。

他举尺凑近洞口。尺身越来越烫，烫得他掌心发麻。就在这时，洞里传来一声轻响。

咔。

像尺敲在骨头上。

然后一个声音，贴着他的耳朵，很近，很轻：

"你终于，来找你爹了。"

陆鸣汗毛一下全竖起来。洞口黑漆漆的，什么也看不见。但那股甜的腥味，正顺着洞口，一点点漫上来。

老周在身后"呛"地拔出柴刀："啥声？"

陆鸣没回头。他盯着那个洞，喉咙发干。

"周伯，"他听见自己说，"把庙门，抵死。"
