# 科幻未来

> 科幻未来世界观词库，包含飞船、机甲、量子、AI、全息、星舰、跃迁、赛博、植入体、神经接口、空间站、虫洞等科幻专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用科幻未来世界观词库。写作时自然融入科幻世界的专有名词和感官描写：全息投影的蓝光、引擎的低频嗡鸣、金属舱壁的冰冷、神经接口接入时的刺痛、跃迁时的扭曲感、机甲液压系统的嘶嘶声。身体描写兼顾生物锚点和科技改造——除了常规身体反应，还要有植入体发热、神经接口传来数据流、义肢的机械反馈、HUD投射在视网膜上的信息。动作描写要有科幻味：接入神经接口、启动跃迁、激活全息面板、操控机甲、对接空间站、量子通讯。场景：星舰舰桥、机甲驾驶舱、赛博朋克贫民窟、太空站环形走廊、外星殖民地。

### 约束规则

- 必须使用科幻专有词汇，科技设定要自洽
- 身体锚点加入植入体/神经接口/义肢/HUD等科幻元素
- 感官描写要有未来感：金属/能量/数据流/全息光/引擎振动
- 科学术语使用要合理，避免堆砌名词但不懂含义
- 可以适当创造新词，但必须通过上下文让读者理解
- 对话风格根据设定调整——可以是军事化的简洁、赛博朋克的俚语、或精英科学家的术语

```
舰桥的红色警报灯疯狂旋转，映在每个人脸上。

「敌舰跃迁完成，三艘巡洋舰，距离十二万公里！」

陈舰长猛地握紧指挥椅的扶手，神经接口在后颈处微微发烫——"致远号"的AI正在将战术数据直接注入他的视觉皮层。下一秒，HUD在他视网膜上展开，三艘敌舰的轮廓、护盾值、武器参数全部以半透明的图标悬浮在视野中。

「全舰一级战备，启动能量护盾，左满舵！」

引擎室的低频嗡鸣骤然升高，人工重力因为过载而波动了一瞬，几个没系安全带的船员踉跄了一下。

「主炮充能完毕，锁定完成！」武器官的声音从通讯器里传来，带着电流杂音。

陈舰长盯着视野中越来越近的红色光点，深吸一口气。

「开火。」

舰体微微一震，一道蓝白色的离子光束从主炮口喷涌而出，撕裂了漆黑的太空。
```
