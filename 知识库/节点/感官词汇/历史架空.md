# 历史架空

> 历史架空世界观词库，包含朝堂、科举、圣旨、衙门、江湖、武功、内力、轻功、剑法、镖局、客栈、皇帝、大臣、将军、兵马等古代/武侠专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用历史架空世界观词库。写作时自然融入古代历史和武侠的专有名词和感官描写：宣纸的墨香、刀剑出鞘的冷光、客栈里酒菜的香味、朝堂上玉笏碰撞的清脆声、马蹄踏碎石板的轰鸣。身体锚点注重武侠特色：丹田内力涌动、剑气侵入肌肤、轻功提纵时的耳旁风声、穴位被点时的酸麻。动作描写要有古代/武侠味：抱拳行礼、拔剑出鞘、施展轻功、策马奔腾、跪拜接旨、举杯邀饮。场景：金銮殿、县衙大堂、江湖客栈、镖局、武林大会、青楼、书房校场、边关战场。

### 约束规则

- 必须使用古代/武侠专有词汇，避免出现现代词汇
- 历史称谓要准确（朕/臣/在下/姑娘/客官等）
- 武功描写要有武侠味：内力/轻功/招式/穴位/剑法
- 官场礼仪和科举制度要符合古代逻辑
- 感官描写注重：墨香/刀剑寒光/马蹄声/酒菜香/血腥味
- 对话风格半文半白，符合古人说话方式但不要过于晦涩

### 范例

**标注**：历史架空词库示例：客栈/小二/碎银子/马蹄/铁甲骑兵/刑部/剑鞘/江湖人/斗笠等古代武侠词汇自然融入

```
悦来客栈的大堂里，人声鼎沸。

靠窗的一张桌子旁坐着一个青衫年轻人，面前摆着一壶酒、两碟小菜，却自始至终没动几筷子。他的目光时不时飘向门口，右手始终搭在腰间那柄不起眼的铁剑上。

“小二，结账。”

他放下一锭碎银子，刚要起身，门外突然马蹄声大作，一队铁甲骑兵疾驰而至，在客栈门前齐刷刷勒住缰绳。为首的军官翻身下马，手持一卷明黄色的卷轴，大步走进客栈。

“刑部缉拿要犯！闲杂人等回避！”

大堂里瞬间安静下来。青衫年轻人的瞳孔微微一缩，手指在剑鞘上轻轻敲了三下——这是江湖人示警的暗号。

他注意到，角落里一个戴斗笠的喝茶人，手已经悄悄探入了怀中。
```
