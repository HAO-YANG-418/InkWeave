# 平衡（temperature:0.7，默认）

> AI创造性平衡，temperature设为0.7。在遵循大纲和设定的基础上，允许适当的创意发挥——可以添加有趣的细节、自然的对话变化、适度的意外转折。是最通用的创作模式，默认推荐选项。
> 所属节点：AI创意度

## 教学指令

你使用平衡创作模式（temperature=0.7）。你在遵循核心设定和大纲的基础上，可以进行适度的创意发挥。允许添加：生动的细节描写、自然的对话变化、小范围的意外和转折、有趣的配角反应、环境中的小彩蛋。但大方向必须按大纲走，核心人设不能崩，主要剧情节点不能偏离。用词可以灵活，适当使用比喻、修辞和生动的表达，但不要过于花哨。对话可以有即兴发挥，但要符合人物性格。可以在场景中加入出人意料但合理的小细节，让故事更有活力。适合：大多数创作场景，既有可控性又有创作活力。

### 约束规则

- 核心设定、大纲、人设必须遵循，不能偏离大方向
- 允许添加生动细节、自然的对话变化、小范围意外
- 允许使用修辞和比喻，但不过度花哨
- 对话可以即兴发挥，但符合人物性格
- 小转折可以有，但必须合理且能自洽
- 可以引入次要新元素（如一个路人、一个小道具），但不能影响主线
- 在稳定性和创造性之间取得平衡

### 范例

**标注**：平衡模式：在遵循主线的基础上添加生动细节和小转折，既有控制又有活力

```
（平衡模式续写示例）
前文：林晚走进咖啡馆，看到沈知行坐在靠窗的位置。

续写：她深吸一口气，走过去。高跟鞋踩在木质地板上，发出清脆的声响——她特意选了这双鞋，就是为了让自己看起来不那么狼狈。

沈知行抬起头，目光在她脸上停留了一秒。他比三年前瘦了些，眼下有淡淡的青黑，像是很久没睡好。

「你迟到了七分钟。」他说，语气听不出情绪。

「路上堵车。」她坐下，发现桌上已经摆了一杯美式——她以前最爱喝的那种，不加糖不加奶。他还记得。

（平衡模式：添加了合理的细节——高跟鞋、眼下青黑、提前点好的咖啡，这些小细节增加了层次感但不偏离主线，同时“他还记得”是一个小情感转折）
```
