# 问题循环

> 5种问题滚动循环，每章必须回答一个问题并提出新问题

## 核心原则

每章 = 回答旧问题 + 提出新问题。问题驱动叙事，读者因"想知道答案"而继续阅读。

## 问题类型

| 循环 | 问题范围 | 生命周期 | 示例 |
|------|---------|---------|------|
| 即时问答 | 本章内 | 1章 | "这道门后面是什么？"→ 本章结尾打开 |
| 跨章问答 | 2-5章内 | 2-5章 | "他为什么能免疫这种毒素？"→ 3章后揭示 |
| 卷级问答 | 本卷内 | 整卷 | "谁在幕后操控这一切？"→ 卷末揭示 |
| 关系问答 | 角色关系线 | 可跨卷 | "她为什么要背叛？"→ 跨卷揭示 |
| 世界问答 | 世界观层面 | 可跨卷 | "这个世界的能量来源是什么？"→ 逐步揭示 |

## 问题生命周期

```
提出问题 → 提供线索（触碰） → 增加压力 → 部分回答 → 完整回答 → 提出新问题
    ↓              ↓                ↓           ↓           ↓           ↓
  标记"待答"    标记"活跃"      标记"紧迫"   标记"部分"   标记"已答"   新问题诞生
```

## 问题状态管理

| 状态 | 含义 | 操作 |
|------|------|------|
| 待答 | 刚提出，不需要立即回答 | 3章内首次触碰 |
| 活跃 | 已触碰，读者在关注 | 每2章提供新线索 |
| 紧迫 | 压力积累，读者急于知道 | 1-2章内部分回答 |
| 部分 | 已部分回答，仍有悬念 | 缩小问题范围，聚焦核心 |
| 已答 | 完整回答 | 触发新问题 |
| 遗忘 | 超时未触碰，读者已遗忘 | 标记为遗忘，不再追踪 |

## 问题数量约束

| 层级 | 同时活跃上限 | 说明 |
|------|------------|------|
| 即时问答 | 每章至少1个 | 本章必须回答的问题 |
| 跨章问答 | 不超过3个 | 超过3个读者会混乱 |
| 卷级问答 | 1个 | 本卷核心悬念 |
| 关系问答 | 不超过2个 | 不同角色关系线 |
| 世界问答 | 不超过2个 | 过多世界观问题会稀释其他悬念 |

## 问题设计原则

1. **问题要对角色有切身影响**：不是"这个世界有多大"，而是"如果不找到出口，他就会死在这里"
2. **问题要有唯一答案**：不是"他会不会成功"，而是"他只有一次机会，代价是什么"
3. **问题要层层嵌套**：回答表层问题后，暴露更深层问题
4. **问题要与角色动机绑定**：问题驱动的不是"剧情需要"，而是"角色想要"
5. **问题要有情感重量**：不只是"谜题"，而是"这对角色意味着什么"

## 问题循环检查

每章写完后检查：

- [ ] 本章回答了什么旧问题？
- [ ] 本章提出了什么新问题？
- [ ] 活跃问题是否超过上限？
- [ ] 是否有问题超过生命周期未触碰？
- [ ] 新问题是否与角色动机绑定？
- [ ] 回答是否令人满意？（不是"原来就这样"）
