# 克制留白 (Show Don't Tell)

> 不直接写情绪名称，用身体反应、微动作、环境映射和对话潜台词表达情感。冰山理论：留白只停情绪层，事件因果与动作链必须写清。
> 所属节点：情感表达

## 教学指令

⚠️ 好懂红线（2026-08-31 钉死）：克制≠难懂，留白≠藏逻辑。含蓄/克制/留白只适用于**情绪层**（不直说角色感受），**绝不适用于信息层**——事件因果、动作链、设定逻辑必须说清，读者零回读。任何写法一旦让人需回读才懂，立即让位给"读着顺"。网文第一标准是好懂。

⚠️ 补充（2026-08-31）：冰山理论**只停情绪层**——不直说"他很愤怒"，改用指节发白。但事件因果、动作链、设定逻辑**不许藏**，藏了就是让读者猜，与网文好懂相悖。

克制留白的核心是'冰山理论'——写出来的只有八分之一，剩下八分之七在水面下。你永远不直接告诉读者角色在想什么、感受到什么，而是写他做了什么、身体有什么反应、说了什么（以及没说什么）。读者自己读出来的情绪，比你写出来的强烈一百倍。

【身体反应库——分情绪对应具体动作】

1. 紧张/恐惧：不要写'他很紧张/害怕'，写：

- 手指无意识地摩挲某个东西（烟盒/打火机/衣角/袖口/杯沿）

- 咽口水，但喉咙发紧咽不下去

- 后颈僵硬，肩膀不自觉耸起

- 呼吸变浅，能听见自己的心跳

- 手心出汗，在裤子上蹭了蹭

- 脚趾在鞋里蜷起来

- 视线飘忽，不敢对视，或者死死盯着一个地方

- 说话比平时快，或者比平时慢，或者突然忘词

- 想点烟但打火机打了三次都没打着

2. 愤怒/暴怒：不要写'他很生气/愤怒'，写：

- 指节发白，拳头攥得太紧指甲掐进掌心

- 太阳穴突突跳，能看见血管在跳

- 呼吸变粗，鼻孔张大

- 说话声音反而变小、变平（压抑的愤怒比大吼更可怕）

- 把手里的东西轻轻放下，但放得太轻了——在控制

- 突然开始做某件无意义的事（擦桌子/整理东西/倒水），动作很快

- 笑了一下，但不是真笑

- 沉默。长时间的沉默。

3. 悲伤/难过：不要写'他很悲伤/难过'，写：

- 某个动作做了一半停住了（伸手拿烟，停在半空两秒，又收回来）

- 说话声音正常，但说完某句话之后停顿了很久

- 眨眼睛的频率变高，或者一直不眨眼（在忍眼泪）

- 摸烟的手在抖，但自己没发现

- 突然开始说一些无关的话（'今天天气不错''吃饭了吗'）

- 把东西收拾得异常整齐

- 重复某个无意义的小动作（反复按打火机/转杯子/折衣角）

- 不说话，只是抽烟/喝水/看着某个地方

4. 震惊/不敢相信：不要写'他很震惊/不敢相信'，写：

- 手里的东西掉了，但没立刻去捡

- 张了张嘴，没说出话

- 往后退了半步，自己没意识到

- 笑了一声，很短，像咳嗽

- 反复看同一个东西（纸条/照片/短信），看了一遍又一遍

- 听见声音但没反应，有人叫他名字才回过神

- 某个平时很熟练的动作突然做不好了（系不上扣子/点不着烟）

5. 压抑的情感：不要写'他在忍着/他很克制'，写：

- 深呼吸，吸得很慢，呼得更慢

- 端杯子/拿烟的手稳得不正常，像刻意控制

- 转移话题，主动说别的事

- 站起来走到窗边/门口，背对着人

- 说了句玩笑话，但笑得不自然

- 答应得太快（'好''行''没问题'），像怕自己反悔

【技法原则】

1. 反差原则：情绪越激烈，动作越平淡。听到亲人死讯不是号啕大哭，是愣了两秒然后继续点烟，打了四次没点着。平淡的动作里有山呼海啸。

2. 具体到不能再具体：不要写'他手在抖'，写'他端杯子的时候，茶洒出来一点，在桌面上晕开一小片深色'。不要写'他很紧张'，写'打火机的齿轮磨了三次，火星有了，油也有了，就是不着'。

3. 无用即真实：人在情绪激烈的时候会做毫无意义的事——整理本来就整齐的东西、擦本来就干净的桌子、反复按同一个按钮。这些'无用动作'比任何情绪描写都真实。

4. 环境映射：情绪可以投射到环境上，但不要写'连老天都在哭'这种老套的。写'风停了''矿灯闪了一下''墙上的钟滴答声突然变响了'。环境没有情绪，是角色的感知变了。

5. 潜台词原则：对话永远和真实想法有差距。'没事'='有事'，'我先走了'='再待一秒我就要撑不住了'，'你说什么就是什么吧'='我不跟你争但我根本不同意'。不要解释潜台词，让读者自己读。

6. 禁止清单：绝对禁止出现以下词汇——紧张、恐惧、愤怒、悲伤、难过、开心、高兴、痛苦、绝望、心碎、五味杂陈、百感交集、心如刀绞、怒火中烧、忐忑不安。这些词是作者的偷懒，是对读者的不尊重。

### 约束规则

- 绝对禁止直接使用任何情绪标签词（愤怒/悲伤/紧张/害怕/开心/难过/绝望/痛苦等），一个都不许有
- 每个情绪场景至少有2-3处具体的身体反应/微动作描写，必须具体到身体部位和动作细节
- 禁止陈词滥调的身体反应（心如鹿撞、浑身发抖、倒吸一口凉气、瞳孔地震、浑身冰冷等）
- 每300字至少有1处'无用动作'（无意义的习惯性动作）来表现情绪
- 情绪越激烈，外在动作越克制——强烈情绪用平淡甚至反常的动作表现，不要大喊大叫大哭大闹
- 对话必须有潜台词，人物说的话和真实想法之间要有缝隙，禁止角色把心里话直接说出来
- 每250字至少有1处身体锚点（生理反应/微动作/感官细节）
- 禁止叙事者跳出来解释人物情绪（'他其实很害怕''她嘴上这么说心里却很难过'）
- 情绪转折点必须有具体的动作标记（手停了/烟掉了/打火机打不着/杯子洒了）
- 每处重要场景至少调用两种感官（视觉+触觉/嗅觉/听觉/味觉），触觉与嗅觉最易被忽略也最建立代入感，避免单一视觉堆砌（热门网文基准：双感官铺陈）

### 范例

**标注**：Show Don't Tell示范：全文没有一个情绪词（没有震惊/悲伤/痛苦/绝望），所有情绪都藏在细节里——手指停半秒、扣子系两次、打火机打三次、烟吸呛了没咳、声音太平、看着窗外不回头。读者能感受到那种山崩于前但强行压住的情绪，但作者一个字都没说。'还有事吗？'四个字是逐客令，意思是'你走吧，再待下去我要撑不住了'，这就是潜台词。

```
陈默接过那张纸。

纸是A4打印的，边角有点卷，被很多人摸过。他的手指碰到纸面的时候，停了一下——大概半秒，不仔细看根本注意不到。

他把纸展开。

诊断书三个字是黑体的，下面是他父亲的名字，再下面是一堆医学术语，他看不太懂，但他看懂了最后那行字。

他把纸折起来。折痕对齐，压了压，折得很整齐，然后放进工服内侧的口袋里。

扣子系了两次。

第一次扣子没对准扣眼，他的手指滑开了。第二次才系上。

他从口袋里摸出烟盒，抖出一根，叼在嘴里。打火机在另一个口袋，他摸了两下才摸到。齿轮拨了一次，没着。拨了第二次，火星闪了一下，还是没着。

第三次才点着。

他吸了一口，烟吸得太深，呛了一下，但他没咳。

站在对面的老周没说话，等着。

「知道了。」陈默说。

声音很平。平得像一潭死水，连波纹都没有。

他把打火机放回口袋，烟夹在手指间，看着窗外。窗外天阴着，堆着很厚的云，像要下雨。

「还有事吗？」他问，没回头。
```
