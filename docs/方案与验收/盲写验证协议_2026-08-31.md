# 盲写验证协议（2026-08-31 用户拍板·最高优先级）

## 1. 原则（用户原话落地）
> "我们所有的东西都是要去改变根本，然后写的时候忘掉记忆去写，这样才能验证。"

- **所有改动的目标 = 改根本（模型写字的底层倾向）**，不是往上叠更多显式规则。
- **唯一有效的验证 = 盲写**：剥离全部显式规则清单，只留改过的 config/KB 默认种子，自然写一章；写出来仍好懂/有货/有骨 → 根本真改了；写出来塌 → 规则只是撑表面的拐杖，根本没动。

## 2. 推论（约束我们的做法）
- 好懂红线 / #6吃大纲的肉 / #7节奏骨架 / 铁则，全是**临时脚手架，必须可拆**，不能当永久护栏。
- 真改的根本只有两层：
  1. **config/KP 种子替换**（冷峻→口语白话、克制留白→内外结合）——已落，改的是"默认倾向"。
  2. **微调权重**（进权重学网文语感）——待跑，改的是"底子"。
- 检测器只配做安全网抓硬伤（碎句/藏逻辑/一逗到底），不碰剧情质量。
- **盲写必须配 `盲写评分卡_A层15项_固化.md`**：剥离脚手架写完后，按 A 层 15 项逐项打分（✅/△/✘/➖）并附证据，只判"整体不塌"= 无效。评分卡是盲写结论的唯一有效载体（P2 固化）。

## 3. 盲写 A/B 协议（代码方执行，引擎跑）
材料：同一本小说、同一章大纲（保证输入一致）。

| 组 | 配置 | 目的 |
|---|---|---|
| **A 组（带脚手架）** | 当前 `生成指令.md` 全量（含好懂红线+#6+#7） | 现状基线 |
| **B 组（盲写·剥离脚手架）** | 临时注释掉 `生成指令.md` 的 #6/#7/好懂红线三段，仅保留 config/KP 默认种子（口语白话+内外结合） | 测根本是否真改 |

步骤：

4. 人工或 CLI 比：好懂？有货？追读骨？零文艺腔？
