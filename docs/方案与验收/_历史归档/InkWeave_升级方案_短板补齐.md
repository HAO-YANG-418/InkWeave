# InkWeave 升级方案 · 短板补齐（目标 v5.0）

> 编写时间：2026-08-21
> 背景：v4.9 已完成「表层去 AI 八股 + 质量门禁闭环」，实战第16章跑出 97分A。
> 本文针对上一轮评估暴露的三大短板，给出可执行的补齐方案。
> 核心判断：从「不像机器生成的烂文章」升级到「像有个性的好文章」。

---

## 一、总体战略

三场战役，按「改动最小 → 最大短板 → 最高天花板」排序：

| 战役 | 目标 | 优先级 | 改动量 | 对标意义 |
|------|------|--------|--------|----------|
| 一 · 去均匀腔 | 防强制规范制造「太干净没个性」的新套路 | P0 | 小 | 守住表层护城河不翻车 |
| 二 · 长程一致性 | 补事实层 fingerprint，跨章不崩 | P1 | 中 | 追上 Sudowrite 的关键 |
| 三 · 人味/叙事质量 | 区分「正确」与「动人」 | P2 | 中 | 拉近与通用模型人味差距 |

---

## 二、战役一 · 去均匀腔（破格额度）— P0

### 问题
v4.9 的强制均匀已在实战中暴露反效果风险：
- 每章感官被机械压成 视觉33/听觉20/触觉33，真人写作有起伏；
- 零破折号、零"不是X是Y"、修辞变奏≤1处——全禁反而「太正确」；
- 91 处身体锚点若都模板化成 凉/麻/颤，会成新套路。

### 落地改动
1. **铁则加「破格额度」**（`InkWeave写作工坊/生成指令.md`）
   - 破折号：每章允许 ≤2 处，超出才报 error，≤2 处降 warning（铁则十二放宽）。
   - "不是X是Y"：每章允许 ≤1 处，超出 error，≤1 处 warning（技法二放宽）。
   - 修辞变奏：额度从 1 提为 2，给不规则节奏留口子。
2. **感官基调起伏**（`检测工具/pre-analysis.ts`）
   - 当前：每章强制 视觉≤45% + 非视觉均匀。
   - 改为：pre-analysis 生成「本章感官基调」（如本章听觉主导 50%、视觉 25%），章节之间轮换主导感官，制造起伏；检测端按「基调±偏差」判定而非死卡 45%。
3. **身体质感多样性**（`检测工具/checkers.ts` 新增 `checkTextureVariety`）
   - 禁止连续 ≥3 处同一质感词（凉/麻/颤/涩 循环），warning 级。

### 验收
- 重跑第16章，《共振》在「破格额度」下仍 0 error，且允许有 1-2 处 deliberate 破格不误杀。
- 写一章「感官基调=视觉主导」的对照章，证明起伏生效、不机械。

## 三、战役二 · 长程叙事一致性（事实层 fingerprint）— P1

### 问题（最大短板）
当前 `.fingerprint.json` 只记 `verbStackingVerbs + senseError` 等**表层统计**。
跨章的 角色特征漂移、设定名词突变、时间线矛盾、伏笔凭空消失、专有名词前后不一致——**完全不验**。
这是相对 Sudowrite（Story Bible + 记忆模型，长程一致 4/5）最弱的一项（我们 1/5）。

### 落地改动
1. **新增事实抽取**（`检测工具/extract-entities.ts`）
   - 输入：本章正文 + 项目设定（角色档案.md / 世界观设定.md）。
   - 输出「事实指纹」：出场角色及当前状态（位置/伤势/持有物）、关键设定名词、时间锚（第几日/时段）、未回收伏笔列表、数值与专有名词。
   - 先用**规则 + 轻量 LLM 兜底**：规则抓专有名词/数字/角色名，LLM 做语义归并。
2. **扩展 fingerprint 结构**（`检测工具/check-chapter.ts` 保存逻辑）
   - `.fingerprint.json` 新增 `facts` 字段：`{ characters, settings, timeAnchor, pendingForeshadow, properNouns }`。
3. **新增跨章事实校验**（`检测工具/checkers.ts` 新增 `checkCrossChapterFacts`）
   - 下一章 check 时，读上章 `facts` 与本章程式比对，报：
     - 角色特征漂移（如上一章断臂，本章完好无交代）
     - 设定名词突变（同一概念前后叫法/数值不一致）
     - 时间线矛盾（上一章夜，本章未交代直接日）
     - 伏笔凭空消失（pendingForeshadow 未回收且无新伏笔替代）
   - 接入 check-chapter 门禁，**warning 级**（不废章，避免长文挫败）。
4. **pre-analysis 注入事实禁忌**（`检测工具/pre-analysis.ts`）
   - 把上章 `facts` 的「待回收伏笔 + 角色状态」注入本章简报，防遗忘。

### 验收
- 构造 2 章测试：第A章设伏笔「右手断指」，第B章写「右手完好」→ 报 warning。
- 构造时间线矛盾样本 → 报 warning。
- 真实续写第17章，fact 校验 0 warning（证明正常写作不被误杀）。

## 四、战役三 · 人味/叙事质量（轻量评估）— P2

### 问题
检测端不验：钩子真假、水章、因果断链、情感真实、角色声音差异。
通用模型人味 4/5，我们 2/5——因为强制规范压低个性。

### 落地改动
1. **新增叙事质量校验**（`检测工具/checkers.ts` 新增 `checkNarrativeQuality`）
   - 章末钩子校验：检测铁则十已禁的假钩子句型（「他不知道的是/黑暗中有东西/一切才刚刚开始」）——**生成指令已写但检测端未验**，先补上（error 级，因为假钩子是硬伤）。
   - 水章检测：场景数 <4 或 对话占比 <8% 且无外部压力（铁则五已写未验）→ warning。
   - 因果链断点：连续 ≥4 段无「动作→世界回应」结构 → warning。
2. **角色声音差异**（`检测工具/checkers.ts` 新增 `checkCharacterVoice`）
   - 同一角色对话引导词/句式模板是否跨章稳定；主角与配角声音是否有区分 → warning。
3. **情感真实度**（`检测工具/checkers.ts` 新增 `checkEmotionGrounding`）
   - 铁则六禁直述情绪已有，补检测：情绪是否落到具体身体部位/动作，而非抽象形容词 → warning。

### 验收
- 用 trea 早期烂尾样本 / 通用模型裸写样本跑新检测器，证明能抓「假钩子 + 水章 + 情感飘」。
- 真实章节跑 0 warning。

## 五、工程化约定

- **所有新增检测默认 warning 级**，避免废章挫伤长文写作。
- **error 级只保留**：破折号超额度、排比堆叠≥6处、假钩子——这些是硬伤，必须拦。
- **单元测试**：`检测工具/checkers.test.ts` 补三类新检测器用例。
- **门禁自检**：`verify-gates` 覆盖新检测器，保证回归不破。
- **CLI 无需改**：新检测器挂在 check-chapter 内部调度，pre-analysis 注入逻辑。

---

## 六、执行时间线（建议）

- **P0（1-2 天）**：战役一。破格额度 + 感官基调起伏 + 质感多样性。立刻消除均匀腔风险，改动最小、回报最快。
- **P1（3-5 天）**：战役二。事实层 fingerprint + 跨章事实校验。最大短板，追上 Sudowrite 的关键。
- **P2（1 周+）**：战役三。叙事质量 + 角色声音 + 情感真实。拉高天花板。

---

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| 破格额度放太宽 → 回到 AI 味 | 小步调参，先 ≤2 破折号/≤1 不是X是Y，实战观察 |
| 事实抽取靠 LLM → 成本高/不稳 | 规则优先，LLM 仅做语义归并兜底；缓存到 fingerprint |
| 检测端越重 → 跑得越慢 | 跨章检测只在 `--save-fingerprint` 时触发；纯 check 轻量 |
| 真实性误杀正常写作 | 全部 warning 级 + 真实章节 0 误杀验收才算过关 |

---

## 八、决策建议

建议**先打 P0（去均匀腔）**：改动最小、立刻防反效果、且能马上重跑第16章验证不误杀。
P1（长程一致性）是拉开与竞品差距的真正胜负手，但工程量大，需单独排期。
