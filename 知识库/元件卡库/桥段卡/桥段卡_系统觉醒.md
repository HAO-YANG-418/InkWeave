# 桥段卡：系统觉醒

- **母题**：平凡人获超自然外挂 + 认知颠覆
- **结构**：①异常身体信号（痛/光/声音） → ②旁人点破（你不对劲） → ③主角装睡/藏拙 → ④超自然埋线（系统/神明/规则现身）
- **情绪曲线**：惑(0-25%) → 疑(25-55%) → 惊(55-80%) → 钩(80-100%)
- **钩子位**：章末留「它开口了」或「第二个症状出现」
- **适配题材**：都市异能 / 灵异 / 无限流；禁用纯写实
- **来源书**：我在精神病院学斩神 / 灵境行者（结构提炼，非原文）
- **禁忌**：禁止系统无代价无代价（须有规则/代价）；禁止觉醒后性格突变；禁止超自然设定前后矛盾
