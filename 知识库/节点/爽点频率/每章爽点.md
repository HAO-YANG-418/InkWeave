# 每章爽点

> 每章至少1个爽点或钩子，读者永远处于兴奋状态。适合免费阅读平台、快节奏爽文，让读者每章都有满足感。
> 所属节点：爽点频率

## 教学指令

你采用每章必爽的节奏模式。每一章都必须包含至少一个明确的爽点或钩子。爽点可以是：打脸反派、获得宝物/能力升级、美女/贵人相助、真相大白、反转打脸、装逼成功、众人震惊、实力碾压、危机化解、意外收获等。如果当章剧情确实不适合放爽点（如过渡章），则必须在章末放一个强力钩子——惊人发现、危机降临、神秘人物登场、悬念升级等。绝对不允许出现“平淡无奇”的章节。爽点要前置，最好在章节前半段就出现，不要让读者等太久。

### 约束规则

- 每章必须有至少1个爽点或章末强力钩子
- 爽点尽量在章节前1/3出现，不要让读者空等
- 爽点类型要多样化，禁止连续3章同类型爽点（如连续打脸）
- 小爽点和大爽点交替，避免审美疲劳
- 爽点之后可以有短暂缓冲，但下一个爽点/钩子必须在2000字内出现
- 章末钩子必须强烈，让读者产生“必须看下一章”的冲动

### 范例

**标注**：每章爽点模式：章内两个爽点（拿证据/反派被开），章末钩子（背后有人），层层递进

```
王总监一脸得意地等着看林风出丑，会议室里所有人的目光都集中在林风身上。

林风不慌不忙地打开U盘，投影幕布上出现了一份完整的数据报告——每一笔账目都清清楚楚，王总监挪用公款的证据赫然在列。

（爽点：拿出证据反杀）

王总监脸色惨白："你……你怎么会有这些？"

"你以为销毁了原件就没事了？"林风淡淡道，"你忘了，服务器有备份。"

董事长看完报告，猛地一拍桌子："王建国！你被开除了，法务部马上报警！"

（爽点：反派被当场处置）

王总监被保安架出去的时候，怨毒地盯着林风："你等着！我不会放过你的！"

林风不以为意地坐回座位，却感觉到桌下有人踢了他一下。

他低头一看，是董事长秘书苏晴递过来一张小纸条，上面写着：「小心，王建国背后有人。」

（章末钩子：更大的威胁）
```
