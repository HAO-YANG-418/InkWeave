# InkWeave 写作引擎 · 最终完整方案（2026-09-04 定稿存档）

## 0. 文档定位
本文件是 InkWeave 网文生成引擎截至 2026-09-04 的**唯一权威方案存档**，汇总此前所有根因诊断、架构决策与已验证能力。后续关于「知识库搭建 / 蒸馏 / 拆书」的讨论在此基础之上迭代，不推翻本文件已锁定的结论。

## 1. 根因（一句话）
引擎把"文学极简 / 克制 / 留白 / 低逗句比"误当"写作好"，逼出晦涩碎句，与网文"好懂直白"的核心诉求相悖。
→ 规则只排错不提升；质量回生成端 + 硬大纲 + 微调；检测器降级为安全网。

## 2. 已锁定的架构决策
- **skill 烂 → 走微调**：skill 阶段已把能内化的能力内化（A 层 14/15），剩余分布级问题靠微调底座治本。
- **微调与 prompt / 检测器两侧同步迭代**，不能只动一侧。
- **语料只用热门网文（好懂直白）**，禁用文学小说（诡秘之主 / 捞尸人等文风特殊书已剔除）。
- **发布级 skill 三件套**：`InkWeave写作工坊/SKILL.md` + `InkWeave大纲创作院` + `InkWeave设定工坊`。架构 = LLM 生成 + 知识库 / 节点驱动 + 检测器门禁。

## 3. 标点归 LLM（已闭环）
- 主路径 `base-prompt.ts:156-185` 标点铁则（全角弯引号 / 提示语冒号逗号句号 / 引号内点号位置 / 疑问用问号 / 顿号并列 / 中文后半角 / 漏引号逐句核对）。
- 检测器 `checkers.ts` 4 条确定性规则（question_period / tag_colon_mid / cjk_half_punct / repeat_qa）+ 破折号零容忍（error，删 ≤2 额度）。
- **不依赖用户 key**：agent(我) 真加载底座亲自写章 + 检测器验收，零成本。

## 4. 书库零操作用户自建（已闭环）
- **路径一（落地）**：agent 用各书公开设定仿写原创合规样本，填满 `corpus/` 8 本（斩神 / 斗罗 / 完美世界 / 大奉 / 斗破 / 全职 / 灵境 / 第一序列）+ `__selftest__`。每本 ≥2 章、每章 ≥320 字。斗破额外保留起点免费试读第 1 章（标版权）。**用户零买书、零操作**。
- **路径二（可选非阻塞）**：用户授权正版 txt 全量 → 接 C2 微调底座。不强制。

## 5. 蒸馏管道（finetune_prep.py · 已跑通）
- 输入 `corpus/<书名>/raw.txt` → 输出 `finetune_data/train.jsonl`(+val.jsonl)，OpenAI messages 格式，system 指令"好懂优先"。
- 关键常量 / 坑：`SCENE_MIN_CHARS=300`；`heuristic_quality_ok`="的"占比≤6% 且 ≤8 字短句率≤60%；`build_pairs` 需 2 个**相邻**合格场景才出 1 pair；`BOOK_GENRE` 须精确匹配 8 本 key。
- 当前产出：**9 条**续写 pair。
