## 0. 一句话结论

**检测器侧（闭环修正）明确进步，生成侧（文风多样性）未重新量化但有结构性改善信号，产品化侧（分发/流程/度量）仍是老问题未动。** 不能笼统说"进步了"，要分三层看：引擎自身修对了 bug，但 08-17 评价里最致命的"风格多样性 4 分""分发 3 分""度量 2 分"三条，本轮实战**既没有恶化也没有根治**。

## 2. 明确进步的点（有硬数据）

### 2.1 检测器契约自相矛盾——已修（D1）
- **旧状态**：08-17 报告 4.3 指出"知识库节点未真正生效，第14章视觉89次占比过高"。更深的 bug 是：`pre-analysis` 允许视觉基调章视觉>45%，但 `checkers` 无条件硬要求"触觉≥视觉"，导致**8/9 章误报**。
- **当前**：D1 修复后（按实际分布推断基调），**10 章零误报**，视觉基调章（20/25）不再被硬惩罚。
- **判定**：真进步，且是"检测器自己打自己脸"的根因级修复。

### 2.2 排比堆叠——从"统治全章"到"10章零触发"
- **旧状态**：08-17 报告 4.1 把"堆砌递进体"列为最严重问题，第14章被 `穿过X穿过Y`、`往X流往Y流`、`不是…是…` 统治。
- **实测对比**：
  - 第14章（旧，3909字）：`穿过`2 / `往.*流`1 / `不是.{0,4}是`0 / `像`17
  - 十章实战（新，均2435字）：`不是X是Y` 累计仅 19 处（均章≤3，方案B下均合规），**排比堆叠（≥6处 error）零触发**
- **判定**：五感轮换 + 章节镜头侧重 + D2 阈值治理，结构上压制了机械排比。但注意第14章"像×17"的密集比喻问题，新十章未专门核查比喻密度——**比喻堆叠可能是新的隐蔽均质源**，建议下轮加一项 `metaphor_density` 检测器。

### 2.3 长篇稳定性——从"21章样本"到"连续10章 0-error"
- **旧状态**：08-17 报告基于 1 章静态审阅 + 21 章存在性证据，未验证连续门禁通过率。
- **当前**：第17–26章连续 10 章 **100% 通过 error 级门禁**，长程角色/伏笔无断裂，fingerprint facts 章间正确流转。
- **判定**：真进步，证明引擎在长篇规模下门禁闭环稳定。

### 2.4 契约-检测器一致性——已对齐
- 08-17 报告 4.2 痛点"生成与检测两张皮"部分缓解：本轮把铁则十一（字数±10%）、D2（≤2warning/≥3error）、D3（碎句白名单）同步进生成指令正文，检测器与契约不再打架。

## 3. 没有进步 / 仍未解决的点（诚实列）

### 3.1 风格多样性仍是短板（4 分未根治）
- 十章评分落在 C 级（66–79），仅收尾章达 B（86）。C 级意味着"合格但缺乏惊艳节奏"。
- 五感轮换解决了"单一感官霸权"，但**句法节奏多样性**（长短句配比、段落呼吸）仍靠人工扩写时手动控制，引擎未内置"节奏曲线"硬约束。
- **建议**：下轮加 `rhythm_curve` 检测器（章内长短句方差阈值），从工程上锁住节奏多样性。

### 3.2 生成→检测反向闭环仍未打通（08-17 的 4.2 最高优先级建议）
- 08-17 报告建议"每章检测后，把最频繁 2–3 类 warning 写入下一章本章禁忌"。
- 本轮十章实战**未实现此闭环**——warning（感官密度/碎句/质感）每章仍在犯，靠人工事后扩写消解，不是引擎自动规避。
- **判定**：这是"去均匀腔"能否从 C 升 B 的关键，目前仍是最大未解项。

### 3.3 产品化三件套原地踏步（分发/流程/度量）
- 分发（3分）：仍未装成 WorkBuddy skill、无 MCP、无网页壳——卖课前置条件不成立。
- 流程（3分）：仍 `npx tsx` 三步法，抖音电商目标人群（非技术）不可用。
- 度量（2分）：十章实战是唯一进展，但无读者盲测 / 完读率数据。
