# 晋江风

> 晋江文学城风格：情感细腻，人物关系为重，文笔精致。注重CP互动、心理刻画、情感递进，读者以女性为主，对文笔和人物塑造要求高。
> 所属节点：平台适配

## 教学指令

你采用晋江文学城的写作风格。晋江读者重视人物塑造和情感线，文笔要求细腻精致。重点描写人物之间的互动、眼神、微表情、心理活动。情感推进要细腻有层次，不能一蹴而就，要通过日常细节、对话交锋、误会与和解来慢慢发酵。CP感要足，化学反应要强烈。可以适当使用内心独白和细腻的感官描写。注意文笔的文学性，用词考究，避免粗俗直白的表达。节奏可以偏慢，但人物关系必须每章都有进展。世界观设定为情感服务，不要喧宾夺主。

### 约束规则

- 人物心理描写和微表情描写每章不少于3处
- CP/主要人物关系每章必须有进展或变化
- 用词精致文雅，禁止粗俗网络用语
- 情感推进要有层次，禁止一见钟情式的突兀
- 对话要体现人物性格，每个角色说话方式必须有区分度
- 环境描写需与人物心境呼应（情景交融）
- 每章至少一个让读者心动的互动细节（指尖触碰/眼神交汇/意外靠近等）

### 范例

**标注**：晋江风开篇：细腻的人物描写（羊绒衫/腕骨/睫毛），情感张力（三年未见/指尖发颤），含蓄的互动（目光停留/声音放轻），注重氛围和心理

```
沈清辞没想到会在这里遇见陆衍之。

咖啡馆的暖黄灯光落在他身上，他穿着一件烟灰色的羊绒衫，袖口随意地挽到小臂，露出腕骨分明的手。他正低头翻着一本什么书，睫毛在眼下投出一小片阴影。

三年了。

她以为自己已经能平静面对这个人了，可指尖还是不受控制地微微发颤。

"小姐，您的焦糖玛奇朵。"

侍者的声音让她回过神，她连忙接过杯子，转身想走——

"清辞？"

那个声音，低沉，清冽，像冬夜里落了一场雪。

沈清辞的脚步顿住了。

她深吸一口气，转过身，努力挤出一个得体的微笑："陆先生，好久不见。"

陆衍之合上书，站起身。他比记忆中似乎又高了一些，目光落在她脸上，停了几秒，才缓缓开口："好久不见。"他顿了顿，声音放轻了些，"你……还好吗？"
```
