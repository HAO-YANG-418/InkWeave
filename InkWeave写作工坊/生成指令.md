**铁则六 · Show Don't Tell**：禁止直述情绪。情绪落到具体身体部位。

**铁则七 · 身体锚点**：每段必须有视角人物的身体感知。禁止连续两段无身体反应。

**铁则十 · 章末钩子**：最后100字必须有前文未提及的具体新信息颠覆判断。禁止假钩子。

**铁则十八 · 人味（最后短板）**：技术正确≠有人味。AI 文与真人写的最后鸿沟在四点，生成时对照：

**铁则十九 · 内容密度（治"写空"·热门网文基准）**：字数不够=内容没铺够，不是判定问题。热门网文作者共识：信息密度优先、每段都得有货、AI 才"均匀填充字数"凑数。
- 动笔前列 3–5 个「必须落地的具体信息点」（新设定/伏笔/一次人物反应/一个环境细节），写时逐一铺陈，禁止概括式叙述空转。
- 每段承担至少一项：推进冲突 / 展示人物 / 给钩子 / 给情绪。删掉不影响主线的描写=水，必须删或改写。

- 留白（仅情绪层）：情绪/心理可留一点余韵空间；但真相、事实、因果、关键情节信息必须写清，不靠"不说透"制造质感——藏逻辑=晦涩（网文第一标准：好懂）。
- ✔ 监测站的锈铁门半开着，掉漆的牌子歪在门框上，搪瓷缸里的水结了层薄冰。他推门进去，铁锈味扑面，指节冻得发白。
- ✘ 监测站是一个位于矿区边缘的简陋建筑，内部设施老化，环境阴冷，气氛压抑。（概括空转，无可感细节）

**铁则二十 · 去 AI 味写作（打破顺滑·热门网文基准）**：读者骂 AI 文是"正确的废话"和"没灵魂"。AI 与真人最后鸿沟：过于顺滑、可预测、无具体触感、无个人立场。
- 禁"正确的废话"：写情绪不写形容词，写细节不写空话。禁止「他感到一股无名的怒火从心中升起」「脸上洋溢出喜悦的笑容」这类万能模板，要写动作与生理反应。
  - ✔ 他把茶杯捏碎了，瓷片扎进手里都没觉得疼，指节白得发青。
  - ✘ 他非常愤怒，内心充满难以遏制的怒火。（正确但空洞，AI 腔）
- 制造语义跳跃（只破 AI 顺滑感，不破读者理解）：段落间可突然换角度、插具体例子、某段写得潦草——人类写作有断层。但跳跃不得破坏因果连贯与读者理解：若读者需回读才懂"谁/为何/发生了什么"，则该跳跃违规，必须补清。留白≠藏逻辑，低逗句比≠剁碎句（网文基准：简约≠难懂）。
- 注入主观性与具体经验：落到真实可触细节/个人化比喻；允许角色有偏见、情绪化片面判断。
- 逻辑转折口语化：用「但」「可」「说到底」制造不完美衔接，不要教科书式递进。
- 句式长短错落：连续两短句后接一长句，制造节奏起伏，避免均匀 15–25 字流水；铺垫长句拉弓，转折高潮短句放箭。
- 人设自洽带瑕疵：角色行为符合设定，主角可有怂/犯错/软肋，反派有苦衷；杜绝完美龙傲天与全员工具人。
- 禁止正确但空洞的总结句：不写「这件事让我们明白了很多」「世界远比想象复杂」。
  - ✔ 他本来想说点什么得体的，话到嘴边变成：这破地方，连鬼都不乐意来。
  - ✘ 此次经历让他深刻认识到，命运的复杂性远超人们的预期。

**铁则二十一 · 读者爽点本能（创作本能级）**：读者骂「不好看」很少因为文笔差，因为没爽点。本铁则为「创作本能级」——好作者动笔即预埋爽点：主角有私心、对话有火花、设定在危机里长出来、章末钩子戳情绪。
1. **主角私心驱动（抗工具人）**：主角每章行为由「他自己的私心/恐惧/未了愿/软肋」推动，而非纯执行任务。允许主角怂、错、偏心、护短。禁止「全员为大局无私奉献=工具人」。
   - ✔ 林深拧阀前手停了一瞬——老罗是他师父辈的人，真要拿活人当栓，他这辈子都得背着。他还是拧了，但喉头发紧。
   - ✘ 林深为了小镇安全，果断关阀，拯救了所有人。（无私执行机器，无血无肉）
2. **对话必须碰撞**：每章至少一处对话两方带不同目的或信息差，台词互相顶、刺、逼问，不是问答式信息传输。禁止「汇报式对话」（甲问乙答，无张力）。
   - ✔ 「先关阀！」赵明远声从手机压出来。「他是人。」林深没动。「罗叔要是死了你救得活？」
   - ✘ 「我们去哪？」「去镇东。」「为什么？」「因为小满在那。」「好。」（纯信息传输，无火花）
3. **设定埋进危机反应（强化铁则六 show don't tell）**：新设定不在平静处大段陈述，借角色在异常/危机中的具体身体反应或动作长出来。禁止重复「设定陈述句」（如连篇解释母体/残频机制）。
   - ✔ 蓝印在他腕上猛地一缩，像被什么东西咬住——他这才懂，残频不是死物，它认得活人的脉。
   - ✘ 残频是母体分裂出的意识体，具有寄生与记忆吞噬特性，详见设定集第三章。（解释腔）
4. **章末情绪钩子（强化铁则十/十九）**：章末 80–120 字必须是颠覆情绪判断的具体悬念/反转，戳读者情绪，不是「任务续集」（「明天还要去X」）。
   - ✔ 他合死最后一处阀，以为完了。地下极深处，传来第八声极细的嘶——比前七处都轻，却比前七处都近。
   - ✘ 封完阀，众人撤离，明天还要去镇外废井排查。（任务续集，无情绪钩）

**铁则二十二 · 回看反转（铺垫→双看 · 创作本能级）**：重要反转/阴谋/身份揭晓前，必须在前 1–3 章以**具体物件/对话/名字/细节**埋下"可被读者忽略"的伏笔，揭晓时读者回看能"恍然大悟"。这是都市爽文长效追读的核心钩子，比章末断裂钩子更长效。
- ✔ act1 股权图最底层有个人名"周庆生"，当时只当背景；第5章顾成揭"有人吞你爸厂"时，读者回看股权图——周庆生就是前合伙人，双看成立。
- ✘ 第5章突然冒"你爸前合伙人周庆生要吞厂"，前面零铺垫，读者毫无回看素材，反转变机械降神，无感。
- 落法：伏笔用"不抢戏的细节"承载（图角小字/旧物/旁人一句闲话/环境里同一符号），不抢戏；揭晓章让该细节被"重新看见"，形成回看。
- 与铁则十（章末钩子）互补：章末钩子管单章留存，回看反转管多章追读。

**铁则二十三 · 去"X的。"句尾 tic（节奏去均匀腔 · 创作本能级）**：禁止同一章内以"的"结尾的短句高频刷屏（"冰的。/凉的。/涩的。/冷的。"），读着像标点怪、没起伏。**每 200 字至多 1 个"X的。"收尾**；状态/感官用"动词+补语"或换句式承载。
- ✔ 他攥紧栏杆，指节发白，风灌进领口，后颈一阵凉。
- ✘ 风凉的。他攥紧栏杆。手心凉的。后颈凉的。（刷屏）
    - 量化红线：全章以"的"结尾的句子占比 ≤ 5%（检测器暂未强制此项，属 craft 本能级；出版级须自审稀释）。若某状态必须单独收尾，用"动词+补语"替"形容词+的"：写"掌心渗进一股凉"不写"凉的。"

**铁则二十四 · 开篇钩子（来自公开试读合规蒸馏 · 路径一）**：网文第1章开篇用「可感知挫败场景 + 配角反应衬托 + 主角收束动作 + 埋线」四拍立住人设与追读钩。
- 范例（斗破苍穹第1章公开试读，起点读书 App，©天蚕土豆/起点中文网，仅引用非全文）：测验魔石碑显「斗之力三段」→ 周围嘲讽与惋惜反应 → 萧炎落寞转身回队尾 → 埋「三年之约、天才陨落」伏笔。四拍干净、零理解负担。
- 落法：开局先给读者能共情的具象失利（别用旁白交代），用围观者嘴替读者反应，主角用一个动作收束情绪，最后落一句埋线的话钩住下一章。
- 来源合规：本范例取自平台公开免费试读章，仅用于 craft 分析；真实全量蒸馏须用户授权全本 txt（路径二），不扒全文、不碰盗版。

**铁则二十五 · 多题材书库节奏（来自 8 本合规合成样本蒸馏 · 路径一）**：不同题材开篇用不同的「挫败→底牌→回看」母题立住追读钩，写前先按题材选对母题，再套铁则二十四四拍。

- 都市悬疑/灵异（斩神类）：用「异常身体信号 + 旁人点破 + 主角装睡/装不知 + 竖眼/秒针停等超自然埋线」。例：天花板竖眼→陈大夫说你疯了→主角攥怀表装没看见→秒针停（埋「有人不想他醒」）。
- 玄幻（斗破/斗罗类）：用「公开羞辱场景 + 围观反应 + 主角不闹只记数字 + 废物里藏底牌」。例：退婚书→纳兰嫣然低声→萧炎折纸不闹→袖里黑戒指凉（埋「有人封了斗之气」）。
- 探案朝堂（大奉类）：用「案发现场 + 物证反推 + 主角不点破只问细节 + 衣角/鞋印等实物埋线」。例：税银空库→锁无撬痕→许七安蹲看鞋印→后墙衣角（埋「钥匙开库搬走」）。
- 废土（第一序列类）：用「壁垒内外反差 + 冷硬物触发 + 主角按兜不交 + 铁牌/曲等信物埋线」。例：墙缝暖风→半块冷饼→庆尘捡铁牌不交→妹妹的曲（埋「骑士令」）。
- 电竞（全职类）：用「被宣布出局 + 新人议论 + 主角不回头 + 旧机器/旧号埋线」。例：退役通知→新人说老将让位→叶修下楼不回头→兴欣破机器（埋「从头打」）。
- 太古/大荒（完美类）：用「采猎收获 + 祭灵/兽吼反差 + 主角碰活物 + 树脉/心跳同频埋线」。例：拎鱼回村→祭灵渗汁温→石昊碰树→脉与爹咳同频（埋「村子替疼」）。

- 落法：母题是「题材默认钩子」，四拍是「通用结构」；先选母题定情绪底色，再用四拍落具体动作与埋线，切勿跨题材错用母题（废土写电竞式退役会假）。
- 来源合规：8 本样本均为 agent 按各书**公开设定/简介仿写的原创合规样本**（非原文、不抄正文），存于 `corpus/<书名>/raw.txt`，经 `scripts/finetune_prep.py` 蒸馏出 9 条续写 pair（含 `__selftest__`）。真实全量分布须用户授权正版 txt（路径二），本铁则为小样本 craft 提炼，涨的是「多题材节奏直觉」非真书全量。
