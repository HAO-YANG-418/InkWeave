# 桥段卡：案发现场反推

- **母题**：离奇案件 + 现代/专业逻辑拆解
- **结构**：①凶案/奇案现场（尸体/密信/异象） → ②众人误判方向 → ③主角抛出现场物证反推（公平线索） → ④真凶意外 + 牵出更大阴谋
- **情绪曲线**：谜(0-30%) → 偏(30-50%) → 推(50-80%) → 惊(80-100%)
- **钩子位**：章末留「凶手在在场者里」或「案子连着朝堂」
- **适配题材**：探案朝堂 / 悬疑 / 历史
- **来源书**：大奉打更人（结构提炼，非原文）
- **禁忌**：禁止推理跳跃（须给读者公平线索）；禁止案件烂尾不收；禁止主角降智配合反派
