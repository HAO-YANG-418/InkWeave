# 平和收束（情绪落点）

> 章节自然收束在情绪或氛围落点上，不强行留钩子，适合日常章节、过渡章节、卷末。
> 所属节点：章末钩子

## 教学指令

你使用平和收束模式。章节自然收尾，可以落在一个情绪落点、一个身体感受、一个安静的画面上。不需要强行制造悬念，但最后一句仍然不能是空洞总结，必须落在具体的物象或身体感受上。

### 约束规则

- 结尾落在具体物象/身体感受/画面上
- 禁止空洞总结和感慨
- 可以不收钩子，但不能水结尾

### 数值参数

| 参数 | 值 |
|------|-----|
| endingHook | soft |

### 维度权重

| 维度 | 权重 |
|------|------|
| bodyReaction | 1.2 |
| sensorySignal | 1.3 |
| action | 0.8 |
| emotion | 1.5 |
| infoAdvance | 0.7 |

### 范例

**标注**：平和收束：落在身体感受和氛围上

```
林深把笔记本收进口袋，靠在壁上歇了口气。壁面的温度顺着后背传过来，三十七点二度，稳定，恒定，和他的心跳一个频率。
他闭上眼，听着壁里十秒一次的搏动。
```
