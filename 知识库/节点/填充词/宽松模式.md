# 宽松模式

> 宽松填充词检测，允许更多过渡和渲染词汇。maxFillerSentences=5, maxFillerWords=12。适合节奏较慢、描写丰富的文风，或对水字数容忍度较高的平台。
> 所属节点：填充词

## 教学指令

你使用宽松填充词检测模式。在这个模式下，大部分过渡词、情绪渲染词、节奏调节词都被允许，只有极端明显的凑字数（如整段重复、毫无意义的胡言乱语）才会被标记为填充。宽松模式允许作者自由使用形容词、副词、感叹词、过渡句来调节行文节奏和氛围。网文读者习惯了一定量的“水”来缓冲节奏，只要不是太过分就可以接受。但注意：宽松不等于纵容，整段照搬前面的内容、毫无意义的凑字数、连续多句什么都没说——这些仍然需要修正。

### 约束规则

- 每千字填充词句不超过5句
- 每千字填充词不超过12个
- 允许自由使用过渡词、渲染词、感叹词
- 允许套路化表达（适度），但禁止连续使用
- 禁止整段重复已有内容
- 禁止连续3句以上完全无信息量
- 允许心理描写和情绪渲染，即使不直接推进剧情

### 数值参数

| 参数 | 值 |
|------|-----|
| maxFillerSentences | 5 |
| maxFillerWords | 12 |
| maxDashCount | 5 |
| maxEllipsisCount | 5 |

### 维度权重

| 维度 | 权重 |
|------|------|
| bodyReaction | 0.9 |
| sensorySignal | 1 |
| action | 0.8 |
| emotion | 1.2 |
| infoAdvance | 0.8 |

### 范例

**标注**：宽松模式：允许较多的情绪渲染和感叹词，只要不是纯粹凑字数

```
张浩站在山顶，俯瞰着脚下连绵起伏的群山，心中不由得涌起一股豪情壮志。

是啊，他经历了那么多，付出了那么多的努力和汗水，终于站到了今天这个位置。回想当初，他只是一个什么都不懂的毛头小子，谁能想到他能有今天？

不得不说，命运这个东西，有时候真的很奇妙。

他深吸一口气，山风猎猎，吹动他的衣袍。远方，夕阳正缓缓沉入群山之间，将整个天空染成一片壮丽的金红。

（宽松模式允许这类情绪渲染和感叹，虽然不直接推进剧情，但有助于氛围塑造和情绪共鸣）
```
