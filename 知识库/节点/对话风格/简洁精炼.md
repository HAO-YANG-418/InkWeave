# 简洁精炼

> 对话极简，话少意多。适合硬汉、高冷角色、悬疑场景、矿工等沉默寡言的人物。
> 所属节点：对话风格

## 教学指令

⚠️ 好懂红线（2026-08-31 钉死）：克制≠难懂，留白≠藏逻辑，简练≠不说清。含蓄/克制/留白/省略**只适用于情绪层**（不直说角色感受），**绝不适用于信息层**——事件因果、动作链、谁做了什么、设定逻辑必须写清，读者零回读。任何写法一旦让人需回读才懂，立即让位给"读着顺"。网文第一标准是好懂。

⚠️ 补充（2026-08-31）："话少信息多"的潜台词留给**态度和情绪**（不说"我很生气"），**关键事实、动机、事件因果不许全靠读者从动作里猜**——该说清的一句台词说清，藏信息不等于高级。

简洁精炼对话的核心是'话少信息多'。人物不多话，但每句话都有分量。沉默本身就是对话。具体技法：

1. 字数控制：单句对话不超过15字，极端情况可以1-3个字。能说两个字不说三个字，能用动作代替就不说话。回答常常是一个字、一个点头、一个眼神。

2. 潜台词密度极高：每句话背后都有没说出口的东西。'走了。'可能是'我走了你别死'。'嗯。'可能是'我听到了我不同意但我懒得跟你争'。读者要从上下文和动作里读出来。

3. 沉默的使用：不回答本身就是回答。停顿、犹豫、转移视线、转身就走——这些非语言反应比说话更有力。对话之间可以插入大段动作描写，制造沉默的重量感。

4. 禁止解释性对话：角色不会把自己的意思解释清楚，不会说'我生气是因为你昨天骗了我'这种话。情绪要读者自己体会。

5. 问答不对称：问三句答一句，答非所问，或者用问题回答问题。不配合对话本身就在塑造人物性格。

6. 动作重于语言：当一个动作可以表达态度时，绝不用语言。放下茶杯的力度、走路的速度、看人的角度——这些都在说话。

### 约束规则

- 单句对话原则上不超过15字，多数对话在10字以内
- 连续对话不超过3句必须穿插动作/环境描写，且动作描写字数应多于对话字数
- 禁止解释性台词（角色把自己的情绪、动机、计划直接说出来）
- 对话标签'XX道/说'每千字不超过5次，绝大多数对话用动作引入或不标签
- 每段对话场景中至少有1次沉默/不回答/用动作代替回答
- 禁止使用感叹号超过对话总句数的10%，简洁角色不轻易激动外露
- 禁止出现'我觉得''我认为''你听我说'等啰嗦开场

### 范例

**标注**：极简对话示范：整段200多字只有6句对话，每句不超过5字。'老李没说话''老李没回答'是沉默的用法。'35.8'一个数字包含全部信息，不需要解释这意味着什么。结尾'走'一个字，比'我们走吧''赶紧离开这里'有力一百倍。动作描写（胳膊垂着/手指抖/膝盖打弯/浮尘一动不动）承载了绝大多数信息。

```
铜碗放在膝上，水已经凉了。他没喝。

洞口的光暗了一度。

「老李。」他说。

没人应。

他等了三秒，端起铜碗喝了一口。水锈味。

「该你了。」

阴影里动了一下。老李爬过来，动作很慢，右胳膊垂着，使不上劲。他接过铜碗的时候手指在抖。

「壁温多少？」

「35.8。」

老李没说话。他知道这意味着什么。正常是32度。

「还能走吗？」

老李没回答，把铜碗递还给他，撑着壁面站起来。膝盖打了个弯，但他站住了。

他把矿灯拧亮，光柱里浮尘一动不动。

「走。」
```
