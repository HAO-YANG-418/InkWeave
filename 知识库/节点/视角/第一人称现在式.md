# 第一人称现在式

> 以“我”的视角叙述，使用现在时态。临场感极强，仿佛事件正在读者眼前发生，适合紧张刺激的悬疑、惊悚、沉浸式体验作品。
> 所属节点：视角

## 教学指令

你使用第一人称现在式进行写作。叙述者是“我”，所有事件都用现在时态描述（“我走”“我看到”“我在想”），仿佛一切正在发生。这种时态带来极强的临场感和紧迫感，读者和主角同步经历事件，不知道下一秒会发生什么。你只能写“我”此刻的感知和想法，不能提前透露未来的信息（不能写“后来我才知道”“这是我最后一次见他”之类的话，因为在现在式中“我”不知道未来）。内心独白用现在式，感官体验正在发生，决定正在做出。注意时态绝对一致，不能出现过去式（除非角色正在回忆，可以短暂切换但要立即回到现在式）。

### 约束规则

- 叙述视角严格为第一人称“我”，时态严格为现在式
- 只能写“我”此刻的感知，禁止提前透露未来信息
- 禁止使用“后来”“之后”“那是我最后一次”等打破临场感的表述
- 内心活动、感官体验、动作决定都用现在式表达
- 回忆段落必须明确标记（如“我想起”），且不能过长，立即拉回现在
- 他人心理只能通过当下的表情、动作、语言推测
- 利用现在式优势：制造紧迫感、即时恐惧、临场决策的紧张感

### 范例

**标注**：第一人称现在式：全程现在时态（推开/摸索/找到/倒吸/发抖/传来），临场感极强，没有事后回顾的距离感，读者和主角同步紧张

```
我推开门。

屋子里很暗，窗帘拉得严严实实。我的手沿着墙壁摸索，找到开关——

灯亮了。

我倒吸一口冷气。

墙上贴满了照片。全是我。我在公司加班的样子，我在超市挑苹果的样子，甚至有我在卧室里睡觉的样子。有人在跟踪我，而且不是一天两天了。

我的手在发抖。我强迫自己深呼吸，掏出手机。拨号，110——

身后传来脚步声。

很轻，很慢。但在这死寂的屋子里，每一步都像敲在我的太阳穴上。

我猛地转身。
```
