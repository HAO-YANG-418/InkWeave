## 一、架构纠正（关键）

- 此前误判"无 `llm.json` key 则无法生成初稿"——**站错视角**。
- 真部署：InkWeave = skill，运行在主机 agent（WorkBuddy）内，**主机 LLM 即生成器**。本 agent 直接按 `生成指令.md` 的 20 条铁则 + 裂日 `config.md` 22 节点配方 + `pre-analysis` 注入的上章指纹禁忌，写出第27章。全程零 key、零 API 调用。
- 结论：`gwe-engine.ts` 的"自持 key 调 API"路径是**独立 CLI 模式的兜底**，不是 skill 装载形态的必要组件。
