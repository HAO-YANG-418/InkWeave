> 前置：P0 去均匀腔(v5.1) 已完成，表层去 AI 味(5/5)、长程一致性(P1+P1.5) 已齐备。

## 一、诊断：人味到底缺什么

对真实第16章《共振》(93/A) 做五维人味审计：

| 维度 | 本章现状 | 判定 |
|------|----------|------|
| 生活质感细节 | 糖纸窸窣、指甲掐出月牙、铁锈硌红印、枕上湿印——**做得好** | 不缺，正向保留 |
| 身体锚点/感官 | 凉/涩/麻质感链贯穿，密度充足 | 不缺（P0 已保） |
| 情感弧线（层次） | 情绪几乎只用"骨温三十七度一/数值锚点"平铺，**无克制→溃堤→余波层次** | **缺** |
| 留白/未说出口 | 关键对话全部"说完了"（赵明远讲完第三种选择、林浅点破母体藏进频率），无欲言又止/用动作替语言 | **缺** |
| 角色声音独一性 | 林浅/周野/赵明远说话方式是否有区别**不可检测、未引导** | **缺（不可见）** |
| 自嘲/反讽/幽默 | 三少年救世全程零调侃，对自身处境荒诞无半句自嘲 | **缺** |

**结论**：第16章证明 InkWeave 已能写出"技术正确 + 有质感"的文本，但系统性缺**情感层次、留白、自嘲反讽、角色声音可验证**。这正是 AI 文与真人写的最后鸿沟。

## 二、P2 边界（只做可落地子集）

不做（超出规则检测能力、需 LLM 或主观判断）：
- 不强行检测"是否好笑"（幽默不可规则判定）→ 改为**生成指令正向引导**。
- 不把"生活质感"做成强制检测（会误杀好文本）→ 改为**正向引导**。

做（可规则检测、全 warning 级不阻塞门禁）：
- **D1 情感弧线缺失** `emotion_arc`
- **D2 留白/未说出口缺失** `unsaid_gap`
- **D3 角色声音指纹跨章冲突** `voice_drift`（复用 P1 extract-entities）
- **G 生成指令铁则十八·人味**（正向引导，含 ✔✘）

## 三、检测器设计

### D1 · emotion_arc（情感弧线缺失）
信号：
- 平铺情绪标记：数值化情绪锚（`三十七度`/`骨温`/`心跳`/`体温`类）、单一感官词堆叠。
- 层次标记（稀缺即缺）：欲言又止/克制类（`忍住`/`咽下`/`没说出口`/`到嘴边又`/`攥紧`但没发声/`别过头`）、释放类（`终于`/`脱力`/`笑出声`/`眼眶`）。
逻辑：若章内"平铺情绪密度"高（≥N 处数值锚+感官堆叠）且"层次标记"为 0 → warning，建议制造情绪层次（从忍到溃堤到余波）。
注意边界：纯动作/冷硬风格文本（如海明威式）也可能层次标记少——故仅当"情绪词密度高但层次标记为 0"才报，避免误杀冷叙事。

### D2 · unsaid_gap（留白缺失）
信号（留白标记）：
- 对话截断（`……`/`他没说完`/`话卡在`/`咽了回去`）
- 用动作替代语言（`转过身`/`低头`/`把话咽下`/`踢了踢地`/`望向别处`）
- 环境替角色说（用景物/物件承接情绪，无直述）
逻辑：若对话占比 > 8% 且全章留白标记 = 0 → warning，建议至少 1 处"没说破的"。
边界：对话极少的章（<8%）不报——冷硬独白本就少对话。

### D3 · voice_drift（角色声音指纹跨章冲突）
复用 `extractChapterFacts` 已抽的角色 present/惯用词。新增：每章为每个 present 角色提取"语言指纹"（语气词/惯用语/句式长度偏好），与上章同角色指纹比对，突变（如林浅上章用"轻声"，本章突然满口书面语）→ warning。
实现：在 `ChapterFact` 扩 `voicePrint` 字段；`checkCrossChapterFacts` 加 voice 比对分支（warning 级）。
降级：首章/无上章指纹 → 不报。

## 四、生成指令（铁则十八·人味）

正向引导四条，每条 ✔✘：
1. **情感要分层**：从克制（忍/咽/别过头）→ 溃堤（终于/脱力/笑出声）→ 余波（事后身体残留），不要通篇用数值平铺情绪。
2. **留白**：关键情绪用"没说破"承接——对话截断、动作替语言、环境替角色说。不是每句话都要说完。
3. **角色声音独一**：给每个常驻角色一个语言指纹（惯用语/语气词/句式），跨章稳定，不串味。
4. **自嘲反讽**：角色对自己处境的荒诞可有一两句调侃，人味常从此来。
