# 写前分析

> 在加载「生成指令.md」之前执行。分析完成后，将结果填入生成指令的"本章简报"区域。

---

## 第1步：意图分析

读取 `详细规则/意图策略.md`，确认本章意图的：
- 情绪基调
- 节奏（短句/混合/长句）
- 禁止模板
- 开头策略（2选1，不重复上章）
- 章末钩子策略（意图专属钩子4选1，不重复上3章）

**输出**：
```
意图：[类型]
情绪基调：[XX%]
节奏：[短句/混合/长句]
禁止模板：[...]
开头策略：[策略名]
钩子策略：[钩子名]
```

---

## 第2步：冷却检测

读取 `知识库/数据/冷却模式库.md`。

逐项对照54个冷却模式，输出冷却清单：
- 开篇模式冷却（5章）：哪些模式本次禁用
- 战斗描写冷却（3章）：哪些描写方式禁用
- 情绪陈词冷却（3章）：哪些情绪表达禁用
- 转折信号冷却（2-3章）：哪些转折词禁用
- 对手原型冷却（8章）：哪些反派类型禁用
- 效果修饰冷却（3章）：哪些修饰词禁用
- 对话套路冷却（4-5章）：哪些对话模式禁用
- 心理描写套路冷却（3章）：哪些心理描写禁用
- 环境描写套路冷却（3-4章）：哪些环境描写禁用
- 情节模板冷却（8-12章）：哪些模板禁用

**输出**：
```
## 冷却清单
- 禁用模式：[列出所有在冷却期内的模式及替代写法]
- 禁用情节模板：[列出]
- 禁用对手原型：[列出]
```

## 第3步：前文衔接

读取上3章正文，确认：
- 收束模式：上3章各用哪种收束模式（手→物/眼→光/脚→地/骨→热/剑→血），本章轮换用哪个
- 未解决冲突：哪些冲突需要本章推进
- 角色状态：各角色当前位置、身体状态、情绪状态
- 伏笔到期：哪些伏笔必须在本章触碰（对照本项目根 `伏笔/伏笔追踪表.md`）

**输出**：
```
- 收束模式轮换：[上章用X] → [本章用Y]
- 未解决冲突：[...]
- 角色状态：[...]
- 到期伏笔：[...]
```

## 第3.5步：元件卡库调用（拆书骨架 · P1 产物）

> 来源：`知识库/元件卡库/`（L0 母题卡 / L1 桥段卡 / L2 章法卡）。本步为镜头链规划提供"写什么结构"的骨架，与节点系统控"怎么写"正交。

**调用顺序**：
1. 读 `知识库/元件卡库/母题卡/<本书>.md` → 定本章基调（母题/核心冲突/价值主张）。
2. 按本章意图从 `知识库/元件卡库/桥段卡/` 选 1–2 张作骨架（如「退婚打脸」「底牌揭晓」），读其结构4步+情绪曲线+钩子位。
3. 读 `知识库/元件卡库/章法卡/<本书>.md` → 取章首钩子公式 + 章末钩子类型（按轮换表选，忌连章同型）+ 回报间隔。

**输出**（写入第5步生成简报的「结构卡」字段）：
```
## 结构卡
- 母题：[来自母题卡]
- 选用桥段：[桥段卡名 ×1-2，含结构4步摘要]
- 章首钩子：[章法卡公式实例化]
- 章末钩子类型：[轮换表选型，忌连章同型]
- 回报间隔：[小爽/中爽/大反转节拍]
```

**门禁**：未读母题卡 + 未选桥段卡 + 未读章法卡 → 禁止进入第4步。桥段选型须与本章意图匹配（详见各卡「适配题材」），严禁跨题材错配（如悬疑章用退婚打脸）。

## 第4步：镜头链规划（强制前置，不交规划不准写正文）

**实战教训**：跳链生成是碎句和字数超标的根因。没有规划的章节=4000字草稿，靠修补永远修不出3000字精品。

**规划要求**：
1. 将本章拆分为4-6个场景（≤6个，超过则碎片化）
2. 每个场景必须指定：镜头类型、预估字数、核心任务
3. 每个场景的镜头链必须完整：人物动作→光线/视线落点→身体触点→外界物理反应→本拍落点
4. 对话占比控制在25%以内（对话场景压缩为1-2个）
5. 总预估字数控制在目标字数的90%-110%（给细节留弹性，但绝不超20%）

**输出格式**：

```
## 镜头链规划

| 场景 | 镜头类型 | 字数 | 核心任务 |
|------|---------|------|---------|
| 1. [场景名] | [移动/触摸/信息/压力/对话/收束] | XXX | [一句话描述] |
| 2. [场景名] | [镜头类型] | XXX | [核心任务] |
| ... | ... | ... | ... |

总预估字数：XXXX（目标：[目标字数]）
```

**门禁**：镜头链规划未完成，禁止进入生成阶段。规划中发现场景数>6，必须合并场景。

### 第4.5步：规划自检（写前预警，提前发现结构问题）

**目的**：把写后检查中常见的"场景碎片化"和"对话过载"问题提前到写前发现。规划阶段调整比写完重写成本低10倍。

**自检项**：

| # | 检查项 | 阈值 | 不通过处理 |
|---|--------|------|-----------|
| 1 | 场景数量 | 4-6个 | >6 → 合并相邻同类型场景，重新规划 |
| 2 | 对话场景占比 | ≤2个对话镜头 | >2 → 压缩对话场景，合并为1-2个含对话的混合镜头 |
| 3 | 字数预估 | 目标±10% | 超标 → 缩减场景字数或合并场景 |
| 4 | 镜头类型多样性 | ≥3种镜头类型 | <3 → 替换重复镜头类型，增加信息/压力/触摸镜头 |

**输出**：
```
## 规划自检
✅ 场景数量：X个（合规）
✅ 对话场景：X个（合规）
✅ 字数预估：XXXX字（目标±X%）
✅ 镜头多样性：X种（合规）
```

**门禁**：4项全部 ✅ → 进入第5步。任一 ❌ → 调整规划后重新自检。不得以"写的时候注意"为由跳过。

## 第5步：生成简报

汇总以上分析，填入生成指令的「本章简报」区域：

```
- 本章意图：[类型] | 情绪：[XX%] | 节奏：[...]
- 核心冲突：[从哪到哪]
- 开头策略：[...]
- 钩子策略：[...]
- 禁用：[冷却清单摘要]
- 收束模式：[本章用X]
- 到期伏笔：[...]
- 外部压力：[...]
- 结构卡：[母题/选用桥段/章首钩子/章末钩子类型/回报间隔]（来自第3.5步元件卡库）
```

简报写完后，加载 `生成指令.md`，开始生成正文。

### 第5.5步：伏笔台账回写（P3 持久化记忆）
生成完成后，将本章埋设的新伏笔与已回收伏笔写入本项目根 `伏笔/伏笔追踪表.md`：
- 新伏笔：[伏笔名 | 埋设章 | 状态=进行中 | 计划回收章]
- 回收伏笔：[原伏笔名 | 本章回收 | 状态=已揭示]
下章第3步「前文衔接」读取此表确认到期伏笔，形成跨章持久化闭环（治长篇遗忘 / 伏笔超期）。
