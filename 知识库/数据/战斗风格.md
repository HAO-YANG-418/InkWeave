# 战斗风格

> 5种战斗描写风格，每种各有阶段和描写要点

## 风格速查

| 风格 | 适用场景 | 句式特点 | 节奏 | 描写重点 |
|------|---------|---------|------|---------|
| 碾压流 | 主角实力远超对手/展示成长/建立威慑 | 短句，5-12字，高密度动作 | 快 | 对手反应+旁观者震惊 |
| 苦战流 | 势均力敌/生死之战/越级挑战 | 短中混合，关键时刻用短句 | 快→慢→快 | 伤势累积+双方消耗+极限突破 |
| 智斗流 | 战术博弈/能力克制/信息战/陷阱 | 中长句，穿插推理 | 慢→快 | 战术分析+预判+反预判 |
| 意境流 | 高手对决/修炼感悟/重要战斗 | 长句，诗意描写 | 慢 | 意象+氛围+力量本质 |
| 群战流 | 团战/混战/多角色战斗 | 短句，频繁切换视角 | 快 | 空间位置+角色标记+战局变化 |

## 风格详解

### 碾压流

**核心原则**：读者不需要知道主角多强，需要知道对手多惨。

**三阶段结构**：
1. 对手出手 → 描写对手的全力一击（让读者觉得"这招很强"）
2. 主角出手 → 轻描淡写，一拳/一脚/一指，不做多余动作
3. 结果 → 对手的反应（震惊/恐惧/崩溃），旁观者的反应

**描写要点**：
- 主角不报招式名，不解释能力
- 战斗时间短（3-5段），节奏快
- 重点写对手的"不敢相信"和旁观者的"目瞪口呆"
- 用具体效果代替"恐怖"等空泛修饰

### 苦战流

**核心原则**：读者要感觉到"主角真的会输"，每一击都有代价。

**四阶段结构**：
1. 试探 → 双方试探，各有损伤
2. 压制 → 对手占据上风，主角受伤
3. 转折 → 主角找到破绽/突破/使用底牌
4. 决胜 → 极限一击，代价巨大

**描写要点**：
- 累积伤势：每段战斗后更新伤势（左臂废了/肋骨断了/视线模糊）
- 双方消耗：不只是主角受伤，对手也在消耗
- 极限突破要有铺垫（前文埋过伏笔）
- 战后必须有代价（不能打完就恢复）

### 智斗流

**核心原则**：读者不是在"看"战斗，而是在"解"战斗。

**三阶段结构**：
1. 设局 → 主角分析对手能力/环境，制定策略
2. 执行 → 按策略行动，但对手有反制
3. 破局 → 主角预判了对手的反制，真正底牌揭示

**描写要点**：
- 战术分析通过角色内心/对话自然带出，不要大段说明
- 读者和主角信息同步（不要主角知道读者不知道）
- 对手也要聪明（对手的应对要合理）
- 每次智斗的核心机制不同（不能每次都是"预判了你的预判"）

### 意境流

**核心原则**：战斗不是打斗，是力量本质的碰撞。

**结构**：意象建立 → 力量交锋 → 意境升华 → 结果

**描写要点**：
- 用意象代替动作：不是"剑刺过来"，而是"一道寒光撕开夜幕"
- 力量本质可视化：火焰不是真火，是力量的具象
- 慢不是拖沓，是用描写制造重量感
- 适合揭示世界观力量体系的战斗

### 群战流

**核心原则**：读者要能追踪每个角色的位置和状态。

**结构**：空间建立 → 分组战斗 → 战局变化 → 关键转折

**描写要点**：
- 开始前建立空间关系（谁在什么位置，面对谁）
- 每个角色有识别标记（武器/颜色/能力特征）
- 切换视角有明确标记（段落分隔/空行）
- 战局变化要清晰（哪边优势/劣势转换）
- 不超过4个主要战斗视角

## 使用约束

- 同一卷内不得连续3章使用同一种战斗风格
- 碾压流和苦战流交替使用
- 智斗流每卷最多2次
- 意境流每卷最多1次（用于关键战斗）
- 群战流需在前一章末尾建立角色位置
