# 角色档案

> 项目：阈限校园 | 设定工坊 v4.0 | 2026-08-13

---

## 主角：林深

| 项目 | 内容 |
|------|------|
| 年龄/身份 | 17岁，高二（3）班学生 |
| 外貌 | 瘦高，校服袖口磨得发白，左手虎口有块烫伤疤——小时候被开水壶烫的，疤的形状像一片碎掉的叶子 |
| 性格核心 | 观察力极强但习惯沉默——他能注意到别人忽略的细节，但从不主动说，因为说了也没人信 |
| 个人动机 | 藏。他不想当英雄，只想正常毕业。但他发现藏不住了——每次他感知到异常，那些东西也在感知他 |
| 核心冲突 | 用能力=暴露自己，不用能力=看着身边的人被替换 |
| 说话方式 | 话少，回话经常慢半拍，不是反应慢，是在想怎么说最安全。示例："嗯。"（停顿三秒）"你刚才说'她'——你确定是'她'吗？" |
| 角色弧 | 隐藏者→被迫暴露→成为靶子→主动反击→成为觉醒者的灯塔 |
| 与其他角色关系 | 周野（同桌/好友）、林浅（妹妹）、陈老师（班主任，态度暧昧） |

---

## 配角1：周野

| 项目 | 内容 |
|------|------|
| 年龄/身份 | 17岁，林深同桌，体育委员 |
| 外貌 | 肩膀宽，校服永远敞着穿，右手腕上戴三条不同颜色的橡胶手环——红的是献血送的，蓝的是音乐节，黑的不知道哪来的 |
| 性格核心 | 热心但神经大条——他信直觉不信逻辑，偏偏直觉经常准得离谱 |
| 个人动机 | 保护身边的人。他不知道自己为什么总是能提前感到危险，他以为只是"运气好" |
| 核心冲突 | 潜意识里也在觉醒边缘，但他自己不知道——他的直觉是"初觉"的前兆 |
| 说话方式 | 话多，声音大，喜欢用反问。示例："你不觉得今天班主任有点怪吗？就那种——怎么说呢，她平时念通知会推眼镜的，今天没推。" |

---

## 配角2：班主任·陈老师

| 项目 | 内容 |
|------|------|
| 年龄/身份 | 34岁，高二（3）班班主任，教物理 |
| 外貌 | 戴银色细框眼镜，左手无名指有戒痕但没戴戒指，衬衫永远扣到最上面一颗 |
| 性格核心 | 尽责但恐惧——她在保护学生，但她的保护方式是不告诉他们真相 |
| 个人动机 | 守住底线。她知道一些事，但不能说——说了会引起恐慌，恐慌会让「摹本」更容易渗透 |
| 核心冲突 | 知情者，但不被信任。学生们觉得她在隐瞒什么——她确实在隐瞒 |
| 说话方式 | 每句话都像经过删减，停顿时嘴唇会抿一下。示例："同学们——（抿嘴）收拾东西，先去食堂。（停顿）不要单独行动。" |

## 配角3：林浅

| 项目 | 内容 |
|------|------|
| 年龄/身份 | 15岁，高一学生，林深妹妹 |
| 外貌 | 比林深矮一个头，扎马尾，校服口袋里永远装着半包纸巾和一颗糖 |
| 性格核心 | 看起来什么都不怕，其实怕得要死——但她怕的不是自己出事，是怕哥哥出事 |
| 个人动机 | 保护哥哥。林深觉得是自己在保护妹妹，但林浅的觉醒比林深早——她只是藏得更好 |
| 核心冲突 | 妹妹比哥哥更早觉醒，但她不敢说——怕哥哥为了保护她做出更危险的事 |
| 说话方式 | 语速快，爱用"我跟你说"。示例："我跟你说，今天食堂的饭肯定有问题，我早上路过的时候闻到的味道不对——不是坏，是那种，怎么说，没味道。" |

## 配角4：赵明远

| 项目 | 内容 |
|------|------|
| 年龄/身份 | 18岁，高三学长，学生会副主席 |
| 外貌 | 戴黑框眼镜，校服永远整洁得不像高中生，口袋里永远有一支钢笔 |
| 性格核心 | 控制欲强但出发点是保护——他比任何人都清楚「摹本」的规则，因为他是最早觉醒的那批人之一 |
| 个人动机 | 建立秩序。觉醒者不能永远是散沙——他在暗中联络其他觉醒者，试图建立一个网络 |
| 核心冲突 | 他认为牺牲少数保护多数是正确的——林深不同意 |
| 说话方式 | 每句话都像在陈述事实，不用疑问句。示例："你比你妹妹晚觉醒至少三个月。她藏得很好——但你今天在食堂用能力的时候，全校的摹本都看见你了。" |
