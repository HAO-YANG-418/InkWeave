### 1.2 五条共性规律（所有标杆都遵守）

1. **先抽象共性，再补题材个性**（Lorn 第一条原则）
2. **知识库是"资产"不是"聊天结果"**——可落盘、可恢复、可检查、可审计
3. **拆书/蒸馏是显式工程步骤**，不是靠模型"自己学"
4. **写完必过门禁**（质检 + 反AI味 + 相似度），不是"生成了就算完"
5. **长篇必须持久化记忆**（伏笔台账 / 前文衔接 / 指纹），否则第 200 章忘第 1 章

## 二、核心概念：拆书 = 偷框架，不抄剧情

拆书不是"抄书"，是把爆款当**结构图**拆骨架，换自己的血肉重填。它回答四个问题：

| 层级 | 拆什么 | 产出 | 我们的现状 |
|------|--------|------|------------|
| **L0 母题** | 题材核心冲突 / 爽点类型 / 价值主张 | 母题卡 | 铁则二十五（手写总结，非真拆） |
| **L1 桥段** | 可复用模板（退婚打脸 / 系统觉醒 / 金手指首秀） | 桥段卡 | ❌ 无 |
| **L2 章法** | 章首钩子公式 / 章末钩子轮换 / 回报间隔 / 节奏分布 | 章法卡（=作品蓝本DNA） | ❌ 无 |
| **L3 句法** | 金句范式 / 感官白描范式 / 对话 beat 范式 | 句法卡（=作者文风DNA） | ❌ 无 |

> **关键判断**：节点系统控制"怎么写"（风格），元件卡控制"写什么结构"（骨架）。二者**正交**，必须分开建。

### 2.1 版权边界（必须说死）

- **结构级拆书（L0–L2）可合法零成本做**：章法/钩子轮换/回报间隔/桥段模板，从**目录 + 公开试读 + 公开书评/研究**即可合法推断，**不需要全文**，不碰版权红线。
- **句法级拆书（L3）需原文**：金句/白描范式要真书句子，必须从**用户授权正版 txt**（路径二）获取，禁扒全文/盗版。
- 结论：用户"不买书不操作"→ 我们**先做 L0–L2 结构级真拆**（合法、零成本）；L3 等用户授权正版 txt 再补（非阻塞）。

## 三、知识库架构（分层 + 元件卡库）

### 3.1 四层结构

```
知识库/
├── 通用层/            # = Lorn CommonSkills：跨题材铁则、通用桥段、通用章法
│   └── 通用桥段.md / 通用章法.md
├── 题材层/            # = Lorn 题材包装层：都市/玄幻/悬疑/电竞/灵异…每题材一套包装
│   ├── 都市爽文/
│   ├── 玄幻/
│   └── ...
├── 元件卡库/          # ★新增：拆书产物（L0–L3），按母题/桥段/章法/句法组织
│   ├── 母题卡/        # L0
│   ├── 桥段卡/        # L1（最贴出货好懂，优先建）
│   ├── 章法卡/        # L2（作品蓝本DNA）
│   └── 句法卡/        # L3（作者文风DNA，路径二授权后补）
└── 门禁层/            # = 检测工具/：18 项检测器 + 反AI味 + 相似度（已有）
```

### 3.2 元件卡 Schema（示例：桥段卡）

```markdown
# 桥段卡：退婚打脸（都市/玄幻通用）
- 母题：底层逆袭 + 外部羞辱 + 隐忍反击
- 结构：公开羞辱(配角起势) → 主角不闹(埋底牌) → 第三方点破(信息差) → 反转打脸(爽点爆发)
- 情绪曲线：抑(0-30%) → 等(30-70%) → 爆(70-90%) → 余韵(90-100%)
- 钩子位：章末留"真正的底牌还没亮"
- 适配题材：玄幻/都市爽文/历史（禁用：悬疑/灵异慢热向）
- 来源书：斗破苍穹 / 完美世界（结构提炼，非原文）
- 禁忌：禁止主角当场暴怒破功、禁止羞辱后无回收
```

## 四、蒸馏三档（落点）

| 档位 | 做法 | 成本 | 状态 | 建议 |
|------|------|------|------|------|
| **规则化（铁则）** | 拆书规律 → 铁则/节点/禁令 | 零成本、可审计、稳 | ✅ 已做（到二十五） | 继续，L0–L2 规律人审后固化进铁则 |
| **few-shot 示例库** | 真拆书片段按"题材×位置"注入生成上下文 | **零成本、我们还没做** | ❌ 缺口 | **优先补**：建 `元件卡库/` + 写前分析按镜头链调卡 |
| **微调底座** | finetune_prep 出 jsonl → 换底座 | 需算力/授权 | ⚠️ 9 pair 待扩 | 放软件化阶段，路径二授权后放量 |

**落点权重建议**：铁则 + few-shot 先跑（稳、零成本、可审计），微调治本但需算力，不阻塞当前出货。

## 六、执行路线图（分阶段）

- **P1 结构级拆书（零成本·路径一）**：对 8 本跑 L0–L2 拆书，产 `元件卡库/母题卡+桥段卡+章法卡`（从目录+试读+公开研究合法推断）。→ 治"都市爽文差铺垫/反转双看"。
- **P2 few-shot 注入**：写前分析按题材×位置调卡，生成指令增结构卡；跑 3 章验证 B+ 不倒退。
- **P3 持久化记忆**：伏笔台账 + 前文衔接自动注入，治长篇遗忘。
- **P4 题材层包装**：都市/玄幻/悬疑/电竞/灵异各一套包装层（参考 Lorn 题材目录）。
- **P5 微调底座（路径二·需授权）**：用户授权正版 txt → 补 L3 句法卡 → finetune_prep 放量 → 换底座。

> 迭代铁律：每阶段复跑对照章（玄幻/都市/历史）确认仍 0 error + 口语人味不丢，才推进。

## 七、待拍板项（仅 1 个真阻塞）

1. **【阻塞】路径二授权**：要不要为 L3 句法级拆书，提供手上已有的正版 txt（斗破/大奉等）？——不授权也能走 P1–P4（结构级真拆），只是句法级暂缓。
2. **【非阻塞】要不要上 RAG 向量检索**：先用"确定性加载 + few-shot"跑，RAG 等卡库 >50 张再评估，不急。
3. **P1 拆书颗粒度**：我建议 **L1 桥段卡优先**（最贴出货好懂），母题/章法同步。如无异议按此执行。

## 八、结论

我们之前的 `corpus/` 仿写样本能凑字数过质检，但**学不到真书的节奏密码**。升级方向明确：**用拆书法对 8 本出"元件卡库"（L0–L2 结构级，合法零成本），跨书聚合后灌进铁则 + 节点 + few-shot + 微调**。这正好对齐 Lorn 的"蒸馏三件套"工程范式，也补齐了我们 v4.8 最关键的四个缺口（真拆书元件卡 / 文风DNA / 持久化记忆 / few-shot 示例库）。
