大奉打更人 · 卖报小郎君

许七安幽幽醒来，嗅到了空气中潮湿的腐臭味……「没想到重活了，还是逃不掉当警察的宿命？」许七安有些牙疼。「可我为什么会在监狱里？」
判定 · 部分达标：skill 开头「身体锚点 ≤20字」已经做对（刀烫手=好）。但网文第 1–2 句就让人笑/怕，skill 锚点之后慢半拍才给冲突与人味——前 1/3 对话密度偏低。

② 句节奏 一句话 vs 一整段（D级头号卖相扣分项）

SKILL · ch01（整段一句话 ≈170字）

屋里灯是惨白吸顶灯，嗡嗡响，听得人后槽牙发酸。光打下来啥都发黄，墙皮掉了一块，底下露水泥灰。空气里一股铁锈混酒气，地上倒个绿啤酒瓶，滚到国庆手边没碎，瓶口凝着半圈白沫。许照吸口气，肺里凉飕飕带着外头寒气，脑子反倒清楚一点。他注意到茶几上两只杯子，一只满一只见底，杯壁都挂水珠，说明来人不只一个，还坐下来喝过。

诡秘之主 / 斗破苍穹

痛！好痛！头好痛！光怪陆离满是低语的梦境迅速支离破碎……

三段斗之气，二十岁被强制退婚，这个消息恐怕当今萧家已经成为了你我的笑柄了吧？哈哈！
判定 · 差距明显：skill 大量「逗号长链裹成一段」，单段 150–170 字不换气；网文用短句断奏，阅读更跟手。这直接踩中检测器「长句>60字 / 段落>200字」warning，是 D级的主因。

全职高手 · 蝴蝶蓝

叶修微微仰首靠在头枕上，闭着眼……「我说哥，你就带这么点东西回来啊？亏我还特地开了辆大车子出来预备拉行李，结果，就一小包——」「你是光带了键盘和鼠标啊你！」
判定 · 差距在中段：skill 描写本身不空不晦涩，但「成块堆」而非「碎进动作/对话里」。网文几乎每段都有对话穿插，描写不抢戏。

实话总结：当前盲写 = 硬伤层全过（0 error，好懂不晦涩有货），卖相层 3 项追平（开头锚点 / 对话人味 / 章尾钩子）、3 项仍差（长句断奏 / 描写密度 / 硬爆破）。 差的全是「节奏与密度」，不是「写得烂」——所以推 D→B 要清的是那 ~10 条结构 warning，是「提卖相」不是「修缺陷」。
