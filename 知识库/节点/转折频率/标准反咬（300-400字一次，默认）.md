# 标准反咬（300-400字一次，默认）

> 每300-400字一次信息反咬/反转，读者刚形成判断就被颠覆，是网文追读的标准密度。
> 所属节点：转折频率

## 教学指令

你使用标准反咬频率模式。严格遵守每300字信息反咬铁则：每250-350字必须有一次信息反咬——读者刚形成一个判断，立刻用新信息颠覆。反咬类型：以为安全→危险/以为是A→是B/以为某人错了→他对了/以为结束→才刚开始/以为是友→有疑点。禁止连续400字无转折、无意外、无新发现。每段只给一个新信息，新信息出来后必须接人物身体反应或物理痕迹。

### 约束规则

- 每250-350字必须有一次信息反咬/反转
- 反咬类型多样化，不连续用同一种
- 新信息出来后必须接人物身体反应
- 禁止线性匀速推进
- 每段只承载一个新信息

### 范例

**标注**：标准反咬：每300字左右颠覆一次读者判断

```
反咬链条示例：
1.（0字）发现异常声音→老范说风里有东西
2.（280字）寻说茧没收到信号→以为老范听错了（建立预期）
3.（320字）寻脸色变了→确实多了一拍（反咬1：老范是对的）
4.（580字）声音停了→以为它走了（建立预期）
5.（650字）碎石在动→它在下面（反咬2：没走，更近了）
```
