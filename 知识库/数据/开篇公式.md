# 开篇公式

> 6种开篇公式，每种各有使用场景和案例

## 公式速查

| 公式 | 适用场景 | 核心要点 | 常见错误 |
|------|---------|---------|---------|
| 悬念切入 | 章节属于揭露/转折类，有未解之谜需要引爆 | 从异常现象/反常行为开始，让读者立刻产生"为什么" | 悬念太弱/拖太久不解释/故弄玄虚 |
| 动作切入 | 战斗章/冲突章/危机章 | 直接从动作中段开始，不铺垫，用短句制造紧迫感 | 动作写半段开始解释/动作前加铺垫段落 |
| 场景切入 | 新地点/重要场景首次登场/氛围章 | 从一个感官细节开始（声音/气味/温度/光线），逐步展开 | 场景描写与后续剧情无关/只写视觉 |
| 对话切入 | 信息交换章/对峙章/关系章 | 第一句对话必须有信息量或冲突，不能是寒暄 | 开头对话无信息/对话对象不明确/对话后无下文 |
| 内心切入 | 抉择章/成长章/情感章 | 从外部刺激触发内心活动，内心活动必须导向外部行动 | 内心独白无锚点/一开始就大段心理/心理与行动脱节 |
| 倒叙切入 | 需要前史支撑的章节/揭示章 | 从当前悬念开始→触发回忆→只写相关部分→回到现在 | 倒叙太长/读者已知内容/切换无标记 |

## 公式详解

### 悬念切入

**结构**：异常现象 → 角色反应 → 揭示部分信息 → 抛出更大疑问

**案例**：
- 门缝下有光，但房间里不应该有人
- 对手的剑上刻着主角家族的纹章
- 本该死去的人出现在人群中

### 动作切入

**结构**：动作中段 → 短句连击 → 结果 → 回溯原因（可选）

**案例**：
- 剑锋距眉心三寸，他还没拔剑
- 地面裂开，碎石坠入深渊，他的手抓住了崖边
- 血从指缝渗出，滴在雪地上，晕开一片红

### 场景切入

**结构**：感官锚点 → 环境特征 → 角色位置 → 冲突/异常引入

**案例**：
- 铁锈味从走廊尽头飘来，越来越浓
- 钟声敲了三下，回声在空荡的大殿里久久不散
- 火把的火焰突然齐刷刷偏向同一个方向

### 对话切入

**结构**：有信息量对话 → 说话者身份 → 冲突升级 → 转向行动

**案例**：
- "你确定要进去？里面的人，上一次开门是三十年前"
- "他不是失踪，是被藏起来了"
- "第三个条件，我要你的名字"

### 内心切入

**结构**：外部刺激 → 内心反应 → 决策 → 行动

**案例**：
- 他盯着自己的手。刚才那一拳，他没收住力
- 名单上的名字他都认识。每一个都认识
- 还有一个办法。他不想用，但只剩这一个了

### 倒叙切入

**结构**：当前悬念 → 触发物 → 回忆（精简） → 回到现在 → 理解改变

**案例**：
- 看到那把剑的时候，他突然想起师父临死前说的话
- 这个声音他听过。十年前，同样的话，同样的语气

## 使用约束

- 相邻两章不得使用同一种开篇公式
- 倒叙切入每卷最多使用2次
- 悬念切入后必须在3段内给出第一个线索
- 动作切入不得添加任何铺垫段落
