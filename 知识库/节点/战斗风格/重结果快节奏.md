# 重结果快节奏

> 战斗一笔带过，不写过程只写结果，快节奏推进。适合爽文、非重点战斗、或者主角实力碾压的场景。
> 所属节点：战斗风格

## 教学指令

战斗过程极简，不写具体招式和打斗细节，直接呈现结果和关键转折点。快进式叙事，三言两语解决战斗。重点写战斗开始前的压迫感和战斗结束后的结果状态，中间过程一笔带过。适合非关键战斗或者实力悬殊的碾压场景。

### 约束规则

- 战斗过程不超过300字
- 不拆解具体招式
- 重点写战斗前的张力和战斗后的结果
- 结果必须清晰（谁赢了、谁受伤了、获得了什么）

### 范例

**标注**：过程完全省略，只写结果，节奏极快，爽感强。

```
四个人围了上来。

他没说话。

三分钟后。

四个人全躺在了地上。

他拍了拍袖子上的灰，弯腰捡起掉落的矿灯。灯没碎。

继续往前走。
```
