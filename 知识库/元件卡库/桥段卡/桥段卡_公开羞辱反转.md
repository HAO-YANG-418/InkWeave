# 桥段卡：公开羞辱反转

- **母题**：当众被踩 + 用智商/实力反转
- **结构**：①公开场合被群嘲（酒宴/朝堂/擂台） → ②主角不辩只做 → ③抛出现实证据/逻辑反杀 → ④嘲讽者集体破防
- **情绪曲线**：辱(0-30%) → 静(30-50%) → 反(50-80%) → 崩(80-100%)
- **钩子位**：章末留「他到底是什么人」或「更大的局刚露头」
- **适配题材**：探案朝堂 / 玄幻 / 历史；禁用纯感情向
- **来源书**：大奉打更人 / 斗破苍穹（结构提炼，非原文）
- **禁忌**：禁止主角降智配合羞辱；禁止反转无铺垫（须前文埋公平线索）；禁止反派丑角化无脑
