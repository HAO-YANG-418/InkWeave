# 写后检查

> 正文生成完成后执行。此阶段不涉及创意写作，纯粹是检查和修复。

---

## 第0步：环境准备

首次使用需安装依赖：
```
cd InkWeave/
npm install
```

## 第1步：算法检测

运行检测工具：
```
npx tsx 检测工具/check-chapter.ts <本章文件路径> --target <目标字数>
```

检测工具覆盖18项精确算法检测：
逗号链/句群波形/短语重复/感官密度/禁用字/"不是X是Y"/碎句/万能套路词/数据锚点/角色台词差异化/动作点名册/感叹号配额/解释腔/拍内断句/标点残损/读者负担/紧邻段落重复/字数达标

**检测→判定→重写（禁止修补）**：
1. 跑检测工具，输出报告
2. 评分≥85（B级）且无error → ✅ 通过，**不作任何修改**，直接交稿
3. 评分<85 或 有error → ❌ 不合格，回到写前分析阶段重新规划镜头链，**全文重写**（禁止修补）
4. 最多重写2轮。第1轮重写后仍<85，进入第2轮（最后机会）。第2轮后仍<85 → 🚫 **强制报错，退回大纲创作院重新拆分本章**。不得以"取最高分"绕过。
5. **禁止修补**：检测后禁止逐项修复违规。修一处会破坏镜头链连续性，导致更多碎句。不合格就重写，不补丁。

### 全书质量检测（周期性）

累积 5 章以上时，建议执行全书检测，扫描跨章重复模式和全局质量趋势：

```
npx tsx 检测工具/check-all.ts <章节目录> [--json] [--parallel]
```

全书检测覆盖：单章质量评分排行 / 跨章高频短语 / 跨章套路词 / 开篇模式重复 / 全书统计。
`--parallel` 参数可启用多章并行扫描，加速大批量检测。

---

## 第2步：语义质量检查

检测工具无法覆盖的深层问题，LLM逐条判断：

| # | 检查项 | 方法 | 通过标准 |
|---|--------|------|---------|
| 1 | 套路语义检测 | 对照冷却模式库，语义理解判断是否使用了冷却期内的模式 | 无冷却期内模式被重复使用 |
| 2 | 情节模板检测 | 从情节走向判断是否走了装逼打脸/拍卖会/比赛/奇遇/英雄救美老路 | 无模板雷同，或有关键变数 |
| 3 | 章类型多样性 | 本章功能类型是否与前3章重复 | 不与前3章类型完全相同 |
| 4 | 冲突维度多样性 | 冲突类型是否与前3章重复 | 至少1个维度与前3章不同 |

---

## 第3步：反思评估

读取 `知识库/数据/反思评估标准.md`。12维度逐项打分，**必须引用正文证据**：

**结构性维度（5个，用检测工具精确计算）**：文字质量/节奏/信息密度/感官丰富度/连续性

**语义维度（7个，LLM判断）**：意图对齐(0.20)/结尾钩子(0.18)/开头力度(0.12)/情感冲击(0.10)/角色声音(0.08)/对话质量(0.07)/原创性(0.04)

综合评分 = 结构性维度分 + 语义维度分×权重 - 附加扣分。

输出反思评估报告（写入 `审稿/第X章反思评估.md`，模板参见 `审稿/审稿模板.md`）。

---

## 第4步：重写（如需要）

**触发条件**：评分<85 或 存在error。

**重写流程**（禁止修补）：
1. 回到写前分析，重新做镜头链规划（调整场景数/字数分配/镜头类型）
2. 全文重写，不保留原文
3. 重写后重新跑检测
4. 最多2轮。第2轮后仍<85 → 🚫 强制报错，退回大纲创作院重新拆分本章大纲
5. **绝对禁止**：逐项修复违规。修补是幻觉——修一处碎句会破坏镜头链，产生更多碎句。
