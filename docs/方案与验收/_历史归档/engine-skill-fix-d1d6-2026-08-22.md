## 1. 各缺陷修复明细

### D1 ｜ 感官基线契约自相矛盾（🔴 高）
- **根因**：`checkSenseDensity` 无条件要求 `触觉 ≥ 视觉`，与视觉/听觉/嗅觉/味觉基调章冲突。
- **改法**：检测器按本章**实际感官占比最高者**判定基调（与 pre-analysis 章号轮换目标一致，免章节号透传）。仅当 `topSense==='触觉'` 且 `tactile<visual` 时才报 `sense_tactile_below_visual` warning。
- **结果**：修复前 8/9 章误报 → 修复后 **0 章**。

### D2 ｜ 不是X是Y severity 与铁则不符（🔴 高）
- **决策**：用户选方案 A（对齐铁则十二硬禁）。
- **改法**：`severity = allMatches.length >= 1 ? 'error' : 'info'`，删除原 `>=5 error / >=3 warning / else info` 放水逻辑。
- **结果**：修复前 9 章 0 次 error → 修复后 **8 章触发 error**（仅 ch22 无此句式）。

### D3 ｜ 碎句检测器误杀（🟡 中）
- **改法**：`checkShortSentenceFragments` 增加 `stats` 参数，引入放行白名单——连续短句若位于**对话段**或含**动作/感官动词**（走跑看说拿 + 冷热敷刺等）则不报；仅无信息量的纯流水短句才 warning。
- **结果**：修复前 28 次 → 修复后 **9 次**（降 68%）。

### D4 ｜ 字数门禁阈值失真（🟡 中）
- **改法**：`checkWordCountTarget` error 阈值 `0.7→0.9`（<2700），warning `0.7–0.85 → 0.9–1.0`（2700–3000），对齐契约"目标3000、±10%容差"。
- **结果**：修复前 7/9 章低于3000却过门禁 → 修复后 **9 章全部被拦**（8 error + 1 warning）。

### D5 ｜ 两条感官规则重叠（🟡 中）
