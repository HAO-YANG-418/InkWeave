# 母题卡：都市爽文（含都市异能）

- **母题**：被看轻的小人物 + 金手指/系统觉醒 + 市井逆袭
- **适配题材**：都市爽文 / 都市异能 / 群像
- **核心冲突**：底层小人物 vs 势利眼圈层；觉醒的"外挂" vs 原本规则
- **爽点类型**：装逼打脸（当众碾压势利眼）；系统首秀（金手指亮出来）；市井群像反差（邻居/同事从嘲到敬）
- **价值主张**：真正翻身靠真本事+一点运气；市井烟火里也有硬骨头
- **来源书**：结构原创（综合都市爽文通则，非单本原文）
- **禁忌**：禁主角降智配合反派（反派可以精但主角不能犯蠢）；禁纯写实无金手指（异能/系统类禁用纯写实）；禁冷峻长句造疏离
