## 三、待代码方（.ts，方案方不碰）—— 引擎逗句比硬约束删除

**精确改法**（file:line 已核）：

`源码/kb/base-prompt.ts:140` 与 `源码/prompt-builder.ts:158` 当前文本（两处相同）：
```
禁止在合理动作链里滥用句号把同一拍剁碎（如"他走。光打在墙上。"）；但单句逗号≤8、逗号/句号比≤3.0，换拍必须句号断开。
```
改为（删硬数约束，与 生成指令.md 降级对齐）：
```
禁止在合理动作链里滥用句号把同一拍剁碎（如"他走。光打在墙上。"）；换拍用句号断开，但逗号数和逗句比只是参考——读着顺就保留连写，读着喘才断句，严禁为压低逗句比把一句剁碎（好懂优先，不是含蓄）。
```

**为什么必须删**：生成指令.md 早已把逗句比降级为"只禁一逗到底"，但引擎 .ts 仍硬卡 ≤3.0/≤8逗号。模型同时收到两份矛盾指令，会优先服从 .ts 硬数 → 碎句复发。这正是"单留一侧种子→滑回"的活例。
