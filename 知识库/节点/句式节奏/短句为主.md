# 短句为主

> 以短句(<=15字)为主导节奏，干脆利落，像鼓点般敲击。适合紧张场景、动作场面和快节奏叙事，也是矿工风格核心节奏。
> 所属节点：句式节奏

## 教学指令

⚠️ 好懂红线（2026-08-31 钉死）：克制≠难懂，留白≠藏逻辑，简练≠不说清。含蓄/克制/留白/省略**只适用于情绪层**（不直说角色感受），**绝不适用于信息层**——事件因果、动作链、谁做了什么、设定逻辑必须写清，读者零回读。任何写法一旦让人需回读才懂，立即让位给"读着顺"。网文第一标准是好懂。

⚠️ 补充（2026-08-31）：短句是**节奏选择不是通用法则**，仅适合战斗/紧张/冲击段落。"能用句号就不用逗号"是快节奏段的强化说法，**禁止套用到叙事与说明段**——那里读着顺就保留连写，严禁为短而短把一句剁碎。

短句节奏的核心是'一击即中'。每句话只传递一个信息点，像出拳、像鼓点、像心跳。读者没有喘息空间，紧张感自然生成。具体技法：

1. 单信息原则：每句话只写一个动作、一个感官、一个念头。不要把两个动作塞进同一句。'他转身，拔出刀'要拆成'他转身。''拔出刀。'。句号就是停顿，停顿就是重量。

2. 断句要狠：能用句号就不用逗号，能拆成两句就不合成一句。'他看见老李倒在地上，胸口在流血'要拆成'老李倒在地上。''胸口在流血。'。每一句单独成段，冲击力翻倍。

3. 名词动词优先：短句中少用形容词和副词。用名词和名词、动词和名词直接碰撞。'刀很快。''血很热。''墙很硬。'不需要修饰，事实本身就有力量。

4. 留白制造重音：关键瞬间前后加空行或极短句（1-3字）。'他抬头。''一个字。''死。'单独成段，像锤子砸下来。

5. 节奏变化：全是短句也会疲劳。每10-15句短句后，可以插入一句稍长的句子（20-25字）作为节奏调剂，但立刻回到短句。长句是为了让接下来的短句更有力。

6. 感官碎片化：把感官体验拆成碎片——不是'他听到巨大的爆炸声感到一阵剧痛'，而是'声音来了。''耳朵嗡的一下。''疼。''什么都看不见。'。碎片化更接近人在极端状态下的真实感知。

7. 禁止解释：短句不解释。不说'因为瓦斯浓度太高所以他们必须撤退'，只写'瓦斯响了。''走。'。读者自己会连起来。

### 约束规则

- 单句原则上不超过20字，90%句子在15字以内
- 短句（15字以内）占比70%以上
- 禁止连续3句以上超过15字的句子
- 每200字至少有1处1-3字的极短句单独成段作为重音
- 避免使用分号连接多个分句，禁止破折号，少用省略号
- 动作场景中每句只包含一个动作，禁止连动句（'他转身拔出刀冲出去'必须拆开）
- 形容词和副词使用密度不超过每100字3个
- 段落长度控制在3-5句以内，关键动作可以一句一段

### 范例

**标注**：短句节奏示范：整段平均句长不超过10字，关键节点用1-3字极短句（'超了。''不对。''走。''是红的。'）单独成段制造重音。每句一个信息点：报警响了→看仪表→浓度1.8%→老李没听见→风停了→壁面烫→在震→有红光。读者跟着句子节奏一起紧张，没有一句解释为什么危险，读者自己懂。

```
瓦斯报警响了。

不是预警。是那种持续的、尖锐的、要命的响声。

他抬头看仪表。

浓度1.8%。

超了。

老李还在前面刨煤。没听见。

他抓起矿灯往那边照。光柱晃了两下，照见老李的背影，弓着，像只虾。

「老李！」

没反应。

风停了。

他知道这意味着什么。通风管一停，瓦斯三分钟就能到爆炸浓度。

他站起来。膝盖撞到横梁，疼。顾不上。

「走！」

他往前跑。靴底踩在碎煤上滑了一下，手扶住壁面，壁面是烫的。

不对。

他停下。

不是烫。

是在震。

很轻。从很深的地方传上来。像什么东西在里面翻身。

他回头看。

通道口的方向，有光。

不是矿灯的光。

是红的。
```
