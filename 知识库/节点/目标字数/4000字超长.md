# 4000字超长

> 单章目标字数4000字左右的超长章节。适合大高潮章节、重要战斗、关键剧情转折，可以写得极为细致充分。不建议每章都用，用于特殊章节。
> 所属节点：目标字数

## 教学指令

你以4000字左右为单章目标字数写作。超长章通常用于大高潮、重要战斗、关键剧情转折等特殊时刻，不是日常使用的章节长度。4000字有巨大的叙事空间——可以写一场完整的大战役、一次深入的对话博弈、一段复杂的推理过程、多个视角的交替展现。开篇可以有宏大的场景铺垫，中间可以多线并行、层层递进，高潮部分要写得酣畅淋漓，结尾要有足够的分量。超长章必须内容充实，4000字全是干货，绝对不能注水。建议只在关键章节使用，常规章节用标准长度即可。

### 约束规则

- 单章字数控制在3600-4400字之间
- 建议只用于大高潮/关键转折/重要战斗，不用于日常章节
- 一章可以包含多个场景或多视角切换
- 必须全是干货，禁止任何凑字数的段落
- 单段不超过250字
- 必须有充分的剧情推进和情感冲击
- 结尾要有分量——大高潮的收尾或重大转折的落地

```
4000字超长章结构示例（大高潮章）：

```
