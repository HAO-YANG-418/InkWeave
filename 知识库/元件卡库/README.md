# 元件卡库（拆书产物 · L0–L2 结构级）

> 本库由 P1「结构级拆书」产出。拆书 = 偷框架不抄剧情。
> **版权红线**：所有卡片均为「结构/框架提炼」，来源于各书公开目录、公开试读、公开书评与研究，**非原文、不扒全文、不碰盗版**。L3 句法卡（作者文风DNA）需用户授权正版 txt 后方可补，当前 `句法卡/` 为空，预留。

## 层级与用途

| 层 | 目录 | 拆什么 | 写前分析何时调 |
|----|------|--------|----------------|
| L0 | `母题卡/` | 题材核心冲突/爽点类型/价值主张 | 定本书基调时 |
| L1 | `桥段卡/` | 可复用场景模板（逆袭/打脸/反转） | 镜头链规划选骨架 |
| L2 | `章法卡/` | 章首钩子公式/章末钩子轮换/回报间隔/节奏分布 | 写前定章法 |
| L3 | `句法卡/` | 金句/白描/对话 beat 范式（预留·需授权） | — |

## 调用约定（写前分析.md 镜头链阶段）

1. 读 `母题卡/<本书>.md` 定基调。
2. 按本章意图从 `桥段卡/` 选 1–2 张作骨架（如「退婚打脸」「底牌揭晓」）。
3. 读 `章法卡/<本书>.md` 取章首钩子公式 + 章末钩子类型（按轮换表选，忌连章同型）+ 回报间隔。
4. 将以上摘要写入 `生成指令.md` 的「本章结构卡」段（P2 接入）。

## 卡片 Schema

**母题卡**：母题 / 适配题材 / 核心冲突 / 爽点类型 / 价值主张 / 来源书 / 禁忌
**桥段卡**：母题 / 结构(4步) / 情绪曲线 / 钩子位 / 适配题材 / 来源书 / 禁忌
**章法卡**：章首钩子公式 / 章末钩子轮换 / 回报间隔 / 节奏分布 / 来源书
