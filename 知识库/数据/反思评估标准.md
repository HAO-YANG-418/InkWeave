# 反思评估标准

> 12维度写作质量评判标准，定义"什么样的网文章节算好/算差"

## 维度权重

| 维度 | 权重 | 评什么 |
|------|------|--------|
| 意图对齐 | 0.2 | 这章要做的事做了没？该推进剧情却在水日常？该高潮却没爆起来？ |
| 情感冲击力 | 0.1 | 情绪有没有起伏？还是从头到尾一个调子？读者有没有"心跳时刻"？ |
| 节奏控制 | 0.08 | 该快的地方快了吗（战斗/冲突）？该慢的地方慢了吗（情感/氛围）？ |
| 角色声音一致性 | 0.08 | 角色说话像他自己吗？有没有所有人说话一个味？ |
| 开头力度 | 0.12 | 前3段有没有抓住读者？还是在铺背景/写醒来/赶路？ |
| 结尾钩子 | 0.18 | 结尾有没有让读者想看下一章？还是平淡收尾？ |
| 信息密度 | 0.07 | 这章给了读者多少新信息？有没有大段废话？ |
| 感官丰富度 | 0.04 | 五感描写有没有？是不是全是视觉？描写是服务叙事还是在堆词？ |
| 对话质量 | 0.07 | 对话是在推进剧情还是在说废话？有没有信息倾倒？ |
| 文字质量 | 0.05 | 文字基本功：用词是否准确？句式是否多样？有没有语病？ |
| 连续性 | 0.05 | 与前文的衔接是否自然？有没有设定矛盾？伏笔有没有管理？ |
| 原创性/套路化 | 0.04 | 有没有陈词滥调？情节/描写/对话是否模式化？ |

## 差模式清单

| 模式 | 严重度 | 描述 | 检测信号 |
|------|--------|------|----------|
| 意图跑偏 | 0.8 | 标注要推进剧情，实际全章在写日常/修炼/聊天，核心剧情没动 | 全章无新事件、核心矛盾未推进、大量日常描写 |
| 高潮未爆 | 0.7 | 标注高潮章，但情绪没到，冲突没爆，像流水账一样平淡度过 | 冲突双方未直接对抗、情绪描写平缓、无转折/爆发点 |
| 揭示空洞 | 0.6 | 标注揭示真相，但揭示的内容没有冲击力，或揭示方式太直接 | 直接说出真相无铺垫、揭示内容读者早已猜到、揭示后角色无反应 |
| 水章 | 0.9 | 全章无新信息、无冲突、无决策、无关系变化，纯粹凑字数 | 无新事件、无冲突、无决策 |
| 意图模糊 | 0.6 | 章节意图不明确，既像推进又像铺垫，什么都想写结果什么都没写好 | 一章涉及3+个不同事件、每个事件都浅尝辄止、章节重心不断转移 |
| 情绪平淡 | 0.7 | 全章情绪一条直线，没有高低起伏，读着没有感觉 | 无情绪高潮点、情绪词使用均匀、无冲突/危机/转折 |
| 告知而非展现 | 0.6 | 直接写"他很愤怒/悲伤/开心"，而不是通过行为/对话/细节让读者感受到 | 他感到XX、心中涌起XX、一股XX之情油然而生 |
| 情绪断裂 | 0.5 | 上一段还在紧张战斗，下一段突然开始轻松聊天，情绪转换无过渡 | 相邻段落情绪反差大、无过渡句、场景切换突兀 |
| 过度煽情 | 0.5 | 强行煽情，大段心理描写堆砌情绪，读者反而无感 | 心理描写超过3段连续、大量排比句渲染情绪、无实际事件支撑情绪 |
| 情绪标签堆砌 | 0.5 | 连续使用情绪标签词："愤怒""悲伤""绝望"在同一页出现3次以上 | 情绪标签词密度高、同一段落3+情绪标签、情绪词无行为支撑 |
| 战斗拖沓 | 0.7 | 战斗场景用了长句和大段描写，节奏慢得像散步 | 战斗中长句多于短句、战斗段落超过5行、战斗中插入大段心理/回忆 |
| 情感仓促 | 0.5 | 本该慢下来的情感场景，三两句就带过了 | 情感场景段落极短、无环境/感官描写、情绪转换太快 |
| 节奏单一 | 0.4 | 全章句式长短一致，段落大小均匀，读起来催眠 | 句长方差小、段落长度均匀、无节奏变化点 |
| 信息倾倒 | 0.6 | 大段设定/背景/说明一口气倒出来，读者消化不了 | 连续3段以上纯说明、无角色视角的设定介绍、大段修炼体系讲解 |
| 声音同质化 | 0.7 | 所有角色说话方式一样，分不清谁在说 | 不同角色对话句式相似、用词习惯无差异、语气态度一致 |
| 人设崩塌 | 0.8 | 角色的行为/说话与之前建立的设定矛盾 | 冷静角色突然暴怒无铺垫、胆小角色突然勇敢无原因、聪明角色做蠢事 |
| 万能应答 | 0.5 | 角色对话都是"嗯""好的""我知道了"这类无信息回应 | 大量简短应答、对话不推进剧情、对话不展现性格 |
| 背景铺陈型 | 0.7 | 开头大段介绍世界观/历史/修炼体系/地理环境 | 前3段为纯说明、无角色出场、无冲突/动作 |
| 日常流水型 | 0.6 | 主角醒来/吃饭/赶路/修炼，无冲突无异常 | 清晨天刚亮、起床/洗漱/吃饭描写、赶路/修炼无意外 |
| 假钩子型 | 0.8 | 作者跳出来剧透："他不知道，一场危机正在逼近" | 他不知道、殊不知、他尚未意识到 |
| 总结回顾型 | 0.6 | 开头回顾上一章发生了什么 | 经过昨天的XX、回想起之前的、大段回顾前情 |
| 平淡收尾 | 0.7 | 事情办完了，大家各回各家，没有任何悬念 | 于是这一天就这样过去了、无悬念/危机/期待、情绪平缓收尾 |
| 说教收尾 | 0.6 | 结尾大段感慨/感悟/说教，破坏节奏 | 结尾段为角色感悟、大段心理独白、主题升华式收尾 |
| 硬断 | 0.5 | 话没说完/动作没做完直接断章，像被掐断一样 | 句子未完成、动作进行中断章、无任何收束 |
| 假悬念 | 0.6 | 结尾制造了悬念，但下一章开头就轻松化解，欺骗读者 | 结尾危机感强但下章秒解、反复使用生死未卜式结尾 |
| 信息稀薄 | 0.7 | 全章3000字但实际推进的剧情只有一句话能概括 | 大量重复描写、同一情绪反复渲染、无新事件/新信息 |
| 废话填充 | 0.6 | 为了凑字数，大量无意义对话/描写/心理活动 | 无信息对话、重复已知信息、无目的场景描写 |
| 信息过载 | 0.5 | 一章塞了太多新设定/新角色/新事件，读者消化不了 | 一章引入3+新角色、大段设定说明、多个事件并行无主次 |
| 纯视觉 | 0.4 | 全章只有视觉描写，没有声音/触感/气味/温度 | 无听觉词、无触觉词、无嗅觉词 |
| 感官堆砌 | 0.5 | 为了"丰富"而堆砌感官描写，与剧情/情绪无关 | 连续大段感官描写、感官细节不影响剧情、描写后无角色反应 |
| 感官缺失 | 0.6 | 全章几乎无环境/感官描写，像剧本一样只有对话和动作 | 无环境描写、无感官词、场景感弱 |
| 信息倾倒 | 0.7 | 角色通过对话大段解释设定/背景/计划，像在念说明书 | 单段对话超过5行、角色解释设定、对话内容是作者想告诉读者的信息 |
| 无意义对话 | 0.5 | 对话不推进剧情，不展现性格，纯粹凑字数 | 寒暄/客套话、重复已知信息、嗯哦这样啊 |
| 对话标签累赘 | 0.3 | 每句对话都加"他愤怒地说""她温柔地回答"这类标签 | 每句对话后有情感副词、XX地说/道/喊频繁出现 |
| 所有人一个腔调 | 0.6 | 不同角色说话方式完全一样 | 对话句式雷同、用词习惯无差异、无法通过对话猜出说话者 |
| 词汇贫乏 | 0.4 | 反复使用同一个词，特别是形容词和动词 | 同一词一章出现5+次、强大恐怖惊人反复出现 |
| 句式单一 | 0.4 | 全章都是"主语+谓语+宾语"的结构，读起来单调 | 句式结构雷同、无倒装/省略/反问、段落节奏均匀 |
| 修辞老套 | 0.5 | 比喻/形容都是用烂了的："如闪电般""快如疾风""重如泰山" | 如XX般频繁、常见成语堆砌、比喻无新意 |
| 过度修饰 | 0.4 | 每个名词前都堆形容词，每个动词后都跟副词 | 形容词/副词密度高、名词前2+修饰词、动词后2+副词 |
| 设定矛盾 | 0.9 | 本章内容与前文建立的设定冲突 | 角色能力忽高忽低、地理位置错误、时间线矛盾 |
| 伏笔遗忘 | 0.6 | 前文埋的伏笔迟迟不回收，读者已经忘了 | 活跃伏笔超过10个、伏笔埋设超过20章未回收、新章无伏笔回收 |
| 场景断裂 | 0.5 | 与上一章结尾的衔接不自然，场景跳转突兀 | 无过渡直接换场景、上一章结尾的悬念本章不回应、时间跳跃无说明 |
| 角色失踪 | 0.5 | 重要角色突然消失，多个章节不出现也不交代去向 | 前文角色不再出现、无交代去向、新角色替代旧角色功能 |
| 套路化描写 | 0.6 | 使用了网文高频套路词和描写模式 | 嘴角勾起一抹弧度/冷笑、眼中闪过一丝寒芒/精光/杀意、倒吸一口凉气/冷气 |
| 情节套路 | 0.7 | 情节发展完全可预测，使用了网文经典模板 | 装逼打脸模板：被看不起→展示实力→全场震惊、拍卖会模板：低价起拍→疯狂竞价→主角截胡、比赛模板：分组抽签→遇到强敌→险胜/爆发 |
| 万能修饰词 | 0.4 | 过度使用"恐怖的""惊人的""可怕的""不可思议的"等空泛修饰 | 恐怖的XX、惊人的XX、可怕的XX |
| 转折套路 | 0.5 | 每次转折都用同样的信号词 | 然而、就在这时、他不知道的是 |
