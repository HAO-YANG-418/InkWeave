# 意图策略规则

## 15种意图策略表

| 意图 | 策略 | 情绪基调 | 节奏 | 禁止模板 |
|------|------|---------|------|---------|
| climax | 压力递增法：短句加速，减少描写，每次"差一点成功"让压力更大，释放后给喘息 | 紧张(95%) | 短句/稀疏段落/高行动 | "最强一击/天地变色/空间扭曲" |
| emotional_impact | 共鸣放大法：细节积累情绪，用具体细节代替抽象形容词，爆发后给消化时间 | 悲伤(90%) | 中长句/中等段落 | "泪流满面/心中涌起" |
| reveal_secret | 三阶段揭示：暗示→部分揭露→完全揭露，揭露后引发新问题，不一次性倾倒 | 震撼(80%) | 中句/中等段落/高信息 | "原来/其实/真相是" |
| create_conflict | 利益冲突法：双方各有合理动机，试探→挑衅→底线→爆发，冲突升级有层次 | 紧张(70%) | 短句/密集段落/高对话 | 正邪对立模板，反派须有合理动机 |
| advance_plot | 因果链推进：事件之间必须有因果，每次只揭示一层，禁止巧合 | 好奇(60%) | 混合/中等段落 | 巧合推动，万能转折词 |
| show_growth | 代价成长法：通过失败/失去触发成长，成长后立即用新能力解决旧难题 | 满足(60%) | 混合/中等段落 | "盘膝坐下/突破境界/瓶颈松动" |
| build_relationship | 冲突→理解→羁绊：用具体事件而非对话表达关系变化，小细节比大场面有力 | 温暖(50%) | 中句/中等段落/高对话 | "心中涌起暖流/目光交汇/心跳加速" |
| raise_stakes | 赌注升级法：用具体后果替代抽象威胁，让失败代价从"损失"到"毁灭" | 恐惧(80%) | 短句/密集段落 | "前所未有的危机/更大的阴谋" |
| world_building | 体验式展开：通过角色体验展示世界观，每次只展示一个侧面，禁止"百科全书式"说明 | 震撼(50%) | 长句/中等段落/高描写 | "古老的传说/千百年来/神秘的力量" |
| character_intro | 印象锚定法：第一个动作定义角色性格，对话风格独特，不一次性交代所有信息 | 好奇(40%) | 混合/中等段落 | "一袭白衣/不怒自威/深不可测" |
| plant_foreshadow | 不经意埋设法：伏笔藏在日常场景中，在当下有表面功能，每个伏笔标注回收计划 | 好奇(30%) | 混合/中等段落 | 强行插入"殊不知……" |
| resolve_foreshadow | 延迟满足法：先展示结果（异常现象）→再揭示原因（伏笔回收）→回收后立即产生新影响 | 满足(70%) | 中句/中等段落 | "原来如此，一切都在计划之中" |
| transition | 锚点衔接：用时间/空间锚点明确过渡，场景切换必须有明确线索，过渡段≤200字 | 中性(30%) | 混合/稀疏段落 | 流水账式"然后……接着……" |
| breather | 温度调节法：高强度后提供情感调节，用日常展示角色另一面，在轻松中埋下轮冲突种子 | 温暖(30%) | 长句/中等段落/高对话 | 纯日常无信息推进 |
| build_atmosphere | 五感沉浸：开场用感官锚点定位，情绪基调决定感官选择，用环境变化暗示情绪变化 | 震撼(40%) | 长句/密集段落/高描写 | 纯氛围无叙事推进 |

## 意图 → 开头策略（每组选一个，不重复）

| 意图 | 策略A | 策略B |
|------|-------|-------|
| climax | **高压切入**：用正在发生的致命动作开头，不作铺垫 | **感官冲击**：用强烈感官冲击（光/声/冲击波）直接拉入 |
| emotional_impact | **结果先行**：先给情感结果（死亡/失去/背叛），再展开过程 | **沉默冲击**：用沉默和感官细节表达情感，不直接说"他很难过" |
| reveal_secret | **悬念钩子**：用异常感知开头，制造"不对劲" | **对话揭示**：用揭示性对话开头，直接抛出信息 |
| create_conflict | **对话引爆**：用冲突性对话开头，直接抛出对立 | **动作对峙**：用对峙动作开头，制造即刻紧张 |
| advance_plot | **场景定位**：用时间/地点坐标快速定位，然后推进事件 | **中途切入**：从事件中间切入，省略铺垫 |
| show_growth | **感官锚点**：用具体身体感受开头（疼痛/温度/触感） | **动作切入**：用正在进行的动作开头，暗示挣扎状态 |
| build_relationship | **对话开场**：用角色间对话开头，展示关系动态 | **动作互动**：用互动动作开头，展示关系本质 |
| raise_stakes | **危机宣布**：直接用危机/威胁开头，不作铺垫 | **对话引爆**：用揭露危机的对话开头 |
| world_building | **概念锚定**：用具体地标/概念开头，作为世界观入口 | **体验切入**：通过角色对世界的感知展示世界观 |
| character_intro | **印象锚定**：用角色第一个动作定义其性格 | **对话亮相**：用体现角色个性的对话开场 |
| plant_foreshadow | **细节锚定**：用看似普通的细节开头，暗藏异常 | **日常反差**：从日常场景开头，让伏笔自然浮现 |
| resolve_foreshadow | **异常触发**：用异常事件触发回收，先感知"不对劲" | **对话揭晓**：用揭示真相的对话开头 |
| transition | **时间跳跃**：用明确时间坐标快速过渡 | **空间切换**：用空间变化作为过渡锚点 |
| breather | **轻松切入**：用轻松场景/动作开头，给读者喘息 | **日常对话**：用日常对话开头，展示角色另一面 |
| build_atmosphere | **环境沉浸**：用具体环境描写开头，让读者先"站"在场景里 | **感官铺陈**：用多重感官细节铺陈氛围 |

## 章末钩子策略

### 通用钩子（5种，任何意图可用）

| 钩子 | 写法 | 禁止 |
|------|------|------|
| 反转收尾 | 章末制造认知反转，推翻前文预期 | 无铺垫硬反转，反转后不解释 |
| 对话暴击 | 用简短对话收尾，颠覆认知/揭示真相/制造情感冲击 | 日常寒暄，无信息量 |
| 视觉定格 | 用极具画面感的瞬间定格收尾，像电影镜头静止 | 纯风景无情感重量 |
| 数字钩子 | 用具体数字制造紧迫感——倒计时/数量变化/等级差距 | 用"很多""无数"代替具体数字 |
| 视角切换 | 章末切换到另一角色/势力视角，展示他们正在做的事 | 无关角色闲笔，必须与主线相关 |

### 意图专属钩子（每意图4种，选1种，不重复上3章用过的）

| 意图 | 钩子1 | 钩子2 | 钩子3 | 钩子4 |
|------|-------|-------|-------|-------|
| climax | 胜负未分 | 代价揭示 | 绝境反击 | 第三方介入 |
| advance_plot | 下一步悬念 | 信息差钩子 | 意外来客 | 时间紧迫 |
| reveal_secret | 更大谜团 | 认知冲击延宕 | 真相碎片 | 信任崩塌 |
| create_conflict | 冲突升级预告 | 立场固化 | 宣战仪式 | 同盟破裂 |
| show_growth | 新能力试炼 | 成长代价显现 | 极限突破 | 能力反噬 |
| build_relationship | 关系微妙变化 | 未说出口的话 | 信任试探 | 牺牲暗示 |
| plant_foreshadow | 异常细节 | 角色异常反应 | 规则异常 | 物品异常 |
| resolve_foreshadow | 连锁反应 | 部分回收 | 代价兑现 | 新线索 |
| build_atmosphere | 环境预示 | 感官异常 | 时间异常 | 空间异常 |
| emotional_impact | 情感余韵 | 未完成的告别 | 物是人非 | 情感反转 |
| world_building | 新疑问 | 规则暗示 | 历史回声 | 边界模糊 |
| character_intro | 变数预告 | 隐藏动机 | 实力展示 | 身份谜团 |
| raise_stakes | 倒计时 | 代价可视化 | 众叛亲离 | 逃无可逃 |
| transition | 新场景钩子 | 时空锚点+悬念 | 途中遭遇 | 目的地异常 |
| breather | 暗流涌动 | 平静中的预兆 | 日常崩塌 | 角色裂痕 |

**钩子轮换规则**：写前查看上3章使用的钩子类型，本章轮换使用。同一钩子冷却2章。优先使用意图专属钩子，通用钩子兜底。
