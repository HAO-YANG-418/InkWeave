# 玄幻修仙

> 玄幻修仙世界观词库，包含丹田、灵气、灵根、金丹、元婴、飞剑、法宝、功法、境界等修仙体系专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用玄幻修仙世界观词库。写作时自然融入修仙世界的专有名词和感官描写：灵气在经脉中运行的感觉、飞剑破空的锐啸、法宝的灵光、丹药的异香、威压带来的窒息感、天劫降临时的天地异象。身体描写要兼顾传统锚点和修仙特色——除了普通的身体反应（手心冒汗/心跳加速），还要加入丹田气海、经脉运转、灵根属性、神识感知等修仙体系特有的身体感。动作描写要有仙侠味：御剑、掐诀、祭出法宝、身形一闪、袍袖一挥等。

### 约束规则

- 必须使用修仙世界专有词汇，避免出现现代词汇（除非是穿越设定）
- 身体锚点除常规词汇外，必须加入丹田/经脉/神识等修仙身体感知
- 战斗描写要有仙侠特色：法术对决/法宝碰撞/飞剑纵横/天地异象
- 境界体系必须一致，不能出现境界混乱
- 感官描写融入灵气/灵光/威压/道音等修仙元素
- 对话风格要符合古风仙侠，避免过于现代的口语

```
秦风盘坐在石室之中，双目微闭，双手结印。

丹田内，那团金色的灵力旋涡越转越快，经脉中的灵气如江河奔涌，冲击着瓶颈处的壁障。他能清晰地感觉到，金丹期的壁障已经出现了裂纹。

“破！”

他低喝一声，神识猛地向内收缩，引导所有灵气汇聚于丹田一点。

轰——

一声闷响在体内炸开，灵力旋涡骤然凝缩，然后猛然膨胀！一颗金灿灿的丹珠在气海中成型，散发出温润而磅礴的灵力波动。

金丹成了！

石室上空，灵气疯狂汇聚，形成了一个肉眼可见的灵气漩涡。天地间隐隐有仙乐飘来，石壁上的灵纹齐齐亮起，整个洞府都在微微震颤。

秦风睁开眼，眸中精光一闪即逝。他能感觉到，自己的神识比之前强大了数倍，方圆百丈之内的一切动静，尽在感知之中。
```
