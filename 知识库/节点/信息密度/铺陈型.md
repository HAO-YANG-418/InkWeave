# 铺陈型

> 慢节奏铺陈，信息密度低（每千字1-2个新信息点）。描写充分，氛围营造到位，适合氛围型、散文式叙事，但需配合好懂底线，不藏因果。
> 所属节点：信息密度

## 教学指令

你采用铺陈型的信息密度模式。写作以氛围营造和细腻描写为主，不急着推进剧情。每1000字大约1-2个新信息点，留出大量笔墨用于环境描写、感官细节、人物内心、情感流动。场景要写透，不要急着切换。让读者沉浸在氛围中，感受到画面、声音、气味、温度。人物的每一个细微表情、动作、心理变化都值得写。环境描写不是装饰，而是叙事的一部分——用环境烘托情绪、暗示主题、铺垫伏笔。节奏要慢，但不能水——每一个细节都要服务于整体氛围和人物塑造。

### 约束规则

- 每1000字约1-2个新信息点，重在描写和氛围
- 环境描写需调动至少3种感官（视觉/听觉/嗅觉/触觉/味觉）
- 每个场景要写透，不急于切换
- 人物心理活动和微表情要细腻刻画
- 禁止快节奏的事件堆砌
- 描写要有目的，禁止无意义的华丽辞藻堆砌
- 对话可以少而精，每句对话都要体现人物性格或关系

### 范例

**标注**：铺陈型：大量感官描写（阳光/槐花香/冰凉瓷碗/金银花），信息点极少（母亲要来接），重在氛围营造和情绪留白

```
暮春的午后，阳光透过老槐树的枝叶洒下来，在青石板路上碎成一地金斑。空气里飘着隔壁院子槐花的甜香，混着潮湿泥土的气息，是南方小城特有的味道。

苏晚坐在门槛上，手里捧着一碗冰凉的绿豆汤。瓷碗上凝着细密的水珠，顺着碗壁滑到她的手指上，凉丝丝的。

外婆在院子里翻晒草药，竹匾里铺着一层金银花，金黄和银白交织，在阳光下微微发颤。外婆的动作很慢，很轻，像是怕惊扰了什么。

"晚晚，"外婆头也不抬地说，"你妈打电话来了，说下周来接你。"

苏晚舀绿豆汤的手停了一下。

她没有说话，只是低头看着碗里碧绿的汤面，倒映着一小片天空，还有槐树叶的影子。绿豆已经煮得开了花，软糯地沉在碗底。

风过，槐花簌簌落下，有几朵掉进了她的碗里。
```
