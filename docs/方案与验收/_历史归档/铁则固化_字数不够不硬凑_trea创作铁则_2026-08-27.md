# 铁则固化 · 字数不够不硬凑（trea 时期创作铁则）

> 落盘时间：2026-08-27 · 方案方（.md 领地）
> 触发：用户指出"在 trea 的时候说过很多次，字数不够不要拿没营养的东西硬凑，可以适当加点内容，内容丰富程度要好"

## 一、来源（用户原话链路）
- **trea 时期创作铁则原话**："字数不够不要拿没有营养的东西去硬凑，可以适当添加点内容，内容丰富程度要好。"
- 早期方案文档 `InkWeave_最终方案决定_热门网文基准_2026-08-22.md:12` 已收录同义原话："内容写丰富了怎么会字数不够"——精神一致，但**从未落进生成指令的操作示例层**。

## 二、上轮实战实证（根因复盘）
2026-08-26 第27章"进窝"重写闭环（14→96）后几轮，方案方（主机 LLM）确实犯了"硬凑"：
- 第6轮贪心补内容，反灌 4 处"不是X是Y"（方案B ≥3 即 error），评分从 87 掉到 24。
- 终版补"风里煤灰混着油炸腥，他深吸一口，心想今天真累"——无新信息点、均匀填充 = 典型注水。

**根因（铁则本身缺口，非故意违反）**：
- `铁则十九` 只反"AI 均匀填充凑数"，**没正给"字数不够时怎么扩"的 ✔✘ 操作示例**。
- `铁则十一` 只说"90%–100% 为 warning 级（建议补写至达标）"，**只下"补写"令、没说"怎么补"**。
→ 方案方默认用最省事的均匀填充/新开无关句去凑，踩中注水。

## 三、三处铁则补丁（已落 `InkWeave写作工坊/生成指令.md`）

### 补丁① 铁则十一 · 字数硬约束（新增"补写红线"）
```
- ⚠️ 补写红线（trea 时期创作铁则）：warning 级"补写至达标"严禁注水——禁止为凑字数
  新开与主线无关的支线、均匀填充叙述、复制同结构句、或堆砌无信息量的环境/心理描写。
  正确补法见铁则十九·扩写准则：只加带新信息点的有营养内容。
```

### 补丁② 铁则十九 · 内容密度（加 trea 来源注记）
```
**（含 trea 时期创作铁则原话："内容写丰富了怎么会字数不够"——字数不够不硬凑，
  靠加有营养内容把丰富度做上去。）**
```

### 补丁③ 铁则十九 · 内容密度（末尾新增"扩写准则" ✔✘）
```
- 扩写准则（trea 时期创作铁则·正补写操作）：字数差口靠"加有营养的内容"填实，不是"硬凑"。
  - 加料方向（任选，必须带新信息点）：多铺一个环境细节 / 补一段人物微反应或动作 /
    落一个伏笔或设定 / 给配角一句有性格的台词 / 多走一个镜头（中景→特写）/
    加一次外部世界反咬（铁则五）。
  - ✔ 差300字：补"他蹲下，指尖蹭过墙根那道蓝痕——和收种时掌心跳的是同频"，
    既填字数又落伏笔、加触觉。
  - ✘ 差300字：结尾加"风里煤灰混着油炸腥，他深吸一口，心想今天真累"——
    无新信息、均匀填充=注水，检测判内容密度低。
  - ⚠️ 注水判定（删掉这段，主线/人物有无影响？无影响=水）：新开无关支线、复制同结构句、
    一句话拆三句纯流水、堆砌形容词——一律重来，不算补写。
```

## 四、未来写章须遵守（操作约束）
1. 写前分析注入铁则十九时，本准则一并生效。
2. 重写轮次若遇"字数差口"，**第一反应是找新信息点扩写**（伏笔/人物反应/镜头/外部反咬），不是开无关句凑。
3. 自检"注水"：补的这段删掉，主线/人物不受影响 = 水，必须重来。
4. 双树检测的"内容密度低 / 均匀填充"警告，应回指本条准则而非降门禁。
