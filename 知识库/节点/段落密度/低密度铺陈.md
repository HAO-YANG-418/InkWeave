# 低密度铺陈

> 长段落为主，铺陈细腻，节奏缓慢。适合文学性描写、氛围营造和深度心理刻画，有沉浸感。
> 所属节点：段落密度

## 教学指令

采用低密度长段落写法。段落可以较长，允许在一个段落内完成完整的场景铺陈、氛围渲染或心理刻画。注重细节的层次感，从视觉、听觉、触觉等多个维度慢慢展开画面。节奏舒缓，不急于推进情节，让读者沉浸在场景中。对话较少，以叙述和描写为主。

### 约束规则

- 单段可到300字，但不得超过400字
- 每千字不少于10个段落
- 长段落内部要有层次变化，不能平铺直叙
- 每3个长段落后必须有一个短段落或对话换气

### 范例

**标注**：长段落细腻铺陈，沉浸感强，节奏缓慢。

```
记忆中的夏天总是和那条河有关。河水不深，最深处也只到胸口，河底是圆滑的鹅卵石，阳光好的时候能看见鱼在石缝间穿梭。两岸的芦苇长得比人还高，风一吹就沙沙作响，白色的芦花飘得满河都是。他和她常常在午后溜到河边，他摸鱼，她坐在石头上洗脚，脚趾头被冰凉的河水浸得发红。那时候的阳光好像永远不会落山，空气里永远有芦苇的清香和鱼鳞的腥味，时间像河水一样慢悠悠地流，什么都不急。
```
