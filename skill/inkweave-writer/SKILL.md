# InkWeave 写作工坊（可分发 skill · 唯一入口）

> **本 skill 是命令驱动的执行器，不是写作建议。**
> 加载本 skill 后，**你唯一允许的动作**是运行下方编排器脚本。禁止凭记忆直接写章节正文、禁止跳过写前分析。

## 唯一动作（每次写章都执行，不可省）

在 **InkWeave 仓库根目录**下运行编排器：

```bash
# 步骤 1：规划 + 生成（写前分析强制前置）
npx tsx 检测工具/inkweave-write.ts --chapter <章号> --title "<标题>" [--intent <意图>] [--outline <大纲文件>] [--target 2800] [--project <项目名>]

# 步骤 2：agent 模式（无 LLM key）下，按步骤1输出的「镜头链规划」写正文到指定文件，
#          然后运行验收（门禁循环，直到 0 error）：
npx tsx 检测工具/inkweave-write.ts --review "<章节文件绝对路径>" [--target 2800] [--project <项目名>]
```

- **provider 模式**（已配 `CUSTOM_BASE_URL`+`CUSTOM_MODEL`）：步骤 1 会自动调引擎生成并跑门禁自纠循环，直接产出终稿。
- **agent 模式**（当前默认，无 key）：步骤 1 输出规划简报，由你按规划写正文，步骤 2 跑门禁循环把 error 打回给你修，直到 0 error。

## 编排器强制做了什么（你无法跳过）

1. **写前分析（镜头链规划文件）**：调用 `检测工具/pre-analysis.ts` 与风格配方，写出 `_plan_第N章.md`，要求每场 ≥400–600 字、合计 ≥ target 才允许开写。无规划文件 = 未走流程。
2. **生成**：provider 模式走 `源码/cli.ts write`（引擎 + 底座 base-prompt + 题材层 + 元件卡库）；agent 模式由你按规划写。
3. **门禁循环**：跑 `检测工具/check-chapter.ts`（双树门禁）。有 error 即打回，不能声明完成。0 error 才出货。

## 共享资源（位于 InkWeave 仓库根）

- `源码/kb/base-prompt.ts`：生成底座（总目标元规则 + 十一铁则）
- `知识库/题材层/`：按本书题材锁调性（如 `都市爽文.md`）
- `知识库/元件卡库/`：母题卡 / 桥段卡 / 章法卡
- `检测工具/`：check-chapter.ts（门禁）· pre-analysis.ts（写前分析）· inkweave-write.ts（本编排器）
- `InkWeave写作工坊/写前分析.md` · `生成指令.md`：流程与铁则详情（参考，不必手读）

## 铁律（防偷懒划水 · 防初稿写空 · 加载本 skill 即生效）

> **底座铁则全文（同步自 `源码/kb/base-prompt.ts`【篇幅与展开度】）。加载本 skill 时即进入模型 system 上下文，不依赖读规划文件、不依赖记忆。** 这是根治"半调用 / 初稿写空"的地基——之前 agent 模式只靠规划文件 + 记忆间接生效，铁则从未真进 system，这层已在此焊死。

- **每章篇幅硬标准**：每章正文目标 2800–3200 字，**硬下限 2800 字**（门禁低于即 error，短而密也须补到 2800）。镜头链没铺满目标篇幅就继续展开，不要写短就停。
- **每场多维度展开**：动作线 + 对话碰撞 + 人物心理/生理反应 + 环境细节，**四者至少三者在场**；禁止只用概括句带过情节。
- **禁止概括式跳过关键情节**：不写"他处理完就走了"，要写出怎么处理、遇到什么阻碍、对方什么反应、结果如何。
- **篇幅靠写足镜头**：动作细节、对话来回、感官落地撑起 2800 字体量；不注水、不重复、不靠无效感慨凑数。短而密是好文，但一章必须有足够镜头数累积到目标篇幅。

**操作流程铁律（不可省）：**

- **盲写 = 真加载底座 + 题材层 + 元件卡库后写，不是凭记忆。** 上方铁则已加载即生效，严禁凭记忆写、严禁"凭记忆写得差不多再让门禁兜底"（记忆里的文学极简偏见会盖过底座硬标准，导致初稿写空）。
- **镜头链规划是强制前置**：字数从规划来（内容写丰→字数自然够），不是写完了再补。单场 < 预算 85% 即该场写空，须补场景内容而非 padding。
- 禁止跳过编排器直接写正文。
- `--review` 会报「初稿达标率」：实际字数 / 规划预算 < 85% 即预警写空，须先补内容再过门禁。
- **agent 写正文时，先把每场字数预算（≥ target/4）写进草稿开头注释，写完一场立即数该场字数，不足则补场景内容；四场全达标（合计 ≥ target×0.85）才跑 --review。**
- 任何章节未跑 `--review` 至 0 error，不得交付。
