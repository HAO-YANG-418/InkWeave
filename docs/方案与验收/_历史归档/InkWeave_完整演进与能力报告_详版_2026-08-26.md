## 一、Trea 是谁、怎么来的

依据 `2026-08-17 / 08-18 memory` 与 `docs/历史评审/InkWeave_联合推进方案_WorkBuddy与trea.md`：

- 早期 Trea 完成了 InkWeave 的**生成端硬化**雏形（v4.7→v4.9）、`reverse-loop` 反向闭环雏形、以及一套网页面板（后按你「删网页」指令移除）。
- Trea 留下三个关键盲区，WorksBuddy 在 **08-17~08-19 接手补齐**：
  1. **error 不拦生成**：检测器有 error 但生成循环不读 `passed`，章节带着 error 直接交付；
  2. **跨章检测「写了没接线」**：`pre-analysis` 里有跨章指纹分析代码，但 `orchestrator` 从未调用，等于摆设；
  3. **阈值打架 / 双树漂移**：生成时树（源码/checks）与验收树（检测工具/checkers）口径不一致，`D2「不是X是Y」` 在两端判级不同。

Trea 时代的「联合推进方案」明确分工：Trea 负责代码落地、WorkBuddy 负责方案与核查，最终统一由 WorkBuddy 收口。

## 三、目前能力（核心）

### 3.1 生成侧 —— 铁则体系（v4.8）

`InkWeave写作工坊/生成指令.md` 当前含 **20 条铁则 + 5 条技法 + 16 条禁令**，覆盖：

- **叙事骨架**：事件优先（铁则一）、读者理解链（二）、句群节奏（三）、一拍一息（四，已软化）、外部压力（五）、Show Don't Tell（六）、身体锚点（七）、感官基调起伏（八）、开头轰炸（九）、章末钩子（十）、字数硬约束（十一）、破折号破格（十二）、句式控制（十三）、对话引导词多样性（十四）、段落开头多样性（十五）、人味（十八）、内容密度（十九）、去 AI 味（二十）。
- **技法**：对话融合、不是X是Y替代、破折号替代、拍内融合、碎句免疫。
- **禁令**：16 条套路词速查（嘴角勾起/眼中寒芒/倒吸凉气/恐怖如斯/然而/然后/殊不知……）。

### 3.2 检测侧 —— 双树

- **生成时树（`源码/checker.ts`）**：15 项检测器 + R4 字数复合门禁：
  `anchor_density / filler_words / paragraph_length / dialogue_interleave`（对话穿插）/ `sentence_rhythm / info_density / sensory_coverage / opening_impact`（开头冲击）/ `cliche_reactions / fragmented_sentences / dialogue_conflict / ending_hook / twist_density / golden_300 / opening_taboos`，外加 `word_count_short`（空心守卫：短而密放行 warning、短而空 error）。
- **验收树（`检测工具/checkers.ts`）**：D1–D6 迭代基础套 + 空心守卫，与生成树口径对齐。
- **阈值外置**：`知识库/阈值标定/default.json` 为单一标定源，含 **52 个阈值字段**，经 `config-merger` 第 4 层 `threshold_overrides` 灌入双树。

### 3. 工具链（CLI，`package.json` 实测）

| 命令 | 作用 |
|---|---|
| `gwe write --number <n> --title <标题>` | 生成章节（入口） |
| `npm run check` / `check-all` | 单章 / 全量检测 |
| `npm run compile-kb` / `build`（prebuild 自动跑） | KB 编译 + tsc 重建 |
| `npm run pre-analysis` | 写前分析 / 跨章指纹注入 |
| `npm run auto-pipeline` / `quick-write` | 自动化流水线 / 快速写作 |
| `检测工具/health-report.ts` | 双树体检，导出 `health-matrix.json`（**默认 `--out` 会覆盖基线，须用临时文件**） |
| `检测工具/verify-regression.ts` | 两份矩阵 delta 对比，回归即 `exit 1` |

### 3.4 闭环能力（反馈 → 生成）

- **章间 reactive**：`pre-analysis.ts:429 injectFingerprint` 读上章 `fingerprint.json`，注入破折号 / 不是X是Y / 逗号比等禁忌（含反例+正例）。
- **全局矩阵注入（档1）**：`readHealthMatrix` 聚合 `health-matrix.json` 全章违规，加权（error×3+warning×1）取 top-5，注入本章避雷清单，**不改铁则硬值**。
- **回归自动化（档2）**：`verify-regression.ts` 直接 diff 两份矩阵，任一 ruleId error 上升即 `exit 1`，CI/人工复核可用。
- **阈值自适应（档3）**：按方案**暂缓**，留接口，防震荡/过拟合。
