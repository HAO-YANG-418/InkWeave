# 重氛围渲染

> 侧重战斗的感受、压迫感和紧张氛围（默认），动作与感官/心理交织，不追求招式细节而追求整体张力。
> 所属节点：战斗风格

## 教学指令

战斗描写注重氛围和感受，不逐招拆解。通过感官印象（风声、金属味、血的温度、压迫感）、身体反应（心跳加速、肌肉紧绷、肾上腺素）和环境变化（灯光闪烁、地面震动、碎片飞溅）来渲染战斗的紧张感。关键动作慢镜头特写，非关键动作一笔带过。节奏有张有弛，在暴烈的动作中穿插瞬间的寂静。

### 约束规则

- 战斗中必须有感官描写和身体感受
- 不逐招罗列，关键动作重点写，过渡动作简洁带过
- 战斗环境必须参与氛围营造
- 节奏要有张弛，不能全程紧绷

### 范例

**标注**：不写具体招式，通过感官（风的声音/血的温度/虎口发麻）和环境（铜碗滚动的回响）渲染战斗。

```
刀砍下来的时候，他听见了风的声音。

不是风——是刀劈开空气的尖啸。他本能地侧身，刀锋贴着肩膀过去，割破工服，皮肤上立刻泛起一道火辣辣的凉。然后是血，温热的，顺着胳膊往下流，滴在地上，和黑色的煤尘混在一起。

对方的第二刀已经到了。

他来不及想任何事。身体比脑子快——矿灯的光在刀刃上晃了一下，他抬臂去挡，金属相撞的瞬间，虎口震得发麻，铜碗从腰间脱落，在地上滚出很远，发出空旷的回响。

黑暗里全是声音：呼吸声、金属声、血涌进耳朵里的轰鸣声。
```
