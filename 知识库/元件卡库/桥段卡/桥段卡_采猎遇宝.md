# 桥段卡：采猎遇宝

- **母题**：幼弱成长 + 凶兽/祭灵机缘 + 同频觉醒
- **结构**：①采猎/探索遇凶兽（危机） → ②险中得宝/遇祭灵 → ③与活物共鸣（同频觉醒） → ④实力小跳+埋身世线
- **情绪曲线**：险(0-35%) → 得(35-55%) → 鸣(55-85%) → 跃(85-100%)
- **钩子位**：章末留「祭灵开口了」或「上界有人来了」
- **适配题材**：太古玄幻 / 成长流 / 宏大世界观
- **来源书**：完美世界（结构提炼，非原文）
- **禁忌**：禁止成长跳跃（须采猎式渐进）；禁止祭灵/兽吼机制混乱；禁止机缘无代价（须有凶险铺垫）
