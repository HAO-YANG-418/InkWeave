# InkWeave — 墨织 · 网文写作智能引擎

> 「读者手指划到你的正文，只有3秒决定要不要看下去。不是三章，是三秒。」

**InkWeave**（墨织）是一个专为中文网文设计的**写作智能引擎**——以墨为线，编织故事。不依赖大模型，纯规则驱动，毫秒级响应。

> **大模型写，墨织判。** 两者配合，迭代到分数达标再发布。

## 核心能力

- **7维雷达评分**：身体反应 / 感官信号 / 动作推进 / 情绪张力 / 信息推进 / 转折密度 / 章末钩子
- **35项质量规则**：开篇3秒、假钩子、AI水文、套路反应、水词填充、句式波形、逗号链等
- **锚点三级制**：套路反应（×0.2）、普通反应（×1.0）、高质量生理反应（×1.8）
- **9项专项检测（v3.4）**：角色台词辨识度、动作点名册、感官密度、句群波形、数据锚点、感叹号配额、禁用字、不是X是Y模式、逗号链
- **跨章分析**：开头/结尾模式重复检测、超期伏笔警告、场景衔接提示
- **22个配置节点**：平台（起点/番茄/七猫/晋江/飞卢）、题材（仙侠/都市/科幻/悬疑等11类）、风格（节奏/视角/修辞/语调）
- **18个内置预设**：6套题材预设 + 12套平台预设，开箱即用

## 快速开始

### CLI 命令行

```bash
npm install -g inkweave

# 检测一个章节
inkweave check chapter.txt

# 从标准输入读取
cat chapter.txt | inkweave -

# JSON 输出（用于程序集成）
inkweave --json chapter.txt > report.json
```

### 代码调用

```typescript
import { createEngineWithKB, MockProvider } from 'inkweave';

const { engine } = createEngineWithKB(new MockProvider());

// 单章检测
const result = engine.check(chapterText);

// 跨章分析（多章对比）
const context = engine.getBookContext();
context.addChapter(chapter1);
context.addChapter(chapter2);
const warnings = context.getCrossChapterWarnings();
// → ["最近3章连续使用单字感官开头，建议换对话/动作开头"]
// → ["重要伏笔'剑骨封印'在第3章埋设，已过5章未回收"]
```

### 配合 LLM 使用

```typescript
import { createEngineWithKB, OpenAICompatibleProvider } from 'inkweave';

const provider = new OpenAICompatibleProvider({
  apiKey: 'your-api-key',
  baseURL: 'https://api.deepseek.com',
  model: 'deepseek-chat',
});

const { engine } = createEngineWithKB(provider);
engine.selectPreset('preset_urban_tomato');

const stream = await engine.writeChapter({
  outline: '主角获得系统，第一次使用就遇到危机',
  previousChapter: '...',
  onDelta: (text) => process.stdout.write(text),
});
```

## 评分说明

| 分数区间 | 等级 | 说明 |
|---------|------|------|
| ≥90分 | 🏆 优秀 | 对标一线热门网文，追读力极强 |
| ≥85分 | ✅ 良好 | 达到发布标准，读者留存率高 |
| ≥75分 | ⚠ 及格 | 有明显问题，需要修改 |
| ≥60分 | ⚠ 较差 | 较多问题，建议重写关键段落 |
| <60分 | ✗ 不达标 | 质量不合格，读者会直接划走 |

## 对比测试

| 文本类型 | 字数 | 得分 | 违规数 |
|---------|------|------|-------|
| 追读力风格 | 388字 | **84.7** | 3 |
| 经典套路开头 | 372字 | **84.4** | 3 |
| AI写景水文 | 391字 | **57** | 9 |

**AI写景水文（57分）被精准识别的问题：**
- 开篇首句49字，太长，读者扫一眼就划走
- 开篇写景/背景开头，浪费黄金3秒
- 连续比喻过密（"宛如泼墨山水画""如水的月光"）
- 空洞成语堆砌（连绵起伏、美不胜收、波光粼粼）
- 填充词过多（"仿佛""不禁""淡淡"）

**追读力风格（84.7分）：**
- 首句"疼。"仅1字，直接切入身体感受
- 全程无空泛写景，信息密度极高
- 章末断裂钩子"是红色。"制造强悬念

## 7维雷达评分

| 维度 | 核心问题 | 评分依据 |
|------|---------|---------|
| **身体反应** | 读者有没有"感受到痛"？ | 身体锚点密度、质量分级、千字锚点数 |
| **感官信号** | 五感有没有被调动？ | 视觉/听觉/触觉/嗅觉/味觉词频 |
| **动作推进** | 故事有没有在动？ | 动作动词密度、对话标签、静态描写比例 |
| **情绪张力** | 有没有让人心跳加速？ | 情绪词、紧迫感、反差、冲突信号 |
| **信息推进** | 有没有在给新信息？ | 新名词/新概念出现频率，信息量增量 |
| **转折密度** | 有没有意外？ | 转折词、认知颠覆、反转信号频率 |
| **章末钩子** | 读者会不会点下一章？ | 最后100字的新信息密度、悬念质量 |

## v3.4 新增：9项专项检测

| 检测项 | 检测内容 | 示例违规 |
|--------|---------|---------|
| **角色台词辨识度** | 不同角色台词是否有区分度 | 所有角色说话风格雷同 |
| **动作点名册** | 动作描写是否单调重复 | 连续使用"点了点头""摇了摇头" |
| **感官密度** | 五感描写是否过于集中视觉 | 全篇只有视觉描写 |
| **句群波形** | 句子长短交替是否有节奏 | 连续10句以上长度相同 |
| **数据锚点** | 数值/数据是否具体可感 | "数万人""无尽的力量" |
| **感叹号配额** | 感叹号是否过度使用 | 一段超过3个感叹号 |
| **禁用字** | 网文常见禁用字 | "呢""吧""吗"句尾滥用 |
| **不是X是Y** | 否定揭示句式是否过度 | 连续使用"不是……是……" |
| **逗号链** | 逗号连接是否过长 | 单句超过8个逗号 |

## 跨章分析

InkWeave 不仅检测单章质量，还能跨章追踪写作模式：

- **开头模式检测**：连续3章用"单字感官开头"？它会在第4章提示你换对话/动作开头
- **结尾模式检测**：连续用"不是X。是Y。"结尾？它会建议换悬念提问或动作收尾
- **超期伏笔警告**：重要伏笔超过5章未回收，自动提醒
- **场景衔接**：自动提取上章结尾场景，提示本章自然承接

## 架构

```
inkweave/
├── src/
│   ├── index.ts              # 统一出口
│   ├── types.ts              # 类型定义 + 默认阈值/权重
│   ├── gwe-engine.ts         # 引擎主类
│   ├── checker.ts            # 35项规则检测器
│   ├── radar.ts              # 7维雷达评分
│   ├── anchor-detector.ts    # 身体锚点检测（三级质量分级）
│   ├── filler-words.ts       # 填充词检测
│   ├── config-merger.ts      # 配置合并器
│   ├── node-registry.ts      # 22个节点注册表
│   ├── validator.ts          # 冲突/依赖验证
│   ├── prompt-builder.ts     # LLM提示词构建
│   ├── llm-provider.ts       # LLM抽象层（OpenAI兼容/Mock）
│   ├── kb-loader.ts          # 知识库加载
│   ├── book-context.ts       # 全书上下文 + 跨章分析
│   ├── book-checker.ts       # 全书批量检测
│   ├── cli.ts                # 命令行工具
│   ├── checks/               # v3.4 专项检测模块（9项）
│   └── kb/                   # 知识库数据
│       ├── nodes/            # 22个节点 × 选项KB
│       ├── presets/          # 18个内置预设
│       ├── base-vocab.json

│       └── base-prompt.ts
```
