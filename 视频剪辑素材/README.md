# 视频剪辑素材库

> InkWeave 写作引擎对外宣传素材归档目录。

## 用途
存放产品宣传用的视频片段、动图、截图、讲解脚本、文案草稿等。所有对外推广物料统一归口此处，便于协作者接手与版本管理。

## 当前素材清单
| 文件 | 类型 | 说明 |
|------|------|------|
| `InkWeave_分支分类体系_综合视图_2026-08-28.html` | 图文展示页 | InkWeave「1伞 + 3子skill + 22维节点 + 17预设 + 双树检测」体系一页视图，适合录屏讲解或嵌进宣传页 |

## 命名规范
- 通用格式：`主题_类型_日期.扩展名`（如 `功能演示_录屏_2026-08-28.mp4`）
- 视频：`功能演示_录屏_YYYY-MM-DD.mp4` / `卖点短片_剪辑_YYYY-MM-DD.mp4`
- 图片：`架构图_截图_YYYY-MM-DD.png` / `成效对比_图_YYYY-MM-DD.png`
- 文案：`口播稿_YYYY-MM-DD.md` / `短视频脚本_YYYY-MM-DD.md`
- 工作版与宣传版分离：`docs/方案与验收/` 放内部工作文档，本目录只放对外成品。

## 使用约定
- 新增素材直接拖入本目录，并同步更新上方清单。
- 未定稿素材可加 `_草稿` 后缀，定稿后去除。
- 素材来源需可追溯：图文类注明对应工作文档路径，视频类注明录制章节/版本。
