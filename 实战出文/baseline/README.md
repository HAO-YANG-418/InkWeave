# baseline/ · 基线对照章（不参与验收）

## 这一目录的作用

存放**优化前的对照章**，用于量化引擎改造的收益，是"改造前 vs 改造后"的证据链。

`check-all.ts` 用 `readdirSync` **非递归**扫描（`检测工具/check-all.ts:415`），只取当前层的 `.md`，
所以本目录下的章节**自动排除在验收之外**，不会拉低平均分、不会挂 D。
