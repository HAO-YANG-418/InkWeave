# 长线布局（5章+）

> 爽点稀疏，5章以上才有一个大爆发。重在长线布局、伏笔埋设、人物成长，适合硬核剧情流、悬疑推理、史诗类作品。
> 所属节点：爽点频率

## 教学指令

你采用长线布局的节奏模式。爽点/大爆发的间隔在5章以上，中间大量篇幅用于伏笔埋设、人物塑造、世界观展开、情感铺垫。读者获得的不是即时满足，而是“伏笔回收时的震撼”。你需要精心布局：前期看似无关的细节，到爆发时全部串联起来，给读者“原来如此！”的巨大快感。中间章节不能无聊——要用悬念、人物魅力、世界观谜团来保持读者的阅读动力。每一个“闲笔”都可能是伏笔，要让二刷的读者能发现前面埋的线索。爆发时必须将前面所有线索收拢，形成强烈的情感冲击和智力满足。

### 约束规则

- 大爽点/大爆发间隔5章以上，重在长线布局
- 每章必须有至少1个悬念点或伏笔线索，不能纯铺垫无信息量
- 前期埋的伏笔必须在爆发时回收，禁止烂尾伏笔
- 中间章节用悬念、人物魅力、世界观谜团维持阅读动力
- 爆发章节必须将多条线索收拢，形成“原来如此”的震撼效果
- 伏笔要自然，不能刻意到读者一眼就看出“这是伏笔”
- 人物成长线必须和大爆发呼应，让爽点同时是人物弧光的顶点

### 范例

**标注**：长线布局模式：前4章分散伏笔（血迹/戒指印/烧毁信/冷灯泡），第5章集中推理回收，智力爽感强烈

```
【第1-4章 长线布局】
第1章：侦探陈默第一次进入庄园，注意到壁炉旁的地毯上有一小块不易察觉的深色痕迹。管家说那是红酒渍。（伏笔：血迹）
第2章：陈默和二小姐交谈时，她下意识地摸了摸左手无名指——那里有一圈很浅的白印，但她并没有戴戒指。（伏笔：婚姻秘密）
第3章：陈默在书房发现一封烧毁一半的信，只能辨认出“……不能让他知道……遗产……”几个字。（伏笔：动机）
第4章：晚宴上，大少爷提到案发当晚他在书房看书，但陈默注意到书房的台灯灯泡是冷的。（伏笔：不在场证明造假）

【第5章 爆发】
陈默把所有人召集到客厅，缓缓说道：

"凶手就在这个房间里。"

他一一列举证据：壁炉旁的血迹经过检测是人血而非红酒、二小姐暗中成婚的对象是死者的私生子、烧毁的信是死者更改遗嘱的证据、大少爷的不在场证明因为冷灯泡而不攻自破……

所有线索汇聚到一个人身上——

管家的脸色越来越白，终于瘫倒在椅子上。
```
