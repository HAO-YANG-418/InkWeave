# 题材层（P4 产物 · 写前入口包装层）

> 本层由 P4「题材层包装」产出。把"题材个性"从通用能力里抽出来封装，对齐 Lorn 的"题材目录 = 包装层"范式：**通用能力（节点/通用桥段章法）共享，题材个性各自封装**。

## 四层架构中的定位

```
知识库/
├── 通用层/      # 跨题材铁则、通用桥段、通用章法（暂由 知识库/数据/ + 节点系统承载）
├── 题材层/      # ★本层：每题材一套包装（定位/爽点/好懂基调/禁忌/推荐元件卡/预设引用）
├── 元件卡库/    # 写什么结构（母题/桥段/章法卡）——本层只【指向】，不重复存
└── 门禁层/      # 检测工具/ 18 项 + 反AI味 + 相似度（已有）
```

- 节点系统控"怎么写"（风格），题材层 + 元件卡库控"写什么"（骨架 + 调性）——二者正交。
- 题材层是**写前入口**：先按题材锁定调性 + 推荐卡，再调具体元件卡。

## 调用（写前分析.md 第3.5步）

1. 先读 `知识库/题材层/<本书题材>.md` → 锁定题材调性 + 取推荐元件卡清单
2. 再按第3.5步调具体母题 / 桥段 / 章法卡（本层已指向）
3. 节点配置引用本层「对应预设」

## 已建题材层

- 玄幻 / 都市爽文 / 悬疑 / 电竞 / 灵异
- 其余题材（历史/废土/西方奇幻/科幻/武侠/轻小说…）可后续扩，或暂复用 `知识库/预设/` 对应题材预设。

## 铁律

- **好懂优先**：任何题材层的"基调"不得回灌"冷峻极简 = 高级"；若引用预设含冷峻项，以好懂优先覆盖，文学性不凌驾好懂。
- **不重复**：本层只聚合指向，元件卡内容以 `知识库/元件卡库/` 为准，改卡改本层引用即可。
- **禁跨题材错配**：桥段卡自带「适配题材」，选题材层推荐清单之外的卡须核对适配字段。
