# 军事战争

> 军事战争世界观词库，包含战壕、步枪、坦克、炮弹、狙击、潜伏、军装、勋章、指挥部、战场、硝烟、弹壳、迷彩、通讯兵等军事战争专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用军事战争世界观词库。写作时自然融入军事战争的专有名词和感官描写：硝烟的刺鼻气味、炮弹爆炸的震耳欲聋、子弹破空的锐啸、坦克履带碾过碎石的咯吱声、军装粗糙布料的摩擦。身体锚点偏军事化：扣扳机的手指、被后坐力震麻的肩膀、匍匐在地时手肘的擦伤、烟熏火燎的脸、被弹片划伤的手臂。动作描写要有军事味：匍匐前进、举枪瞄准、上膛、投掷手榴弹、呼叫炮火支援、隐蔽、卧倒、冲锋、撤退。场景：战壕、阵地、碉堡、指挥部、坦克内部、丛林、沙漠、雪地、城市废墟。氛围紧张肃杀，充满硝烟和铁血。

### 约束规则

- 必须使用军事战争专有词汇，军事术语要准确
- 武器装备和战术动作要符合军事常识
- 战场描写要有真实感：硝烟/爆炸声/弹片/血迹/尸体
- 感官描写注重：硝烟味/爆炸声/子弹呼啸/坦克轰鸣/尘土
- 对话简洁有力，符合军人说话方式（短促/明确/术语）
- 展现战友情谊和战争残酷，但不要过度渲染血腥

### 范例

**标注**：军事词库示例：战壕/炮弹/爆炸/硝烟/坦克/履带/机枪/炮火支援/拉栓上膛/准星等军事词汇，战场氛围紧张肃杀

```
炮弹落下的时候，周铁柱正趴在战壕里啃干粮。

轰——！

地面猛地一震，泥土劈头盖脸地砸下来，他下意识地把半个身子埋进战壕壁上，干粮掉在了泥水里。爆炸掀起的气浪从头顶扫过，带着灼热的弹片和刺鼻的硝烟。

「三班！报数！」连长大喊的声音从炮火间隙里传过来。

「一！」「二！」「三！」……

报到第七个的时候，停了。

周铁柱抹了一把脸上的泥和血——他不知道是谁的血——抬头看向阵地前方。硝烟中，三辆日军坦克正碾过铁丝网，履带咯吱咯吱地响，像是死神在磨牙。后面跟着黑压压的步兵，端着刺刀一步步逼近。

「通讯员！呼叫炮火支援！坐标347,211！快！」

「机枪手！给我把步兵压住！」

周铁柱拿起身边的步枪，哗啦一声拉栓上膛。他的手在抖，但手指扣上扳机的那一刻，反而稳了。

一百米。

八十米。

他深吸一口气，准星对准了最前面那个军曹的脑袋。
```
