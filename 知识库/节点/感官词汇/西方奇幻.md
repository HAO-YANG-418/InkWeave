# 西方奇幻

> 西方奇幻世界观词库，包含魔法、精灵、矮人、龙、骑士、剑、法杖、城堡、巨龙、地精、巫术、咒语、卷轴、公会、王国等西方奇幻专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用西方奇幻世界观词库。写作时自然融入西方奇幻的专有名词和感官描写：盔甲碰撞的铿锵声、火炬噼啪燃烧的气味、魔法涌动时的空气震颤、龙息的灼热、酒馆里麦酒和烤肉的混合气味。身体锚点可以包括：盔甲的重量压在肩上、剑柄磨出的老茧、魔法反噬时的血脉偾张、长弓弓弦勒入指尖。动作描写要有奇幻味：拔剑出鞘、吟诵咒语、施放火球、举起盾牌、骑乘巨龙、锻造武器。场景：中世纪城堡、幽暗森林、矮人矿洞、精灵圣地、魔法师塔、冒险者公会、酒馆、龙穴。

### 约束规则

- 必须使用西方奇幻专有词汇，避免混入东方修仙词汇
- 魔法体系要有规则，不能随意施放无代价的魔法
- 种族特色鲜明：精灵优雅/矮人粗犷/地精狡猾/巨龙傲慢
- 感官描写注重：盔甲金属声/火炬气味/魔法震颤/麦酒香
- 对话风格偏中世纪/欧式，可以适当使用古雅措辞
- 战斗描写要有冷兵器时代的质感：剑与盾/弓与箭/魔法与铠甲

### 范例

**标注**：西方奇幻词库示例：酒馆/麦酒/锁子甲/长剑/佣兵/法杖/暗影法师/灵魂石/斗篷等西方奇幻词汇自然融入

```
酒馆的门被推开，一阵冷风裹着雨丝灌进来。

来人穿着一件湿透的灰色斗篷，兜帽压得很低，腰间挂着一把用旧布缠着的长剑。他走到吧台前，把几枚铜币拍在潮湿的木台上："麦酒，热的。"

酒馆老板打量了他一眼——斗篷下露出锁子甲的领口，靴子上沾满了泥和血，走路时右手始终不离剑柄。佣兵，而且是刚从战场上下来的那种。

"北边的仗打完了？"老板一边倒酒一边问。

来人摘下兜帽，露出一张年轻但疲惫的脸，左脸上有一道还没愈合的刀疤。他端起酒杯喝了一大口，麦酒的热气让他的脸色稍微好了一些。

"仗永远打不完。"他放下酒杯，目光扫过酒馆里稀稀拉拉的客人，最后停在角落的一个戴兜帽的身影上——那人面前的桌上放着一根黑木法杖，杖头镶嵌的暗红色宝石，在昏暗中微微发着光。

他认得那种宝石。那是只有暗影法师才使用的灵魂石。
```
