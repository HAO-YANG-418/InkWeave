## 三、分期路线

### 阶段一 · 跑量积累（方案方主导，轻量代码）
- **G7** 继续实战（裂日 58+ 或新载体）：严格照自检清单第 0 步跑 `pre-analysis` 拿上章禁忌，手写 / 或引擎生成。
- **G6** 起步：攒章节样本，为 A/B 度量备料。
- 退出标准：≥10 章连续实战、双树 0 error、tells 复发率数据化。

### 阶段二 · 闭环硬约束 + 双树统一（代码方高杠杆）
- **G1（#2）** 反向闭环升级：`injectFingerprint` 重构（反例+正例+合并 step0 风格契约）+ `crossChapterRepeat` 跨章校验 + `sense_density` 闭环（上章 error 维度本章升一级）。
- **G2（D4）** 双树同概念合并为单一源（CLI 正则作门禁权威、源码 LLM 作 async 增强）。
- **G3（U2 完整）** 其余过敏检测器挂 KB 节点 `threshold_overrides`。
- 退出标准：实战堆叠/失衡复发率下降；双树口径零漂移；profiler 全量零回归。

### 阶段三 · 产品化（代码方 + 卖课）
- **G4（#3）** 轻量模式验证（接 step0 配方，跑 3 章实测）。
- **G5（#4）** 打包进 Storyvein 浏览器模块（纯函数核心 + 实时质检侧栏）。
- **G6（#5）** 效果度量 A/B 盲评（卖课弹药）。
- 退出标准：Storyvein 实时质检可用；A/B 报告交付。

### 阶段四 · 软件化（需 API key，独立里程碑）
- **G9** D-SMOOTH 实证（①-C 转正）、U3 LLM 语义层解冻验证、反向闭环 LLM 增强。
- 范围边界：不占内部 skill 轮、不动钥匙额度，待用户接入 API 后做。
