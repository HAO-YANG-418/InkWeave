# 轻小说日常

> 轻小说日常世界观词库，包含校园、教室、同桌、社团、便当、校服、暑假、打工、同学、老师、便利店、电车、青春等校园日常/轻小说专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用轻小说日常世界观词库。写作时自然融入日式/校园轻小说风格的专有名词和感官描写：课间教室里的喧闹、走廊上运动鞋的吱呀声、便当盒打开时的香味、夕阳透过窗户的金色、电车驶过的哐当声。身体锚点偏细腻：脸颊发烫、耳朵发红、手指绞着裙摆、心砰砰跳、不敢直视对方的眼睛。动作描写要有轻小说味：双手捧书、歪头疑惑、鼓脸生气、扑上去抱、躲在墙角偷看、跑着赶电车。场景：教室、天台、操场、走廊、社团活动室、便利店、电车站、家庭餐厅、公园、卧室。氛围轻松温馨，有青春感和淡淡的萌味。

### 约束规则

- 必须使用校园/日常轻小说专有词汇
- 氛围轻松温馨，有青春感
- 人物互动要萌，适当的傲娇/天然/腹黑等属性可以自然体现
- 感官描写注重：食物香味/夕阳/校服布料感/铃声/电车声
- 对话风格轻快自然，贴近高中生/年轻人的说话方式
- 适当的吐槽和内心吐槽是轻小说的灵魂

### 范例

**标注**：轻小说日常词库示例：便当/教室/数学/同学/信封/情书/同桌/夕阳/校服等校园词汇，氛围轻松有青春感，结尾留悬念

```
「哟，今天也带了便当啊？」

前桌的山田转过头来，眼睛直勾勾地盯着我桌上的便当盒。

「我妈妈做的。」我把便当盒往自己这边挪了挪，「你别想了，今天没有多余的。」

「小气——」山田拖长了语调，却被走进教室的班主任打断了。

第一节课是数学。我偷偷把便当盒塞进抽屉里，却发现旁边多了一个粉色的信封。

我的心跳漏了一拍。

信封上没有署名，只写着「二年A班 高桥悠太君收」，字迹很秀气，是女孩子写的。

我偷偷瞄了一眼斜前方——同桌的铃木雪正低头翻着课本，侧脸在清晨的阳光中显得格外好看，耳朵尖却微微泛红。

诶？

难道……
```
