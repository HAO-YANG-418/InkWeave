> **本卡自洽**：判分标准写在卡内，不引用 `生成指令.md` 任何行号（P1 重构后该行号已漂移，以"能力本身"为锚）。

## 〇、使用铁律（动手前先读）

1. **真加载底座**：盲写前必须手动读取运行时默认底座 22 个选项的 `system_prompt`（模拟 `prompt-builder.ts` [2] 层注入），否则测的是 agent 自身倾向、结论无效。
2. **剥脚手架**：不查 #6/#7/好懂红线/铁则/能力清单，只带底座自然写。
3. **逐项打分**：15 项每项必须给 ✅ / △ / ✘ / ➖，并附 1 句证据（引原文片段）。
4. **判定图例**：
   - ✅ 内化 = 剥规则后自然做到
   - △ 部分 / 不稳定 = 场景依赖或时有时无
   - ✘ 缺失 = 该章完全没出现
   - ➖ 未验证 = 本轮场景未触发该项（如纯对话章不触发 A14 场景规划），不算短板

## 一、A 层 15 项 · 判分标准（自洽）

| # | 能力 | 判分标准（满足即 ✅） | 一票否反例 |
|---|---|---|---|
| **A1** | 冷开场 | 首句 ≤20 字、直接进动作/现场，无叙事总结句 | "那一年…""故事要从…""话说…"开场即 ✘ |
| **A2** | 外部压力 | 每章 ≥1 次"世界主动反咬主角"（人/制度/时间/空间/物件施压） | 全章只有主角内部心理、无外力加压 = ✘ |
| **A3** | 章末硬钩 | 末 80–120 字给**具体新信息**颠覆判断 | "他不知道的是…""然而他错了"式假钩 = ✘ |
| **A4** | 读者理解链 | 新专名首现必绑可见物（人→麻烦→结果→痕迹→名称→设定） | 抛陌生名词不解释让读者懵 = ✘ |
| **A5** | 情绪外化 | 禁直述情绪词，落到具体身体部位；情绪走克制→溃堤→余波弧线 | 出现"他很难过/很害怕/愤怒地"直述 = ✘ |
| **A6** | 身体锚点 | 每段有视角人物身体感知；对话/信息密集段也禁连续两段无 | 长段对话无身体锚点、角色变摄像机 = △→✘ |
| **A7** | 五感调度 | 有感官基调，但每 200–300 字 ≥1 次非基调感官，禁单一感官霸权 | 纯视觉独大、无听/嗅/触/味穿插 = △→✘ |
| **A8** | 事件优先 | 动作→世界回应→身体留痕；信息裹在动作里 | "先给数据/设定后做动作" = ✘ |
| **A9** | 内容密度 | 每段承担推进/人物/钩子/情绪之一；删掉不影响主线 = 水 | 存在"删了也不影响主线"的段落 = △ |
| **A10** | 反顺滑 | 禁正确废话；注入主观偏见；长短错落；人设带瑕疵 | "正确但空"的总结句（如"生活就是这样"）= △ |
| **A11** | 人味四件 | 情感分层 / 留白只停情绪层 / 角色声音独一 / 自然自嘲反讽 | 全程绷着零贫嘴零自嘲（紧张章尤需查）= △ |
| **A12** | 爽点预埋 | 主角私心驱动 / 对话碰撞带信息差 / 设定埋进危机反应 | 全章无一处"私心或信息差反打" = △ |
| **A13** | 镜头编排 | 每段有镜头功能（移动/触摸/信息/压力/对话/收束等），归不进就删 | 大段无镜头功能的"叙述填充" = △ |
| **A14** | 场景规划 | 4–6 场景、对话 ≤25%、总字数 ±10%、≥3 种镜头类型 | 盲写不查规则也自然合格即 ✅（可下沉为默认习惯） |
| **A15** | 章末收束 | 走标准模式轮换：手→物 / 眼→光 / 脚→地 / 骨→热 / 剑→血，不重复上三章 | 自创收束未走五种标准模式 = △（待专项复验） |
