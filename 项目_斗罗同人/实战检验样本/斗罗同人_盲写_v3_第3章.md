# 斗罗同人 · 第3章 墙上的名字（盲写 v3 · 脚手架剥离后）

> 盲写口径：写前不回看任何规则（好懂红线 / #6 / #7 已从 生成指令.md 剥离；铁则、技法亦不查阅）。只靠已去冷峻的默认底座（口语白话·内外结合·好懂优先·不剁碎句）自然写。目的：验证"剥掉全部显式规则清单后，根本(默认底座)是否仍稳"。

老周把庙门抵死的时候，门板"咚"地弓起来一块。

不是撞，是挤。外头的东西太多，一层压一层往门上贴。木缝里渗进腥气，甜的那股先钻进来。

"顶住！"老周肩膀死死抵着门闩，脸涨得通红，"它们进不来——"

话没说完，门闩"咔"地裂了道口子。

陆鸣回头看了一眼洞口。黑的，那股甜腥正一股一股往外冒。刚才那句话就是从这里面出来的。它认识他，认识他爹。

他咬了咬牙，往洞里钻。

"你疯了！"老周吼。

"我进去看看，快得很！"陆鸣已经矮身进了洞。

洞很窄，得弓着背走。石壁湿，手按上去一手黏泥。走了十来步，忽然宽了。

是一间石室。

陆鸣举起铁尺。尺身自己亮起来了，白光昏昏的，照见四面墙上密密麻麻全是刻痕——一道一道，横的，长短不一，像有人在墙上量了一辈子东西。

他凑近看。每道刻痕旁边，还刻着字。

是名字。

"周大山……四十二年。"

"孙有田……十九年。"

"陈寡妇……三年。"

陆鸣手指发凉。这不是名册，这是账。尺村那三百口人，一个一个，都被量过，都记着数。

他顺着墙往里走，越走手越抖。名字到了尽头，最后一行刻得很深，刻到一半停了：

"陆远山……"

后面是空的。没有数字。

陆远山是他爹的名字。

陆鸣喉咙一紧。他伸手摸那三个字，石粉簌簌往下掉。刻痕很新，比旁边那些新得多——不是三百年前刻的，是后来有人补上去的。

石室中间有块平石，石上摆着半把铁尺。

断的。从中间齐齐截断，断口很平，像被人拿什么东西一下子削断。

陆鸣拿起来。断尺入手，比他腰间那把沉，尺背上有一行小字，刻得极浅，要凑到光底下才看得清：

"量人者，人亦量之。"

他没懂。但这行字的笔画，跟他从小到大在铁尺柄上摸的那道旧刻痕，是一个路子。

外头"轰"的一声。庙门塌了。

陆鸣听见老周闷哼一声，接着是蛇群涌进来的沙沙声，密得像下暴雨。

他把断尺塞进怀里，转身往外冲。刚到洞口，一条红眼蛇已经从侧面窜到脸前——他尺锋一挑，蛇头飞出去，血溅在他下巴上，热的。

通道被蛇堵死了。

陆鸣退回石室，后背贴上石壁。墙上的名字硌着他。

就在这时，他身后那面墙，轻轻响了一下。

咔。

陆鸣猛地回头。

他刚才摸过的那行"陆远山"旁边，多了一道新刻痕。石粉还在往下掉。

那道痕旁边，刻着两个新字。

是他的名字。

陆鸣。

后面跟着一个数字。

那数字不是刻完的——石壁上，刻字的动作还在继续，一点一点往下划。

像有个人，正贴着他背后的墙，一寸一寸量他的骨头。

### 写后比对（写完才评估）

- **开头**：门板被挤弓 + 门闩裂口，硬开场（外部压力立刻到场），非"某某先响了"式慢起。
- **有货**：量尺门真相落地为"墙上刻痕=量人账本（名字+年数）"；断尺 + 尺背刻字"量人者，人亦量之"；爹的名字"陆远山"刻到一半、刻痕很新（不是三百年前的）。全是具体物件与可感细节，非概括句。
- **人物厚度**：父子线从"铁尺=遗物"推进到"爹的名字被刻在账上、且是后补的"——爹不是失踪，是被记过一笔。老周断后挡门（恩义）。
