# 重细节拆招

> 一招一式清晰拆解，动作细节精确到身体部位和武器轨迹。适合武侠、硬派格斗场景，画面感强。
> 所属节点：战斗风格

## 教学指令

战斗/动作描写注重招式拆解，每一个动作都要写清楚：身体哪个部位在动、从哪个方向来、用什么角度、对方如何应对。动作链条清晰，有因有果。使用精准的动作动词，不用模糊的「打过来」「躲开」，要写具体是怎么打、怎么躲。身体的受力感、重心变化、肌肉反应都要写到。

### 约束规则

- 每个攻防动作必须写清方向、部位、方式
- 动作链条有因果关系，不能跳跃
- 使用精准动作动词，不用模糊描述
- 每3-4个动作穿插一次身体感受（疼痛、麻木、重心失衡等）

### 范例

**标注**：招式拆解清晰，每一步动作有方向有因果，身体感受穿插其中。

```
对方右拳直扑面门。

他偏头闪开，拳风擦着左耳过去，带起一阵热风。同时左脚向前半步，右肘横击对方肋下。

对手收拳回防，左臂下格挡开肘击。但他的肘是虚招——右膝已经顶向对方小腹。

对手来不及回防，膝盖结结实实撞在腹肌上。对手闷哼一声，弓起身子。

他顺势抓住对方衣领，右拳从下往上勾出。
```
