# 都市现代

> 都市现代世界观词库，包含手机、电脑、微信、公司、老板、地铁、电梯、公寓、酒吧、咖啡等现代都市生活专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用都市现代世界观词库。写作时自然融入现代都市的专有名词和感官描写：手机屏幕的蓝光、地铁车厢的拥挤、咖啡的香气、写字楼的冷气、霓虹灯光、键盘敲击声、汽车鸣笛、外卖袋的塑料袋声。身体锚点都是现代生活中的——手指划过屏幕、握着方向盘的手、电梯镜面里的自己、耳机里的音乐。动作描写要现代：刷手机、敲键盘、扫码支付、挤地铁、按电梯、打方向盘、点外卖、发微信、开视频会议。场景要有都市感：CBD写字楼、地铁早高峰、深夜便利店、高档酒吧、出租屋、地下停车场。

### 约束规则

- 必须使用现代都市专有词汇，避免出现古代或玄幻词汇
- 身体锚点融入现代生活动作（刷手机/握方向盘/按电梯等）
- 感官描写要有都市特色：霓虹/冷气/尾气/咖啡香/键盘声
- 交通工具、通讯方式、生活场景必须符合现代设定
- 对话风格自然口语化，符合当代都市人说话方式
- 可以融入网络用语、职场黑话、流行语，但要适度

### 范例

**标注**：都市现代词库示例：PPT/咖啡/微信/加班/外卖/CBD/霓虹灯/键盘/末班车/APP等现代词汇自然融入

```
晚上九点，CBD写字楼的灯光还亮着一半。

林悦盯着电脑屏幕上的PPT，眼睛干涩得厉害。她揉了揉太阳穴，端起已经凉透的咖啡喝了一口——苦味让她稍微清醒了一些。

手机屏幕亮了一下，是妈妈发来的微信：「周末回家吗？给你炖了汤。」

她打字回了句「看情况，要加班」，发送，然后把手机扣在桌面上。

旁边工位的张伟伸了个懒腰：「还不走？我先撤了，末班车快没了。」

「你们先走吧，我改完这版方案就走。」林悦勉强笑了笑。

键盘声重新在空旷的办公区响起。窗外，城市的霓虹灯映在玻璃幕墙上，红的蓝的绿的，像一幅冷漠的画。

她点开外卖APP，点了一份麻辣烫——这已经是她这周连续第四天吃外卖了。
```
