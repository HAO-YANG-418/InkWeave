# 手写实战前自检清单（方案方固化 · 2026-08-30）

> 用途：手写《裂日》新章 .md **之前**照此表过一遍，避免跳过 pre-analysis 裸写、重踩已验证的 AI 文风 tells。
> 背景：49–57 批实测"肉眼手写跳过 pre-analysis"导致 not_shi / 连续比喻 / 破折号 等 tells 每批重演；26/27 批跑过 pre-analysis 则有效。本清单把"已验证有效的流程 + 引擎真实 ruleId"钉死。
> 定位：这是**写作方（手写实战）**的纪律清单，不是引擎改动。引擎告诉该避什么，本清单逼你写前就避。

---

## 第 0 步（最关键，常漏）：先跑 pre-analysis 拿上章禁忌

```bash
# 在 InkWeave/ 根目录，写第 N 章前先跑（N=目标章号）
npx tsx 检测工具/pre-analysis.ts N
```

- 输出含 **"本章禁忌（硬约束，生成时逐条检查）"** 段（函数真身 `检测工具/pre-analysis.ts:519 injectFingerprint`，读上章 `.fingerprint.json` 生成）。
- 禁忌来自 `REACTIVE_HARDSET`（`pre-analysis.ts:444-449`）：`comma_chain` / `forbidden_char` / `not_shi_pattern` / `sense_density` —— 即上章**真踩过**的点。
- **禁止跳过这一步直接手写**（49–57 的重踩根因就是这里漏了）。没有上章指纹时脚本会提示先 `--save-fingerprint`，照做即可。

## 第 1 步：字数预算（写前就带，别写完才发现短）

- 裂日 `minChapterWords = 2100`（R4 方案B，`知识库/阈值标定/default.json` 标定），**首稿目标 ≥2100，理想 2500–3000**。
- CJK 首稿系统性偏短是**每批必现**的 AI 文风签名（28–37 首稿 831–1587、49–57 首稿 1078–2047）。**写前把 2100 当硬下限记在脑子里**，每段写具体、信息密度做上去，不凑字不注水（写作基准·创作本能级）。

## 第 2 步：banned-pattern 默写自检（基于引擎真实 ruleId）

写完一段自读一遍，对照下列引擎会拦的点：

| 告诉（tell） | 引擎 ruleId | 手写时怎么避 |
|---|---|---|
| 不是X是Y | `not_shi_pattern` | 避免"不是…是…"定型判断句；7 批全中最顽固，优先自查 |
| 连续比喻过密 | `simile_density`（`源码/checker.ts:1665`） | 同段别连用"像/仿佛/如"；⚠️ 已知 `:1659` 正则会把"如今/如果"误判，修复前别因单处"如"慌，但段落里确实叠了 ≥2 个比喻词就必须改 |
| 破折号破格 | `forbidden_char` | 禁用 `——`（中文破折号）；用逗号/冒号/句号替代 |
| 省略号 | `forbidden_char` | 禁用 `…`；用"……"或正常标点 |
| 紧邻重复 | （相邻重复检测） | 相邻两句别用同一词/同结构开头 |
| 凉质感词 | `excludedTextureWords`（裂日 project.json 已排除"凉"） | 裂日别用"凉"作质感词，换其他体感词 |
| 感官失衡 | `sense_density` / `sensory_balance` | 长场景别只有视觉+听觉，补触/嗅/味 |

## 第 3 步：写充实，不是写长（创作本能级）

- 每段问自己：有具体颜色/触感/温度/声音/味道吗？没有就补细节，别用"不由得/忍不住/似乎"这类填充词（`填充词过多` warning）。
- 比喻只用一个就够，且用具体喻体（"指骨在响"优于"像被铁钳夹住"）。
- 开篇 ≤20 字强感官砸人（疼/响/凉），别先写环境背景（`开篇首句过长` / `环境开场` error）。

---

## 第 4 步：占位符/锚点纪律（赶工 slip 防护）

- 一次性跑多章时，**每章写完立刻 `npx tsx 检测工具/check-chapter.ts N` 验收**，再写下一章。
- 禁止留 `【待补】`/占位段；Edit 锚点用整句唯一串，别用短到会撞车的片段。
- 字数预估失准（首稿没带 2100 预算）是 49–57 的赶工 slip，本清单第 1 步专治。
