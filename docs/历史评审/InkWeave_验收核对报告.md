## 3. 两处纠偏（重要）

### 3.1 "第14→15章闭环验证"措辞不准
- 第15章本体写于 2026-08-15（修复前），其旧 fingerprint 无 stylePatterns，闭环当时注入不了。
- 评价 agent 手动重算第14章指纹后，闭环才真正点火并注入第15章写前分析。
- 能力真实，但文档把"验证"挂错章节。后续章节若用 auto-pipeline 会自动自愈（每章 check 后存 stylePatterns，下章读得到）。
- **建议**：存量 1–15 章指纹缺 stylePatterns，建议一次性重算（或首轮 auto-pipeline 跑通即自愈），避免下一章偶发"无注入"。

### 3.2 排比堆叠仅 warning，不阻断生成（残留风险）
- 第14章被检出 16组74处排比堆叠，但总分仍 88/B级、通过。
- 硬约束写在 `生成指令.md` 为**软约束**（靠 LLM 自觉），非硬门禁。
- 风险：下章仍可能堆砌并"B级通过"，循环只"提醒"不"拦截"。
- **建议**：将 `style_stacking`（排比堆叠）升为 error 级，或大幅提高扣分权重，使重度堆砌章不达 85 分门槛。

### 3.3 轻微不一致（顺手改）
- `生成指令.md` 文件头仍写 `# 生成指令 v4.5.3`，内容已是 v4.8（铁则十六/十七）。建议同步版本号。
