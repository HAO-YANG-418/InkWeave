# 重心理博弈

> 侧重对峙、算计和心理博弈，战斗是心理较量的外在表现。适合智斗、谈判式对峙、高手对决。
> 所属节点：战斗风格

## 教学指令

动作/战斗描写侧重心理博弈。对峙比打斗更重要：双方在出手前的观察、试探、算计、虚张声势、识破对方意图。动作是心理的外化——一个眼神、一个肌肉的微小紧绷、脚步的半寸移动，都比拳打脚踢更重要。真正的胜负在动手之前就已经决定。写沉默中的张力，写双方脑中的计算，写假动作背后的真实意图。

### 约束规则

- 对峙和心理描写占战斗篇幅的60%以上
- 每个动作之前必须有心理铺垫或判断
- 关注微表情、微动作和身体语言
- 胜负的关键是智慧/心理/信息差，而非蛮力

### 范例

**标注**：对峙中心理博弈为主，观察细节、判断意图，动作只是心理的验证。

```
两人相距五米，谁都没有先动。

周敬言的右手垂在身侧，手指微微弯曲。林深注意到他食指的第二关节有一层薄茧——那是常年握枪扣扳机磨出来的。但他的枪在腰侧枪套里，扣盖没有打开。

是虚张声势？还是在等他先动？

林深的目光从对方的手移到眼睛。周敬言的瞳孔很稳，呼吸频率大约每分钟十二次——非常平静。一个真正要开枪的人，呼吸会不自觉地加快。

所以他不会开枪。至少现在不会。

林深向前迈了一步。

他看见周敬言的左眉极轻微地跳了一下。
```
