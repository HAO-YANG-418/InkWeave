# 俏皮轻松

> 轻松幽默，吐槽有趣，节奏明快。适合轻小说、都市喜剧、甜宠、吐槽风作品。
> 所属节点：语调

## 教学指令

俏皮轻松基调的核心是'有趣、好读、让人笑'。叙事可以有吐槽、有反差、有内心OS，节奏明快，读起来不累。但搞笑不是胡闹，要有章法。具体语言规则：

1. 吐槽与内心OS：允许叙事者或主角用轻松的口吻吐槽，可以用括号补充内心吐槽（破折号全局禁用，用逗号替代）。主角内心想法可以很跳脱、很真实、很接地气，但不要每段都吐槽，会累。

2. 反差萌：笑点来自反差——严肃的场景里出现很蠢的细节、高冷的人做出很傻的事、紧张时刻突然冒出一句不合时宜的话。反差要自然，不能硬挠痒痒。

3. 夸张但不离谱：可以适当夸张描写（'他的脸黑得像锅底''眼睛瞪得铜铃大'），但要服务于笑点，不能无意义夸张。

4. 节奏轻快：句子短，对话多，描写点到为止。动作描写要有趣，不要像武功秘籍一样一板一眼。

5. 禁止事项：不要用网络烂梗（'yyds''绝绝子''emo'这类会过时的词），不要为了搞笑破坏人物设定（高冷角色突然变话痨），不要在严肃剧情里强行搞笑（会破坏气氛），不要低俗。

6. 甜宠/轻松向：如果是甜宠文，笑点来自男女主的互动和反差，不是刻意讲段子。情感要甜但不腻，互动要自然。

### 约束规则

- 吐槽频率控制：每千字不超过3处内心OS/吐槽，不要句句都在抖机灵
- 禁止使用过时网络热词和烂梗，用生活化的真实幽默代替
- 句子短为主（15-20字），对话占比可以适当提高到40%-50%
- 搞笑不能破坏人物设定——角色的说话和行为方式要符合其性格
- 严肃剧情（生死/离别/重大转折）时禁止强行搞笑
- 反差萌要自然，不能硬造笑点，不能为了搞笑让角色OOC
- 段落目标长度60-100字，短段落多，留白多，读起来轻松
- 可以使用感叹号和问号，但禁止滥用（每千字感叹号不超过15个）

### 范例

**标注**：俏皮轻松示范：内心吐槽（'行今天走朋克风''毁灭吧赶紧的'）自然不生硬，笑点来自反差（女主狼狈vs男主精致、翘起来的头发），没有刻意讲段子但让人会心一笑。夸张适度（黑眼圈像被打了两拳、像天线），对话自然。结尾内心OS是典型的轻松风处理方式。

```
周一早上七点半。

林夏盯着镜子里的自己，沉默了三秒。

黑眼圈重得像被人打了两拳，头发翘起来一撮，像天线。她用手按了按，按下去，弹起来。再按，再弹。

行，今天走朋克风。

她叼着一片面包冲出门，电梯在15楼停了，门一开——

顾言琛站在里面。西装革履，头发一丝不苟，手里端着一杯咖啡，整个人精致得像杂志封面。

林夏嘴里的面包差点掉下来。

更要命的是，她那撮天线头发还在翘着。

顾言琛的目光落在她头顶，停顿了零点五秒。

「早。」他说，语气平静得像什么都没看见。

林夏用最快的速度把头发捋平，挤出一个笑容：「早啊顾总，好巧啊哈哈。」

电梯门关上。

顾言琛很体贴地没有再看她，只是嘴角好像动了一下。

林夏面无表情地盯着跳动的楼层数字。

毁灭吧。赶紧的。
```
