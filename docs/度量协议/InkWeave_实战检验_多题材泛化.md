# InkWeave 实战检验·多题材泛化（#2）

> 日期：2026-08-19 | 引擎：v4.9（已含 #1 动词多样性修复）| 项目：裂日
> 目的：验证修复后的写前契约在不同题材、非直觉感官主导下的**泛化能力**，并确认 #1 的"动词多样性"修复是否真正消除了排比张力。

## 一、方法

用 `pre-analysis` 生成两章不同题材的契约（多样性轮换把战斗章分到的嗅觉主导、日常章分到的触觉主导——均是非直觉选择，最能考验泛化），据此写两章，严格应用修复后的契约（零破折号 + 多样感官动词 + 感官均衡 + 碎句合并），再跑 `check-chapter` 验证。

样本保留在 `项目_裂日/实战检验样本/`（第17/18章）。

## 二、契约分配（多样性轮换）

| 章节 | 题材 | 主导感官 | 镜头侧重 |
|------|------|----------|----------|
| 第17章 嗅觉战场 | 战斗 | **嗅觉**（非直觉） | 心理 |
| 第18章 触感清晨 | 日常 | **触觉**（非直觉） | 动作 |

## 四、结论

### ✅ #1 动词多样性修复生效（关键）
两章均使用**多样感官动词**：
- 嗅觉章：闻到 / 飘来 / 钻进鼻腔 / 扑进鼻腔 / 闻起来 / 嗅了嗅 / 空气里都是
- 触觉章：触到 / 摸到 / 感到 / 硌 / 蹭 / 握 / 抵 / 贴

**均零排比堆叠 error**。对比实战检验第一轮版B"听见×7"触发 error——张力已彻底消除。修复达成。

### ✅ 契约泛化能力良好
战斗章（嗅觉主导）、日常章（触觉主导）都达 B 级（85–87），且零破折号、零解释腔、碎句干净。证明风格契约在**不同题材 + 非直觉感官主导**下仍能稳定引导出合规章节，不是只能写某一类。

### ⚠️ 暴露的新小问题（非阻塞）
- 第18章出现 1 处**逗号链警告**（日常章某叙事段连续逗号串联："他翻了个身，肩胛碰到床单的褶，粗，洗得发硬的棉，蹭过皮肤像砂纸"）。属 warning 级，可优化但不废章。提示：节奏均匀的长逗号链会降低阅读颗粒感，可适当用句号断拍。

## 五、待办
1. 逗号链 warning 可在生成端契约轻提示（"避免连续≥5逗号串联，适当句号断拍"），优先级低。
2. 字数 error 为样本篇幅限制（~800字 vs 目标3000），非故障；正式写作达字数即消失。
3. 样本原文可作 #5 盲评 / 卖课展示素材（现已有 A/B 对照 + 战斗/日常泛化共 4 份样本）。

## 六、整体实战检验总结（#1+#2）
- 生成端契约有效且可泛化（A/B对照 + 两题材验证）
- 检测端不漏杀（野生网文毛病全抓）
- #1 盲点已修复并验证
