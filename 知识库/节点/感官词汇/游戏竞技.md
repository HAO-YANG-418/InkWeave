# 游戏竞技

> 游戏竞技/电竞世界观词库，包含电竞、操作、技能、CD、走位、团战、打野、中单、ADC、辅助、段位、排位、直播、弹幕、键盘、鼠标等电竞游戏专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用游戏竞技/电竞世界观词库。写作时自然融入电竞游戏的专有名词和感官描写：机械键盘的噼啪声、鼠标快速点击的嗒嗒声、耳机里队友的嘶吼、屏幕上技能特效的炫光、手心的汗让鼠标打滑。身体锚点注重电竞特色：手指在键盘上飞舞、眼睛死死盯着屏幕、后背僵直、心跳随着团战节奏加速、手腕因为长时间操作酸痛。动作描写要有电竞味：秒选英雄、闪现开团、走位躲技能、补刀、gank、推塔、五杀、翻盘。场景：电竞馆比赛舞台、训练室、直播间、网吧、选手休息室。

### 约束规则

- 必须使用电竞游戏专有词汇，游戏术语要准确
- 比赛描写要有节奏感：前期发育/中期游走/后期团战
- 团队配合是重点：沟通/指挥/默契/失误/翻盘
- 感官描写注重：键盘声/鼠标声/耳机里的喊叫/屏幕光/手心汗
- 对话包含队内语音交流，要有电竞选手说话的风格（简洁/激动/术语密集）
- 比赛描写要让不懂游戏的读者也能感受到紧张和激情

### 范例

**标注**：电竞词库示例：大龙/妖姬/技能CD/W技能/惩戒/位移/连招/Penta Kill/解说/电竞馆/机械键盘等电竞词汇，节奏紧张

```
"RNG对阵T1，决胜局，第三十分钟！"

解说的声音透过耳机传来，但林烨已经听不到了。他的世界里只剩下屏幕上的英雄、右下角的小地图，以及手指下噼啪作响的机械键盘。

"大龙！他们在打大龙！"辅助的声音从耳机里炸开。

林烨的瞳孔猛地收缩。他操控的妖姬此刻只有半血，技能CD还剩三秒，但他没有犹豫——手指在键盘上划出一道残影，W技能魔影迷踪踩下去，正好落在龙坑上方。

"我看到了！打野残血！"

他按下R键复制W，二段位移直接踩进龙坑！QRE连招在0.3秒内全部打出，T1打野的血条瞬间蒸发。

"抢了！大龙被抢了！！！"

惩戒落下的那一刻，大龙的哀鸣响彻整个召唤师峡谷。林烨的妖姬借着W的返回位移安全撤出龙坑，血条只剩最后一丝——37点血。

屏幕上，T1四人的头像齐刷刷变成灰色。

"Penta Kill！！！"

电竞馆炸了。
```
