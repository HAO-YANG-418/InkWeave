# 桥段卡：底牌揭晓

- **母题**：隐藏身份/实力曝光 + 全场认知崩塌
- **结构**：①多方误判主角（弱者/无名） → ②危机逼出真底牌 → ③揭晓（身份/血脉/境界） → ④旧识反应反转（惧/敬/悔）
- **情绪曲线**：瞒(0-30%) → 逼(30-55%) → 揭(55-85%) → 崩(85-100%)
- **钩子位**：章末留「原来他一直藏着」或「新的敌人因他而来」
- **适配题材**：玄幻 / 都市爽文 / 群像
- **来源书**：斗破苍穹 / 斩神 / 完美世界（结构提炼，非原文）
- **禁忌**：禁止底牌揭晓太早（须蓄力）；禁止揭晓无冲击（须有前期误判铺垫）；禁止身份副作用全无
