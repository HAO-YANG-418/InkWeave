# 灵异恐怖

> 灵异恐怖世界观词库，包含鬼、幽灵、阴气、纸钱、棺材、坟、诡异、阴森、寒毛、冷汗、阴影、血、诅咒、尸变、招魂等恐怖灵异专有词汇。
> 所属节点：感官词汇

## 教学指令

你使用灵异恐怖世界观词库。写作时自然融入恐怖灵异的专有名词和感官描写：阴风阵阵的寒意、纸钱燃烧的焦糊味、棺材里腐朽的气味、黑暗中若有若无的低语、身后跟随的脚步声、镜子里多出来的影子。身体锚点偏恐惧反应：寒毛倒竖、冷汗直流、脊背发凉、牙齿打颤、腿软、喉咙发紧、瞳孔放大。动作描写要有恐怖味：摸索着开灯、一步步后退、捂住嘴不敢出声、僵硬地转头、颤抖着伸手、狂奔逃命。场景：废弃医院、凶宅、坟地、殡仪馆、老井、地下通道、空无一人的学校、午夜的镜子前。氛围是核心——压抑、诡异、不安、未知的恐惧。

### 约束规则

- 必须使用灵异恐怖专有词汇
- 氛围营造是第一位的：压抑/诡异/不安/未知恐惧
- 不要急于揭示恐怖源头，未知和暗示比直接描写更可怕
- 感官描写注重：阴冷/腐臭/异响/阴影/血腥味
- 身体反应是恐惧的直接体现：冷汗/寒毛/颤抖/腿软/心跳
- 不要用太直白的恶心描写（如过多内脏细节），心理恐惧更高级
- 声音和光影的暗示比直接看到鬼更吓人

### 范例

**标注**：恐怖词库示例：凌晨/黑暗/赤脚/冰凉/脚步声/寒毛/阴冷/女人声音等恐怖元素，未知恐惧比直接见鬼更吓人

```
凌晨三点十七分。

我被尿憋醒，摸索着下了床。走廊里漆黑一片，我没开灯——怕吵醒老婆孩子。

卫生间在走廊尽头。我光着脚踩在地板上，地板冰凉刺骨，这很奇怪，虽然已经入秋，但地暖一直开着。

走到一半，我停住了。

身后传来脚步声。

很轻，很慢，是赤脚踩在地板上的声音。嗒、嗒、嗒……

我的寒毛一下子竖了起来。老婆孩子都在卧室里睡觉，这个时间谁会在走廊上？

我不敢回头。

脚步声越来越近，我能感觉到一股阴冷的气息从背后逼近，像是有人把一块冰贴在了我的后颈上。然后，一个声音在我耳边轻轻响起——

是一个女人的声音，又细又尖，像是从很远很远的地方传来：

「你……看见我孩子了吗？」
```
