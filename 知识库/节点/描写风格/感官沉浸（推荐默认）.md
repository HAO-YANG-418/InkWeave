# 感官沉浸（推荐默认）

> 五感全开的描写方式，视觉、听觉、嗅觉、触觉、味觉多通道并进，沉浸感极强，让读者身临其境。
> 所属节点：描写风格

## 教学指令

感官描写的核心是'让读者用身体读'。不是告诉读者'这里很恐怖'，而是让读者后颈发紧、手心出汗、闻到那个味道、感觉到那个温度。读者不是在看故事，是在故事里。

【五感写作要点】

1. 视觉（40%-45%）：不要只写'有什么'，要写'是什么样的'。

- 光线：光源在哪？是强光还是弱光？什么颜色？照在什么东西上反光？阴影在哪？

- 颜色：不要只写'红色'，写'暗红''铁锈红''像凝固的血一样的红''被水泡得发乌的红'。

- 动态：什么在动？怎么动？灰尘在光柱里浮着，水珠顺着岩壁往下爬，烟往上飘，影子在晃。静态画面是死的，有动态才活。

- 视角：从角色的眼睛看出去，不是上帝视角。他先看到什么，后看到什么，什么被挡住了看不见，什么晃了他的眼。

2. 听觉（20%）：声音最能制造沉浸感和紧张感。

- 不要只写'有声音'，要写声音从哪来、多远、多大、什么质感。'滴答声'不够，'从黑暗深处传来的滴答声，间隔七秒，每一声都比上一声近一点'才有感觉。

- 寂静也是声音。'通风管停了之后，耳朵里只剩自己的心跳声，咚咚的，像有人在里面敲鼓。' 对比之下的安静更可怕。

- 声音的变化：声音变大了？变小了？变调了？刚才有的声音突然没了？声音的变化比声音本身更重要。

- 不要用拟声词堆砌（'哐当一声''轰隆巨响'），用角色的感知和反应写声音——'他耳朵嗡的一下，什么都听不见了'比'一声巨响'有力。

3. 嗅觉/味觉（15%）：嗅觉是最直接触发记忆和情绪的感官，但最容易被忽略。

- 每个新场景至少有一个气味。矿道里是什么味？瓦斯是甜丝丝的像烂苹果，旧巷道有霉味和腐臭味，有人的地方有烟味和汗味。

- 气味要有层次。不是只有'臭味'，是'汗馊味混着烟味，还有一点从深处飘上来的、说不上来的甜腥味'。

- 味觉不要滥用，但关键时刻很有效——嘴里的铁锈味（血）、苦味（恐惧时嘴里发苦）、铜味、铁锈味、灰尘的味道。

4. 触觉（20%）：触觉是锚定感的核心，让读者'踩在地上'。

- 温度：空气是冷是热？壁面是温是凉？风吹在脸上是什么感觉？水是冰的还是温的？温度直接传递情绪。

- 质感：手摸到的东西是什么触感？岩壁是粗糙的还是滑的？衣服是湿的还是干的？铜碗是凉的还是被手焐热了？

- 身体感觉：呼吸的时候肺里是什么感觉？累的时候腿是什么感觉？紧张的时候后颈是什么感觉？疼是怎么个疼法——刺痛？钝痛？火辣辣的？

- 不要写'很疼''很冷'，写'冷风灌进领口，顺着脊梁往下窜，他打了个寒颤''手指冻得发麻，弯都弯不过来'。

【技法原则】

1. 感官融入动作：不要单独拎出来写'这里有XX味，声音是XX，温度是XX'，要把感官写进动作里。'他扶着壁面往前走，岩壁冰凉粗糙，磨得手心发疼，空气里有股甜丝丝的味道，他知道那是瓦斯。'——感官跟着动作走，不生硬。

2. 感官跟着情绪走：角色紧张的时候，听觉会变敏锐（能听见平时听不见的声音），视觉会变窄（只看得见眼前的东西）；角色放松的时候，感官会散开；角色恐惧的时候，会闻到平时闻不到的味道。感官不是客观的，是被情绪过滤的。

3. 选最有代表性的感官：不是每个场景都要五感全上，选2-3种最能传递当下氛围的。恐怖场景侧重听觉+触觉+嗅觉；抒情场景侧重视觉+触觉；动作场景侧重触觉+听觉。

4. 感官要有变化：同一个场景里，感官重点要变。刚进一个地方先闻到味道，然后看到光线，然后听到声音，然后摸到什么。感官像镜头一样推近，读者跟着进去。

5. 禁止陈词滥调：'一股寒气从脚底直冲天灵盖''倒吸一口凉气''空气中弥漫着恐怖的气息'——这些都是偷懒，要用具体的感官细节代替。

### 约束规则

- 每个场景至少激活3种感官类型，视觉占比不超过45%，必须有非视觉感官
- 触觉（温度/质感/身体感觉）是核心锚点，每个场景至少有1处触觉描写
- 感官描写必须融入动作或叙事，禁止像清单一样单独罗列'这里有X味，有Y声音，温度是Z'
- 描写要具体到质感——不写'红色'写具体是什么红，不写'声音响'写是什么样的声音从哪来
- 禁止陈词滥调（寒气冲天灵盖/倒吸一口凉气/弥漫着恐怖气息等）
- 每个新场景/地点出现时，必须有至少1个专属的气味或声音标记
- 感官要被角色情绪过滤——紧张时听觉放大，恐惧时闻到异味，不要客观中立地'摄像'
- 声音的变化比声音本身更重要——声音停了、变近了、变调了，都要写出来

### 范例

**标注**：感官沉浸示范：触觉（岩壁温凉像死人皮肤/水珠黏糊糊）、嗅觉（甜丝丝的烂苹果味=瓦斯）、听觉（通风管停了/心跳声/滴答声间隔七秒/刮岩壁的沙沙声）、视觉（黑暗浓得像墨）四感交织。感官跟着情绪走——一开始没察觉味道，然后后颈汗毛竖起来；关了灯之后听觉瞬间放大；最后那个声音在身后，恐怖感拉满。没有一个词写'恐怖''害怕''紧张'，但读者全程提着气。

```
他扶着壁面慢慢往前走。

岩壁是凉的，不是正常的凉，是那种从很深的地方渗上来的、带着点潮意的温凉，像摸在死人的皮肤上。水珠顺着岩壁往下渗，沾在他手背上，黏糊糊的。

空气不对。

平时这里只有灰尘和炸药残留的硝石味，今天多了一股甜味——很淡，不仔细闻根本察觉不到，像烂苹果，又像什么东西发酵了。他吸了吸鼻子，后颈的汗毛一下子竖起来。

瓦斯。

他停下来，关掉矿灯。

黑暗瞬间压下来，浓得像浸在墨里。眼睛还没适应黑暗，耳朵先醒了——原来通风管的嗡鸣不知道什么时候停了，四周静得能听见自己的心跳，咚咚的，撞得肋骨疼。水滴声从很深的地方传上来，滴答，滴答，每一下间隔大概七秒，每一下都比上一声近一点。

不对。水滴声不会越来越近。

他屏住呼吸。

除了水滴声，还有另一个声音。

很轻。很慢。像是什么东西在爬，爪子刮过岩壁的声音，沙，沙，沙。

在他身后。
```
