# 镜头链规则

正文不能从大纲直接落句子。每段生成前必须先选镜头类型，再按链条展开；链条没走完，不许用句号收束。

## 六类镜头

固定顺序：人物动作 → 光线/视线落点 → 身体触点 → 外界物理反应 → 本拍落点。

| 镜头类型 | 链条 |
|---------|------|
| 移动镜头 | 人物移动 → 光线/风/声音跟随 → 身体触点 → 空间回应 → 落点 |
| 触摸镜头 | 手/脚/背接触 → 材质反馈 → 温差/震动 → 身体余感 → 发现 |
| 信息镜头 | 动作打开 → 视线落字 → 异常差异 → 手停/呼吸变 → 信息钉子 |
| 压力镜头 | 人物尝试 → 系统/人/空间拒绝 → 物理痕迹 → 被迫选择 → 新危险 |
| 对话镜头 | 话出口 → 对方微动作 → 环境压住 → 回答偏移 → 未说出的东西留下 |
| 收束镜头 | 身体动作 → 外界反应 → 信息反咬 → 短句落点 → 下一章问题 |

## 段落模板（八类，每段必选其一）

- 移动镜头 / 触摸发现 / 信息反咬 / 压力逼迫 / 对话推进 / 人物登场 / 伏笔回收 / 章末钩子
- 无法归入模板的段落，视为无任务段落，删或合并。

## 规则冲突优先级

段落模板成立 > 场景压力推进 > 人物行动改变局面 > 镜头连续 > 句群波形 > 短句身份 > 标点指标 > 数量指标
