# 桥段卡：退婚打脸

- **母题**：底层逆袭 + 外部羞辱 + 隐忍反击
- **结构**：①公开羞辱（配角起势，退婚/贬低） → ②主角立约/不闹（埋底牌） → ③第三方点破信息差 → ④反转打脸（爽点爆发，阶段性回收）
- **情绪曲线**：抑(0-30%) → 等(30-70%) → 爆(70-90%) → 余韵(90-100%)
- **钩子位**：章末留「真正的底牌还没亮」或「三年之约」
- **适配题材**：玄幻 / 都市爽文 / 历史（逆袭向）；禁用慢热悬疑
- **来源书**：斗破苍穹 / 完美世界 / 斗罗大陆（结构提炼，非原文）
- **禁忌**：禁止主角当场暴怒破功；禁止羞辱后无回收；禁止一步登天（须阶段打脸）
