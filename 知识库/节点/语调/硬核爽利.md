# 硬核爽利

> 硬气、利落、不拖泥带水。主角霸气不圣母，打脸干脆，节奏快。适合爽文、都市、玄幻、军事题材。
> 所属节点：语调

## 教学指令

硬核爽利基调的核心是'快、准、狠'。叙事节奏快，动作干脆，主角不窝囊，不圣母，不犹豫。语言本身就要有力量感。具体语言规则：

1. 动词驱动：句子以动词为核心，少用形容词和副词。能用动作解决的不用心理描写，能用结果说话的不用解释。踹、砸、劈、瞪、甩、踏、碎——精准有力的单字动词优先。

2. 短句连击：动作场景用连续短句制造打击感，像拳头一拳一拳打出去。每句一个动作，节奏快，不拖泥带水。关键瞬间一句一段，制造顿挫感。

3. 主角硬气：主角不解释、不废话、不道歉、不回头。被挑衅直接反击，被瞧不起直接打脸，不嘴炮不犹豫。行动先于言语。但硬气不是鲁莽——该谋算的时候冷静谋算，动手的时候干净利落。

4. 爽点节奏：压抑不超过两章，打脸必须当场或次日。反派装逼不超过三句就被打脸。主角出手必见血（或见效果），不磨磨唧唧。

5. 语言利落：不用'似乎''好像''仿佛''可能'这类犹豫词。不用'非常''十分''极其'这类修饰词。少用心理描写，多用行为展示性格。

6. 禁止窝囊：主角不能被欺负了忍气吞声，不能被打了不还手，不能看到美女就走不动路，不能圣母心泛滥救不该救的人。该杀杀，该滚滚，不拖泥带水。

### 约束规则

- 动作场景以短句为主（15字以内），连续动作一句一段，制造打击感
- 禁止犹豫词（似乎/好像/仿佛/可能/也许），硬核风格要肯定直接
- 禁止程度副词堆砌（非常/十分/极其），用动作力度体现程度
- 主角对话简洁有力，不解释不啰嗦，能用一句说完的不用两句
- 连续对话不超过3句必须穿插动作描写，动作要有力（拍桌/踹门/攥拳/拔刀）
- 反派装逼台词不超过3句必须被主角打断或打脸
- 每段目标长度50-80字，动作场景可以更短（20-30字一段）
- 单句不超过35字，超过必须拆分
- 禁止主角窝囊行为：被欺负不还手、圣母心泛滥、犹豫迟疑超过两段

### 范例

**标注**：硬核爽利示范：动词驱动（踹/拎/扫/砸/扣/抓/踹/掷/抽/擦），短句连击（'门被踹开。''十秒。''四个人全躺在地上。''咔嚓。'），主角不废话不嘴炮，打完放一句狠话直接走，不拖泥带水。'面钱放在桌上，刚好二十'这个细节比任何描写都体现主角的硬气和讲究。没有心理描写，全是动作。

```
门被踹开。

王虎带着四个人走进来，手里拎着钢管。

「就是他？」王虎叼着烟，扫了林远一眼，「打断一条腿，三万。」

四个人围上来。

林远放下筷子。

碗里还有半碗面，汤还冒着热气。

第一个人冲上来，钢管当头砸下。

林远侧身，钢管砸在桌面上，木屑飞溅。他顺手拿起那碗热面，连汤带面扣在对方脸上。

惨叫声。

第二个人的钢管到了腰侧。林远抓住钢管，一脚踹在对方膝盖上。

咔嚓。

骨头断裂的声音很脆。

第三个人转身想跑。林远把钢管掷出去，砸在后脑勺上，人直接扑倒。

十秒。

四个人全躺在地上。

王虎嘴里的烟掉了。

林远从桌上抽了张纸巾，擦了擦手上的面汤。

「回去告诉赵老三，」林远看着王虎，声音很平，「下次派点能打的。」

他拿起椅背上的外套，头也不回地走了出去。

面钱放在桌上，刚好二十。
```
