# 有限第三人称过去式（默认）

> 以“他/她”称呼视角人物，使用过去时态，但只深入该人物的内心。这是网文中最常用的视角，兼顾代入感和叙事灵活性，是默认推荐选项。
> 所属节点：视角

## 教学指令

你使用有限第三人称过去式进行写作——这是网文最主流的视角。你用“他”或“她”来称呼当前视角人物，用过去时态叙述事件，但只深入这一个人物的内心。你可以自由写这个人物的感受、想法、回忆、判断，但其他人物的内心你只能通过外在表现推测。这种视角的优势是比第一人称更灵活（可以稍微拉开一点距离描写），又比全知视角更有代入感。你可以在不同章节/场景切换视角人物，但同一个场景内必须锁定一个视角，不能跳来跳去。视角人物是读者的“眼睛”和“心”，读者通过他/她来感知故事。

### 约束规则

- 用“他/她”称呼视角人物，叙述用过去时态
- 只能深入当前视角人物的内心，其他人物心理只能推测
- 同一场景内视角锁定一个人物，不得随意切换
- 可以跨章节/跨场景切换视角人物，但切换必须清晰（建议场景转换时切换）
- 叙述信息受限于视角人物的认知，他/她不知道的不能直接写
- 视角人物的选择很重要——要选当下冲突中最有张力的那个人
- 禁止在有限第三人称中突然跳到全知视角

### 范例

**标注**：有限第三人称过去式：用“她”指林晚，深入她的内心（以为做好准备/心跳漏拍/身体比理智诚实），但沈知行的想法只能从“眼神微微变了”推测，不能直接写他心里在想什么

```
林晚推开包厢门的时候，里面已经坐满了人。

她一眼就看到了坐在主位的男人。沈知行穿着一件深蓝色的衬衫，袖口挽到手肘，正侧着头听旁边的人说话，嘴角挂着一丝漫不经心的笑。

三年了。

林晚的手指不自觉地收紧，握在包带上的指节微微泛白。她以为自己已经做好了心理准备，可真正看到这个人的时候，心跳还是漏了一拍。

"林晚？这边坐。"同事招呼她。

她深吸一口气，走过去坐下，刻意选了个正对沈知行的位置——不，不对，她应该选离他最远的位置。可身体比理智诚实，等她反应过来的时候，已经在他对面了。

沈知行抬起头，目光和她对上。

他的眼神微微变了一下，但很快恢复平静，像是在看一个陌生人。
```
