# 有限第三人称现在式

> 以“他/她”称呼视角人物，使用现在时态，只深入该人物内心。兼具临场感和叙事灵活性，适合需要紧张感又不想完全绑定“我”的作品。
> 所属节点：视角

## 教学指令

你使用有限第三人称现在式进行写作。你用“他”或“她”称呼当前视角人物，用现在时态叙述，只深入这个人物的内心。这种视角结合了现在式的临场紧迫感和第三人称的叙事距离，比第一人称现在式稍微“冷静”一点，但仍然有很强的即时感。你可以写视角人物此刻的感受、想法、判断，但不能写其他人物的内心。同一场景视角锁定，不得跳切。所有动词用现在时态（走/看/想/听到/握紧），营造事件正在发生的效果。

### 约束规则

- 用“他/她”称呼视角人物，时态严格为现在式
- 只能深入当前视角人物内心，其他人物心理只能推测
- 同一场景视角锁定，不得随意切换到其他人物内心
- 所有叙述动词用现在式，保持时态一致
- 禁止透露视角人物此刻不可能知道的信息
- 利用现在式制造临场紧张感，适合动作/悬疑场景
- 回忆需明确引入（如“他想起”），且要快速回到当下

### 范例

**标注**：有限第三人称现在式：用“他”指陈默，现在时态（推开/掏出/照亮/握紧/屏住），深入他的感官和紧张感，但不知道门后面的情况，临场感强

```
陈默推开铁门，锈迹斑斑的门轴发出刺耳的吱呀声。

走廊里漆黑一片。他掏出手电筒，光柱切开黑暗，照亮了斑驳的墙壁和地上散落的纸屑。

空气里有一股奇怪的味道，甜腻腻的，像是腐烂的花。

他握紧手电筒，放慢脚步。心跳声在耳膜里轰轰作响，每走一步，地板就发出一声细微的嘎吱。

走廊尽头有一扇门，门缝里透出微弱的光。

陈默屏住呼吸，侧耳倾听——门后面有人在说话，声音很低，听不清在说什么。

他伸手去推门。

门没锁。
```
