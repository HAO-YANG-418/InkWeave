# 严肃正剧

> 庄重沉稳，用词严谨，有历史厚重感。适合历史正剧、严肃文学、谍战、权谋题材。
> 所属节点：语调

## 教学指令

⚠️ 好懂红线（2026-08-31 钉死）：克制≠难懂，留白≠藏逻辑。含蓄/克制/留白只适用于**情绪层**（不直说角色感受），**绝不适用于信息层**——事件因果、动作链、设定逻辑必须说清，读者零回读。任何写法一旦让人需回读才懂，立即让位给"读着顺"。网文第一标准是好懂。

⚠️ 补充（2026-08-31）："禁止戏谑调侃"仅约束**叙事者腔调**，不约束**角色说话**——角色自嘲、贫嘴、带刺的玩笑是人味来源，网文人物需要活人感，不在禁列。

严肃正剧基调的核心是'沉稳、厚重、可信'。叙事像历史记录一样扎实，用词精准不含糊，情感深沉不外放，矛盾冲突有分量。具体语言规则：

1. 用词严谨：用词准确，不含糊其辞，不调侃不戏谑。名词动词精准，避免模糊词（大概/可能/好像）。涉及历史、制度、器物时用词要符合时代背景。

2. 句式沉稳：句子偏长，结构完整，允许复句和从句，但逻辑必须清晰。不用半截话、不用网络语、不用口语碎片。

3. 叙事距离：叙事者保持客观中立，不站队不评论。不替读者做价值判断，把事实呈现出来让读者自己判断。可以写人物内心，但要有深度有层次，不肤浅。

4. 情感深沉：情感表达要克制但有重量。不喊不叫不哭天抢地，大悲无声，大怒无形。越是重要的情感，越要用克制的方式写。

5. 冲突有分量：矛盾冲突不是小打小闹，而是立场、信仰、利益、家国的冲突。每一次冲突都要有前因后果，有代价有牺牲。

### 约束规则

- 禁止网络用语、口语碎片、戏谑调侃语气，保持叙事庄重感
- 禁止模糊词（好像/似乎/大概）连续使用，关键信息必须精确
- 句子结构完整，避免半截话和省略主语过多导致混乱
- 情感表达克制，禁止角色大喊大叫、情绪崩溃式的廉价宣泄
- 涉及历史/制度/器物/礼仪时用词必须符合时代背景，不能出现穿越式错误
- 对话要符合人物身份和教育背景，权谋人物说话含蓄有潜台词
- 段落目标长度100-150字，叙事节奏稳健不急躁
- 单句不超过55字，长句必须有清晰的逻辑结构

### 范例

**标注**：严肃正剧示范：以史笔叙事，时间地点人物精确，用词严谨（銮舆/扈从/微服/勤王），不渲染情绪但沉重感自然涌出。白描史实（荒草半人高/喂马/拍照/掠银）比任何情绪描写都有力量。

```
光绪二十六年，庚子。

七月二十一日，天未明，两宫微服出德胜门西行。銮舆不备，扈从寥寥，王公士民未知所往。

李鸿章自广州奉诏北上，舟至上海，以疾留。张之洞、刘坤一联络东南各省，与各国领事议'东南互保'，约以租界归各国保护，长江内地归督抚保护，两不相扰。

京师沦陷已三日。

紫禁城太和殿前的荒草长到了半人高。日本兵在乾清宫前喂马，俄国兵占据了颐和园，英国军官在天坛的圜丘上拍照。户部存银三百万两被日本兵掠走，内务府的宝物被一车一车运往东交民巷。

直隶总督裕禄在杨村兵败自杀。李秉衡率军北上勤王，于通州张家湾兵败，服毒殉国。

城破那日，军机处章京王瓘正在内廷当值。
```
