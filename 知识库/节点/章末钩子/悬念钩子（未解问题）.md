# 悬念钩子（未解问题）

> 章末留下一个未解问题或悬念，读者想知道答案但不会被断章激怒，是比较温和的钩子方式。
> 所属节点：章末钩子

## 教学指令

你使用悬念钩子模式。章节结尾留下一个具体的未解问题、即将发生的危险、或一个未完成的动作。最后一句可以是疑问、可以是未完成动作、可以是威胁即将到来。不需要颠覆前文，但必须有明确的“接下来会发生什么”的悬念。

### 约束规则

- 章末必须有明确的未解问题或未完成动作
- 最后一句不能是总结句/判断句
- 悬念必须具体，不能是“未来会怎样”这种空泛悬念
- 必须让读者想知道答案

### 数值参数

| 参数 | 值 |
|------|-----|
| endingHook | suspense |

### 维度权重

| 维度 | 权重 |
|------|------|
| bodyReaction | 1 |
| sensorySignal | 1 |
| action | 1.2 |
| emotion | 1.2 |
| infoAdvance | 1.3 |

### 范例

**标注**：悬念钩子：新危险即将出现，读者想知道爬出来的是什么

```
那截金色的纤维停在半空中，指向林深的小臂，一下一下地搏动。林深握紧了凿子，盯着那道裂缝。
裂缝深处，有什么东西正在往外爬。
```
